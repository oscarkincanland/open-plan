# OPPO Sans 4.0 使用说明

本目录字体文件来自 **OPPO Sans 4.0**（font version 1.700），版权归
Guangdong OPPO Mobile Telecommunications Corp., Ltd. 所有。

- 官方来源：<https://www.coloros.com/article/A00000074/>
- 分片来源：npm `@1adybug/oppo-sans@0.1.1`（OPPO Sans 4.0，font version 1.700），
  仅保留 `font-text-*` 与 `font-cn-*` 分片，未修改字体文件。
- 许可协议：OPPO Sans Fonts License Agreement，全文见同目录 `LICENSE`。
- 使用方式：随本软件捆绑内嵌，不单独分发字体文件；未修改任何字体文件，
  仅按 `unicode-range` 分片加载。
- 分片范围：拉丁字符（`font-text-*`）+ 常用中文（`font-cn-*`）；
  生僻字由系统字体回退。
- 字重：可变字体，`font-weight: 100 700`，400/600 均为真实字重，不存在合成加粗。

OPPO Sans 可免费商用，但**不是 OSI 开源许可证**；再分发时必须保留本说明与
`LICENSE`，且不得单独售卖或修改字体文件。
