## 8. 环境与数据状态

- 启动方式：`npm run dev`（后台监督器）或 `npm run start:foreground`；地址 `http://127.0.0.1:3002`。
- 构建：`npm run build`（`client/` Vite）。
- 总门禁：`npm run verify`（服务端语法 + 前端构建 + API 冒烟）。
- 依赖：`npm install` + `npm --prefix client install`；officecli 用 `npm run setup`。
- 本地数据：`.oaw/`（runs/events/pending-asks）不入库；工作区 `office-workspace/`。
- 测试账号：本机单用户，无登录体系；如配置 `OAW_API_TOKEN` 需在本地 `.env`。
- CI：GitHub Actions，push main / PR 触发，16 步。
- 当前未提交改动：代码与文档已按工作流提交；工作区仅剩**与项目开发无关的素材**（`docs/品牌图标备选方案/`、`docs/报告配图/`、设计院报告、软著脚本），保持未跟踪、不入库。
- 干净副本：`open plan/` 已生成（无 `node_modules`、`.oaw`、日志、临时脚本），首次使用需 `npm install` + `npm --prefix client install`；已在 `.gitignore` 中忽略。
