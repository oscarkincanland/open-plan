# Open Plan 技术决策记录（ADR）

> 记录影响后续开发的架构级决策。格式：状态 / 背景 / 决策 / 后果。
> "已批准默认开"类决策均有用户明确批准记录（2026-10-19/20 会话）；其余优化项一律默认关。

## ADR-001 单服务 + Pi SDK 进程内调用
- **状态**：已采纳（沿用）
- **背景**：Agent 能力需要与文档操作、工作区文件系统紧密协作；拆分会带来跨进程事件转发与部署复杂度。
- **决策**：Express 5 单服务（3002），Pi Agent SDK 进程内调用，officecli 作为唯一外部二进制；`scripts/服务监督.mjs` 守护（健康检查 + 崩溃重启，冷启动宽限 180s）。
- **后果**：部署极简（本地单机）；单进程故障域大，靠看门狗与恢复机制兜底；桌面端独立壳（openplan-desktop）attach 同一服务。

## ADR-002 事件即事实（Event Sourcing 语义）
- **状态**：已采纳
- **背景**：断线恢复、跨会话回放、产物归属审计都需要可靠行为记录；前端多视图（对话流/结果卡/任务中心）不能各自解释事件。
- **决策**：所有 Agent 行为统一为注册表登记的事件（`事件注册表.mjs`，lifecycle/persist 双标记）；persist 事件写 JSONL（全局事件流 + Run 目录）；前端视图一律由事件投影（`运行展示投影.js`/`运行轨迹.mjs`）。新增事件不登记则 `test:pi-iteration` 失败。
- **后果**：恢复/审计/回滚有权威数据源；事件类型数膨胀（117+）需要 schema 校验（P1-2，可选开启）与淘汰策略守护。

## ADR-003 统一 feature flag 管道（默认关保基线）
- **状态**：已采纳（2026-10-19 修订：允许用户批准的默认开）
- **背景**：大量优化并行落地，必须保证"关掉即回滚、基线零变化"。
- **决策**：所有开关集中在 `运行开关.mjs`（env 解析+默认值+只读快照，禁止业务模块直读 process.env）；经 `/api/status` 下发，前端 `运行开关.js` 消费，**快照未达=全关=基线**。默认开的例外必须用户明确批准（已有：`askAutoResume`、`stagedVisible`、`autoTab`），用 `readFlagWithDefault` 实现。
- **后果**：实验安全、回滚零代码；开关数量大（40+），需要路线图定期清理并入主路径。

## ADR-004 零新增 npm 依赖
- **状态**：已采纳（硬约束）
- **背景**：供应链安全与包体控制；PI SDK 优化批次确立。
- **决策**：优化优先复用已有依赖（xlsx/docx/docx-preview/x-data-spreadsheet/typebox 等）与 Pi SDK 原生导出；确需新依赖须评审并更新本文档。
- **后果**：预览优化（Excel SheetJS 直读、Word docx-preview 调优）都在现有库内完成；个别能力上限受库约束（如 x-spreadsheet 样式有限）。

## ADR-005 中文命名与中文界面
- **状态**：已采纳（`AGENT.MD` 强制）
- **决策**：新文件中文命名（代码文件按语言惯例）；界面全中文。
- **后果**：Grep/Glob 工具对中文文件名不可靠——检索时用 PowerShell `Get-ChildItem` 核实。

## ADR-006 HITL：ask_user 长窗口 + 迟到回答自动续跑
- **状态**：已采纳（2026-10-19，用户批准默认开）
- **背景**：5 分钟窗口太短——超时后 Agent 按假设瞎猜，用户回来回答已无处可去（404 死卡片）；同时存在"逐项访谈"式过度提问。
- **决策**：等待窗口 60 分钟（`OAW_ASK_TIMEOUT_MS` 可调）；超时补发 `ask_expired`；迟到回答不再 404，落档后自动续跑（会话忙=排队接力，空闲=开新 Run，取消中的任务不复活）；提问纪律写入提示词与工具描述：整轮默认 1 次、至多 2 次，相关待定项合并成一个问题，禁止请示式提问。
- **后果**：长任务挂机答疑成为可能；事件流补全 ask_answered/ask_expired 使等待投影可正确清除；`OAW_ASK_AUTO_RESUME=0` 可整体回退基线。

## ADR-007 complete_task 合并口径（结论不被寒暄覆盖）
- **状态**：已采纳（2026-10-20，用户反馈驱动）
- **背景**：同一 Run 内模型多次调用 complete_task，后写的敷衍结论（"无新增工作"）覆盖先前完整交付总结；界面权威终稿也取最后一条聊天消息，恰是寒暄。
- **决策**：`mergeCompletions`（`运行轨迹.mjs`）：状态变化以最新为准（含 partial→success 推进与事后纠正），状态不变时保留信息量更大的 summary；提示词同时约束同轮只声明一次、最后正文必须是实质结论。
- **后果**：结果卡/agent_summary 稳定呈现最有信息量的结论；模型行为靠提示词引导，服务端口径兜底。

## ADR-008 Excel 预览：SheetJS 直读优先 + 0-based 坐标 + 截断
- **状态**：已采纳（2026-10-20，用户反馈驱动）
- **背景**：原链路（officecli DOM → 全字符串 + 1-based 键）导致日期显示为序列号（45721…）、合并单元格/列宽丢失、整体偏移一格、大文件卡死。
- **决策**：`readWorkbook` 改为 xlsx 包直读优先（`raw:false` 取显示值、`!merges`/`!cols` 透传、行列键统一 0-based），officecli 降为兜底；预览截断（5000 行×120 列×30 表）并显式提示；保留 x-data-spreadsheet 在线编辑（保存 A1 引用按 0-based 换算）。
- **后果**：数据显示保真、大文件可控；编辑保存的值是"显示文本"，复杂格式回写仍有损（已知限制，路线图跟踪）。

## ADR-009 Word 预览：docx-preview + 二次分页 + 缓冲缓存 + 字体回退
- **状态**：已采纳（2026-10-20 增强）
- **决策**：docx-preview 渲染（保留 lastRenderedPageBreak）+ `repaginateDocx` 按 A4 二次分页；docx 二进制 LRU 缓存（3×25MB，页签切换免下载）；文档声明但本机缺失的中文字体注入回退链（已安装字体不干预）；表格默认边框兜底。
- **后果**：长文不再压成超长纸、切换页签秒开、缺失字体观感稳定；分页精确度受 docx-preview 能力上限约束。

## ADR-010 工具审批三值模型 + 超时拒绝
- **状态**：已采纳
- **决策**：写操作审批 allow（一次）/ always（总是，可撤销）/ deny；作用域规则持久化；5 分钟无响应视为拒绝（比 ask_user 更保守）；审批模式 ask/auto 全局切换（auto 不覆盖显式 deny）。
- **后果**：写操作有明确人审闸门；"总是允许"规则可随时撤销（`DELETE /api/agent/permissions/rule`）。

## ADR-011 GIS 能力按模式分级
- **状态**：已采纳
- **决策**：Chat 只读（查询/临时可视化，不落盘）；Work 可写（map_edit/map_import/save，写操作审批）；Office/Review 不暴露地图工具。空间分析（buffer/spatial_filter/bbox_clip）为真实几何、平面近似口径，flag 门控。
- **后果**：权限边界清晰；"声明了却调不到"被 toolPolicyForMode 与能力计划（planTaskCapabilities）双向对齐。

## ADR-012 会话恢复：LIVE Run 探测 + 起点回放
- **状态**：已采纳（flag：OAW_REPLAY_RECOVER）
- **背景**：刷新后冷启动"不自动恢复"与 Run 仍在服务端执行矛盾，导致空白会话与跨轮 token 拼接。
- **决策**：F1 冷启动 listRuns 探测 LIVE Run；F3 首连从 Run 起点整段回放（上限 4000）；F4 水合锚点加 runId 归属校验；恢复的用户回答经 queued 通道在下一次 prompt 注入。
- **后果**：刷新/重连后上下文完整；回放窗口与事件淘汰策略需要持续对齐。

## ADR-013 P10 画布整合：单容器双页签
- **状态**：已采纳
- **决策**：预览与内置浏览器合并为单一 app-canvas-slot（「工作产物/浏览器」页签，proma 式）；页签体 CSS 显隐不卸载（状态零丢失）；浮动重复入口删除；开关语义不变。
- **后果**：右侧栏心智统一；样式接管规则集中在 styles.css 画布块。

## ADR-014 预览文件身份防串
- **状态**：已采纳
- **决策**：预览响应带 identity（工作区+revision），前端校验不匹配即拒绝渲染（防同名跨工作区串内容）；docx 原始流读取同样走身份头校验。
- **后果**：多工作区同名文件安全；identity 变更触发重新拉取。

## ADR-015 产物 staged→published + 回滚
- **状态**：已采纳
- **决策**：写入经写入清单（`.oaw/runs/<id>/写入清单.json`）跟踪；暂存产物运行中即可见（stagedVisible）；run_finished 时发布；产物 diff 记录 before/after（可逆标记），支持按 Run 回滚。
- **后果**：交付可审计、可撤销；`.oaw/` 不入 Git。

## ADR-016 Chat/Work/Review 模块样式冻结
- **状态**：生效中（2026-10-16 起，用户指令）
- **决策**：三个模块的既有 UI 表现（图标位置/样式/动画/配色）冻结；所有优化基于现有架构增量迭代，禁止全量重构；styles.css 动效闸门区内只允许 `oaw-*` 纳管关键帧。
- **后果**：交互类改动只能"行为增强、样式不动"（如行内引用徽章=镜像层画底色）；新视觉层走 opt-in（qoderStyle）。
