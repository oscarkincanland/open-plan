## 2. 发现清单

### P0-1 正式服务版本落后，模板 API 不存在（当前直接症状）

- `npm run service:status`：`listening=true, healthy=false, expectedVersion=0.13.25, runningVersion=0.13.24`，服务启动于 2026-11-09。
- `GET http://127.0.0.1:3002/api/canvas/templates` 返回：`{"ok":false,"error":"画布不存在或缺少 project/canvas.json：templates","code":"CANVAS_NOT_FOUND"}`——旧服务没有模板字面量路由，请求落到了 `/api/canvas/:slug`。
- 临时实例 3137（当前代码）同一请求返回 4 条内置模板，可正常新建/另存/实例化。
- 客户端把模板列表失败**静默置空**（`创作画布.jsx:484-490`），所以界面表现为“没有模板概念”，没有任何错误提示，掩盖了服务版本问题。

### P0-2 模板实现未提交，只存在于工作树

- `git status` 显示 `server/创作画布.mjs`、`client/src/components/创作画布.jsx`、`server/index.mjs`、`client/src/api.js`、`package.json` 修改，`scripts/创作画布模板测试.mjs` 未跟踪。
- 任何重新检出/清理/他人接手都会丢失这版模板能力；同时工作树还混有技能依赖、工作区体验等其它未提交改动，提交时需要按意图拆分。

### P1-1 HTML 板不进模板（与“HTML 汇报材料”目标直接冲突）

- 导入模板：`server/创作画布.mjs:1319-1320` 跳过 `boardKindOf(...)==="html"`；全部是 HTML 时抛 `CANVAS_INVALID: 导入来源没有可复制的画板文件`（实测命中）。
- 另存为模板：`server/创作画布.mjs:1387-1388` 同样跳过 HTML；若画布同时含对象板与 HTML 板，**HTML 板被静默丢弃且无 warning**，用户以为整套版式都存了。
- 函数注释 `:1278` 写的是“html/svg 兼容板与 assets 原样复制”，与实现不一致。
- 影响：用户现有的 `.dc.html`/claude-design 汇报画布（仓库 `designs/open-plan-deck` 就是 14 块 `.dc.html`）无法作为模板导入；而“HTML 汇报材料”正是用户声明的两大用途之一。

### P1-2 内置 deck 模板只有一页封面，不是 PPT 骨架

- `server/创作画布.mjs:1119-1129`：`deck` 模板只生成 `boards/cover.board.json` 一块板；`pages` 只有“主页面”。
- 实测：`template=deck` 新建 → `boards=1`。用户期望的“PPT 模板”通常至少包含封面/目录/章节/内容/图表/结尾，现在等于“封面 + 空白”。

### P1-3 模板只能用于“新建画布”，已有画布无法套用

- 模板下拉只出现在无 slug 的空态表单（`创作画布.jsx:1899-1912`）；已有画布工具栏只有“存为模板”，没有“应用模板/从模板插入页”。
- 影响：做到一半想换版式、或给现有 deck 加一套模板页，只能新建再手工搬。

### P1-4 没有模板管理与预览

- 仅有“模板下拉 + 导入模板 + 存为模板”；服务端已有 `deleteCanvasTemplate`（`server/创作画布.mjs:1433`）与客户端 API（`api.js:527`），但**没有任何 UI 调用**，也没有重命名、标签、缩略图、预览。
- 模板列表项 `boards:null`（内置，`server/创作画布.mjs:1250`），下拉只有标题，用户无法判断模板长什么样、几页、尺寸。

### P1-5 导入形式单一，不符合“导入模板”的常见操作

- 只支持“手输当前工作区内含 `project/canvas.json` 的目录路径”（`创作画布.jsx:1351-1363`，`askText`）。
- 不支持：系统目录选择器、`.zip` 模板包、外部目录（工作区外只读复制）、拖拽导入；没有导入前预览（板数/尺寸/类型/首板缩略图）；没有“导入后重名/覆盖”策略说明。

### P1-6 Agent 不支持模板

- `canvas_write` 的 `create_canvas` 没有 `templateSlug` 参数（`server/agent.mjs` 画布工具参数里 `template` 只用于 `add_board`，可选 blank/cover/onepager）；没有列模板/导入模板/套用模板的工具。
- 影响：用户对 Agent 说“用‘汇报模板’新建一份 PPT”时，Agent 只能从空板开始或自己画，无法复用模板库。

### P1-7 模板列表失败无提示

- `创作画布.jsx:484-490` 捕获异常后 `set模板列表([])`，不提示原因。服务旧版/工作区无权限/接口 500 时，用户只看到“没有模板”，无法定位。

### P2-1 页筛选只过滤缩略条，主画布仍显示全部页

- `显示板列表` 按当前页过滤（`创作画布.jsx:435-438`），但主画布渲染用 `可见板 = 视野内板(板列表, ...)`（`:665`），用的是全量 `板列表`；`适配窗口` 也用全量（`:652-655`）。
- 结果：选中某一页后，缩略条只剩该页，但画布上仍能看到其它页的画板；点“适配窗口”会把所有页一起缩进视口。页筛选语义前后不一致。

### P2-2 增量刷新出现整屏 spinner 闪烁

- `载入画布列表` 一开始就 `set加载态("加载中")`（`:471-478`），而它在 `载入画布` 成功后（`:516`）和每次刷新令牌变化（`:631`）都会被调用；渲染层 `加载态==="加载中"` 直接整屏 return spinner（`:1853`）。
- 结果：打开画布、Agent 每写一次、手动刷新都会短暂整屏“正在加载创作画布…”，与“板级增量刷新”的设计意图相悖。

### P2-3 注释/文档与实现不一致

- `server/创作画布.mjs:1278` 注释称 HTML 原样复制，实际跳过（见 P1-1）；同类注释还有 `:1374` 附近“assets 与兼容板原样复制”。
- 模板列表内置项 `boards:null`、无缩略图字段，前端无法展示规模（见 P1-4）。

### P2-4 其它小问题

- `新建类型` 下拉在选内置 cover/onepager 时仍可切换，但实际版式由模板决定，禁用逻辑只覆盖 `builtin:deck` 与用户模板（`:1899`），交互语义不清晰。
- 内置模板固定写死 4 条（blank/cover/onepager/deck），`blank` 又被下拉隐藏（`:1907`），用户看到的“内置模板”实际只有 cover/onepager/deck 3 项，且都只有 1 块板。

## 4. 影响与优先级建议

1. **先收口**：提交现有模板实现 + 重启/对齐正式服务（0.13.25），让用户能看到当前模板能力；否则后续讨论都建立在“旧服务”上。
