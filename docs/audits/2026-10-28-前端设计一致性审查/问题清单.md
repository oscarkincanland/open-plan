# 前端设计一致性问题清单（审计）

> 状态：草案（审查结论，不含实施）
> 基线：v0.13.2 · 分支 `feature/zcode-harness-align` · 工作区存在未提交修改
> 更新：2026-10-28
> 审查对象：`client/src`（React 18 + Vite 5）与 `client/src/styles.css`
> 关联：[AGENTS.md](../../../AGENTS.md)、[DESIGN.md](../../../DESIGN.md)、[整改计划](../../plans/2026-10-28-005-前端设计一致性问题整改计划.md)

## 1. 审查范围与方法

本次只做审查，不修改代码。证据来源：

1. **静态阅读**：`App.jsx`、`Icon.jsx`、`theme.jsx`、`界面外观.js`、`Feedback.jsx`、`SettingsPanel.jsx`、`TemplateLibrary.jsx`、`KnowledgeBase.jsx`、`工作产物面板.jsx`、`任务中心.jsx`、`MapPanel.jsx`、`SessionSidebar.jsx`、`styles.css` 等。
2. **运行守护测试**（只读）：
   - `npm run test:design-tokens` → **失败**
   - `npm run test:motion` → **失败**
   - `npm run test:a11y` → 通过
   - `npm run test:component-spec` → 通过
   - `npm run test:icons` → 通过
3. **静态统计**：对 `styles.css` 统计字号、圆角、`z-index`、媒体查询；对 `client/src/**/*.jsx|js` 统计十六进制色值、`<div onClick>`、`window.prompt`、`title/aria-label`、纯文字按钮与图标尺寸。
4. **对比度复算**：按 WCAG 相对亮度公式对语义令牌与面板底色逐对计算。
5. **历史截图**：参考 `docs/图标审查截图/`、`docs/交互审查截图/` 中的既有截图，仅用于观感判断，不作为当前构建的像素证据。

**局限**：未启动浏览器做当前工作区的实机复验；历史截图与当前未提交改动可能不一致；未覆盖全部动态状态（流式、审批、子代理、地图绘制）；未做 WCAG AAA 审计。判断类结论已单独标注。

## 2. 结论摘要

- 共发现 **29 项**问题：**P1 9 项、P2 14 项、P3 6 项**，无 P0 阻断项（构建与多数守护测试可用）。
- 三条系统性根因：
  1. **视觉体系多源并存**：pi 暗色基线 + Qoder `data-oaw-style` 视觉层 + 7 套 `data-skin` 皮肤同时存在，而 DESIGN 只承认暗/亮主题与 Qoder 受控层。
  2. **令牌守护覆盖不全且棘轮已失守**：CSS 硬编码色值从 393 增至 405，且 JSX 内联色值 121 处完全不进入令牌测试。
  3. **交互基元缺失**：输入、确认、模态、图标名称提示、可点击容器的实现各写各的，原生弹窗与自定义弹窗并存，键盘可达性不一致。

## 3. 问题明细

> 级别定义：P1 = 违反强制规范或影响 CI/可用性，应优先修复；P2 = 明显不一致，影响观感与维护；P3 = 优化项。
> 类型：**实测** = 有命令或统计输出；**判断** = 基于代码与截图的审查判断。
