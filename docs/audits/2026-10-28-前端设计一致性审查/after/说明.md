## 采集方式

1. `node server/index.mjs`（`PORT=3202`，使用 `client/dist` 构建产物）。
2. Edge headless + CDP：
   - `Emulation.setDeviceMetricsOverride` 设置视口；
   - 写入 `localStorage.oaw_theme`（dark/light）与 `oaw_skin=default` 后整页刷新；
   - `Page.captureScreenshot` 保存 PNG。
3. 每个视口独立刷新，避免上一次窄屏的抽屉状态影响下一张。

## 文件矩阵

| 页面 | 主题 | 视口 |
|---|---|---|
| 首页（Chat 空态） | 暗色 / 亮色 | 1440 / 1024 / 781 / 768 / 560 |
| 首页三栏（展开“工作产物”画布） | 暗色 / 亮色 | 1440 |
| 设置页 | 暗色 | 1440 / 781 |

命名：`首页-{暗色|亮色}-{宽度}.png`、`首页三栏-{暗色|亮色}-1440.png`、`设置-暗色-{宽度}.png`。

## 复核结论

- 1440：侧栏 + 对话（+ 产物面板）排布正常，无横向滚动。
- 1024 / 781：侧栏收窄，对话列保底可读，发送键与顶栏操作可达。
- 768 / 560：侧栏与右栏抽屉化，输入区完整，无横向溢出。
- 暗/亮主题切换后状态色、边框、正文对比度无残留问题。
