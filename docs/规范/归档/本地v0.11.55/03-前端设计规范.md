## 2. 设计令牌（唯一数据源）

### 2.1 三层结构（2026-10-18 起）

后两层只允许引用上一层；新增颜色必须落到令牌层，**不得在规则里直写色值**。
由 `scripts/设计令牌一致性测试.mjs` 的「硬编码色值棘轮」守护：当前 **393 处 / 129 种，只允许下降**。

**第 1 层 · 基础色阶**（只声明取值，不带语义）

```
--op-gray-000 → --op-gray-900   共 13 阶
--op-blue-400 / --op-blue-500 / --op-blue-600
--op-green-500 / --op-red-500 / --op-amber-500
```

**第 2 层 · 语义令牌**（只引用基础色阶 / 前景透明度）

```
--body-bg  --panel-bg  --panel2-bg  --surface  --text  --muted  --dim
--border  --selected  --accent  --accent-hi  --success  --error  --warning
--user-bg  --user-fg        （成对声明；无障碍测试会校验配对）
```

**第 3 层 · 组件变量**（组件只消费本层）

```
--op-comp-chat-bg  --op-comp-toolcard-border
--op-comp-toolcard-pending  --op-comp-toolcard-success  --op-comp-toolcard-error
```

> 三层目前只存在于 **Qoder 视觉层（opt-in，默认关）**；默认主题仍使用既有配色。关闭时外观逐像素回到 pi-dark 基线。

### 2.2 默认主题现有取值（兼容基线）

```
--error: #c0392b    --success: #5c7a1f
--warning: #b7791f  --user-bg: #e6f0ee
```

主题切换：`ThemeProvider`（`theme.jsx`）→ `document.documentElement.setAttribute("data-theme", ...)`；localStorage key `oaw_theme`。

### 2.3 排版

- 正文：系统 sans 栈 —— `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif`。
- 代码/路径/参数/数字：等宽栈 —— `ui-monospace, 'Cascadia Code', 'Source Code Pro', Menlo, Consolas, monospace`。
- 基准字号 12px，行高 18px；正文文档行高 1.6。
- **待确认**：`--font-sans` / `--font-mono` 令牌尚未拆（会改 `body` 核心行），未批准前不得动。

### 2.4 间距、圆角、阴影

- 按钮圆角 3px，padding 2–8px；卡片圆角 3–4px。
- 间距只用 4 的倍数：4 / 8 / 12 / 16 / 24 / 32。
- 阴影只用于浮层与卡片分层，禁止给静态面板加阴影。
- 滚动条：8px 细滚动条、圆角、hover 高亮，随主题变量适配。

### 2.5 动效令牌

```
--dur-fast: 120ms   --dur-base: 200ms   --dur-slow: 320ms   --ease-out
```

- 只作用于 `transform` / `opacity`；**禁止**动画 `width/height/top/left`。
- 统一动效闸门：`data-reduce-motion` / `data-motion-level="off"`；关闭后呼吸点静止、信息不丢。
- `styles.css` 动效闸门区内只允许 `oaw-*` 纳管关键帧（`test:motion` 守护）。

## 3. 布局规则

```
┌ 左栏 SessionSidebar ┬ 中栏 DocViewer / 画布 ┬ 右栏 ChatPanel ┐
│ 文件 / 历史 / 技能   │ 预览 / 工作产物 / 浏览器 │ 对话 / 执行流 / 输入 │
└──────── Resizer ────┴──────── Resizer ──────┴──────────────────┘
```

- 三栏可拖拽（`Resizer`），宽度持久化；最小宽度必须保证主内容可用。
- 中间区多页签：**对话 / 工作产物 / 画布 / 工作流**；页签体 CSS 显隐不卸载（状态零丢失）。
- 知识库为全屏模式，与三栏办公布局互斥；模板库同理。
- 断点：只支持 **≥1280px** 桌面；窄屏（≤1280）不得出现横向滚动条与内容重叠（`test:a11y` 含窄屏用例）。
- 全局错误边界：组件渲染异常显示友好错误页，**不白屏**。
- 新增浮层必须复用既有浮层容器与层级，不自造 `z-index` 阶梯。

- 组件不得自行解释事件；一律消费 `运行展示投影.js` 的结果。

## 6. 交互设计准则

### 6.1 通用

- 所有可点击元素最小 **32×32px**；键盘可完成主流程（Tab 顺序、Enter 提交、Esc 关闭）。
- 表单错误就近显示在字段下方，不只弹全局 toast。
- 危险操作（删除、覆盖、回滚）用 `--error`，并二次确认，写明后果。
- 提交中按钮禁用 + 防重复提交；长任务必须有可中断入口。
- 空状态不能只写"暂无数据"，要写下一步能做什么。
- 加载态必须有明确反馈，不能一片死白；超过 2s 的操作要有进度或阶段提示。

### 6.2 对话与引用

- `@` 引用在输入框内渲染为 **Trae 式行内徽章**：整块编辑（Backspace 一次删整块；块内打字先整块选中）。
- 引用徽章区间必须包含完整 `@` 字符与文件名，差一位整条不渲染。
- 发送后引用条**自动清空**（普通/排队/注入三条路径）；发送失败从文本重建引用。
- 手动删除引用文本记号时，引用状态必须同步移除。

### 6.3 HITL（提问与审批）

- `ask_user` 卡片：等待窗口 60 分钟；超时显示过期态并可"迟到回答"续跑；不出现 404 死卡片。
- 审批卡片：三值 `allow / always / deny`；5 分钟无响应视为拒绝；`always` 规则可在设置中撤销。
- `deny` 优先于自动批准；自动批准模式不得覆盖显式拒绝规则。
- 提问纪律在 UI 上体现为：同一轮最多 2 个问题，相关待定项合并为一题。

### 6.4 执行流与产物

- 执行流固定在对话顶部，可折叠/隐藏/恢复；思考块默认展开，固定 240px 独立滚动。
- 工具卡片状态只留左侧 3px 边条与状态图标（Qoder 层）；本体中性色。
- 产物运行中即可见（stagedVisible）；任务结束自动切「工作产物」页签；用户手动切页签后 10 秒内不打扰。
- 「有未完成项」横幅仅在 `incomplete/blockers` 清单非空时展示。
- 同 Run 多次结论按"状态最新优先、同态信息量优先"合并；结果卡必须显示实质结论，不被寒暄覆盖。

### 6.5 预览

- docx：分页、中文字体、表格线正常；页签来回切换 <2s（缓存命中）。
- xlsx：显示值正确（非序列号）、合并与列宽还原、0-based 无偏移；大表有截断提示。
- 预览必须校验 identity（cwd + revision），不匹配拒绝渲染。
- 三种状态齐全；CAD 未装 DWG 转换器时给出安装指引，不白屏。

## 7. 文案规范

- 按钮：动词开头，2–4 字。`保存` / `新建` / `导出` / `回滚`，不写孤立的 `确定`。
- 错误提示：**发生了什么 + 怎么办**。例：`导出失败，请缩小筛选范围后重试`。
- 文件占用：`目标文件正被其他程序占用，请先关闭 WPS/Word/Excel 或预览窗口后重试`。
- 空状态：`还没有工作产物。运行一次任务后，这里会显示本轮生成的文件。`
- 确认弹窗：只在不可逆操作时使用，写明后果与能否恢复。
- 全中文界面；技术术语保留原文时加中文解释（如 `Event Sourcing（事件即事实）`）。
- 不使用感叹号堆砌情绪，不写"智能、强大、一键搞定"这类空话。

## 8. 动效与无障碍

- 动效只用于状态变化与空间关系提示，不做装饰性循环动画（呼吸点除外）。
- 关闭动效后：页面不跳动、信息不丢失、状态仍可辨。
- 对比度：按主题变量实算 WCAG AA（`test:a11y` 守护，含 alpha 合成与用户气泡 4.5 断言）。
- 焦点可见：键盘 Tab 必须有清晰焦点环，不得用 `outline: none` 无替代。
- 图标按钮必须有 `aria-label` / `title`；纯图标操作要可被读屏识别。
- 窄屏（≤1280）不出现内容重叠或横向溢出。

## 9. 性能要求

- 流式渲染用 rAF 节流；token 增量不得触发整页重渲染。
- 长列表/长文档按需渲染或截断；新增列表必须有分页/虚拟化/上限策略之一。
- docx 二进制 LRU（3×25MB）；工作簿 LRU（6 本，mtime 失效）；Excel 首屏可只解析首个 sheet（`OAW_PREVIEW_LAZY_SHEETS`）。
- SSE 有界队列 + 背压 + 心跳；前端不得无限堆积事件。
- 图片/图表懒加载；Canvas 组件在不可见时暂停。
- 首字延迟改动必须附分段数据；不得凭感觉宣称"更快"。

## 10. 禁止清单（违反即返工）

1. **禁止修改 Chat / Work / Review 三个模块的现有 UI 表现**（图标位置/样式/动画/配色）；优化只能是"行为增强、样式不动"。新视觉层走 opt-in（`qoderStyle`）。
2. 禁止在组件/规则里写死颜色值、px 间距；新增令牌先加到令牌层。
3. 禁止新增 UI 组件库、图标库、CSS-in-JS。
4. 禁止用 emoji 或字母代替图标。
5. 禁止把 `hooks` 放在 `if (!open) return null` 之后。
6. 禁止在组件内直接 `fetch` 并自行拼装事件；走 `api.js` 与投影。
7. 禁止全量重构 `App.jsx` / `ChatPanel.jsx` / `styles.css`；只做增量。
8. 禁止为动效改布局尺寸（width/height/top/left）。
9. 禁止在冻结节区内新增关键帧（只允许 `oaw-*`）。
10. 禁止改 `body` 字体声明等外观核心行，除非 06 有新决策签字。

## 11. 前端验收清单（每次 UI 改动逐条过）

- [ ] 空 / 加载 / 错误 三态齐全
- [ ] 主路径可键盘完成；焦点可见
- [ ] 暗/亮主题均正常，对比度达标
- [ ] 关闭动效后信息不丢
- [ ] 1280px 窄屏无溢出/重叠
- [ ] 无新增硬编码色值（`test:design-tokens` 棘轮只降不升）
- [ ] 图标全部来自 `Icon.jsx`（`test:icons` 绿）
- [ ] 无冻结模块样式改动（diff 中 `styles.css` 冻结区零变更）
- [ ] 无控制台红色报错
- [ ] 对应交互守护测试绿（`test:motion` / `test:component-spec` / `test:a11y`）
