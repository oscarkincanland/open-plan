## 1. 技术选型（写清"为什么不是另一个"）

| 层 | 选型 | 为什么选它 | 放弃的替代方案 |
|---|---|---|---|
| 运行时 | Node.js ≥22 | 原生 `node:sqlite`、原生 test runner、ESM 稳定 | Node 18/20：缺少需要的原生能力 |
| 服务端 | Express 5（单服务，默认 `127.0.0.1:3002`） | 本地单机、路由简单、与 Pi SDK 进程内调用契合 | NestJS：重、启动慢；Fastify：迁移成本大于收益 |
| Agent 内核 | Pi Agent SDK（`@earendil-works/pi-coding-agent`，`package.json` 为 **1.3.0**） | SDK 已提供会话、模型、工具、流式能力，进程内调用延迟最低 | 自研 Agent 循环：重复造轮子且违背"不改内核"；独立 Agent 服务：跨进程事件转发复杂 |
| 前端 | React 18 + Vite 5（SPA） | 纯本地工作台，不需要 SSR/SEO；构建快 | Next.js：SSR 无收益，增加服务端复杂度 |
| 样式 | 单文件 `client/src/styles.css` + CSS 变量三层令牌 | 现有冻结模块与动效闸门都依赖这一结构；零构建链变更 | Tailwind/CSS-in-JS：会破坏令牌棘轮与样式冻结 |
| 文档处理 | officecli 外部二进制 + 原生 OOXML 直写（docx/pptxgenjs/xlsx） | 既有文档精确定位靠 CLI；生成类任务原生直写更快 | 全量纯 JS：编辑类能力不足；全量 CLI：冷启动慢 |
| Excel 读取 | `xlsx`（SheetJS）直读优先，officecli 兜底 | 显示值、合并单元格、列宽可保真，避免冷启动 | 仅 officecli：日期变序列号、偏移一格（已发生） |
| Word 预览 | `docx-preview` + 二次分页 + LRU 缓存 | 保真度高，支持批注/修订 | mammoth：样式还原不足 |
| PPT 预览 | `pptxviewjs`（Canvas） | 翻页/跳页稳定 | 转 PDF：需外部依赖 |
| 知识图谱 | `@antv/g6` v5 | 力导向图开箱可用 | 自绘 Canvas：成本高 |
| 地图 | maplibre-gl + 本地瓦片/GeoJSON | 离线可用、图层模型可控 | 在线地图 SDK：数据出本机、网络依赖 |
| 持久化 | 本地文件 + JSONL 事件流（无数据库服务） | 单机部署极简、可审计、可回放 | PostgreSQL/Redis：违反"不做数据库服务"约束 |
| 实时通道 | SSE（原生 EventSource） | 单向事件流足够；断线重连/游标回放成熟 | WebSocket：需要自管心跳与重连，收益低 |
| 测试 | Node 原生脚本（`scripts/*.mjs`）+ GitHub Actions | 与现有 70+ 脚本一致，零测试框架依赖 | Jest/Vitest：新增依赖，且现有脚本已覆盖 |
| 部署 | 本地单机 + `scripts/服务监督.mjs` 守护 | 用户即本机；桌面端壳 attach 同一服务 | Docker/K8s：本地办公场景过重 |

> **版本漂移提示**：历史文档中出现 Pi SDK `0.83.0` / `1.1.0`，`package.json` 实际为 `1.3.0`。以代码为准，升级需走 D-xxx 决策流程。

## 2. 分层架构（L0–L4）

设计意图：**L0 不动、L1 薄壳、L2 全部业务逻辑、L3 唯一事实通道、L4 只做投影。**

```
L4 前端（React SPA，client/src）
  App.jsx（页签/画布/路由） · ChatPanel（对话流） · DocViewer 家族（预览）
  MapPanel（GIS） · KnowledgeBase · SessionSidebar · SettingsPanel · 对象栏/工作流启动器
        ↑ SSE（事件协议 V2：游标/代际/心跳/背压）        ↓ REST /api/*
L3 流与事件层（server）
  流连接.mjs（连接预算/配额） · 事件协议.mjs · 事件存储.mjs（JSONL 落盘） · 事件注册表.mjs（130+ 类型）
L2 治理层（server，业务逻辑）
  agent.mjs（AgentManager：会话/Run/工具/HITL） · index.mjs（REST + admission + executeAgentRun）
  runs/写入协调/成果管理（产物生命周期） · 审批策略 · 运行预算 · 子代理编排器 · 编辑流水线
  task.mjs（模式与工具白名单） · 运行开关.mjs（flag 管道） · 工作流注册表/校验（领域 Harness）
L1 适配层（薄壳）
  office.mjs/officecli · Pi运行时管理.mjs · mcp管理.mjs · 内置浏览器.mjs（CDP）
  空间分析.mjs · 地图*（GIS 引擎） · kb.mjs（知识索引） · 文档引擎.mjs · CAD解析/修改.mjs
L0 Pi Agent SDK 内核（不改）
  createAgentSession / ModelRuntime / setThinkingLevel
```

### 2.1 依赖方向（箭头 = 可以引用）

```
L4 页面/组件  →  前端投影/开关  →  REST/SSE
                                     ↓
L3 事件层     →  L2 治理层      →  L1 适配层  →  L0 SDK
                                     ↓
                              本地文件系统 / officecli / 外部服务
```

**允许**：上层调下层；同层模块通过显式导出协作。
**禁止**：

- L1 适配层不得引用 L2/L4 业务代码；L2 不得 import `client/`。
- 业务模块不得绕过 `运行开关.mjs` 直读 `process.env`（唯一例外：启动期引导参数）。
- 前端不得自行解释事件语义；一律经 `运行展示投影.js` / `运行轨迹.mjs` 投影。
- 任何模块不得跨层直接引用其他模块内部文件；只走该模块公开导出。
- 不得修改 `node_modules` 内 Pi SDK 源码；扩展只走 `server/pi-extensions/` 或原生导出。

## 3. 目录地图与放置规则

### 3.1 根目录（只允许这些类型）

```
<项目根>/
├── AGENT.MD                 # 智能体唯一入口（硬规则/角色/权限）
├── README.md                # 给人看的简介（只保留一份）
├── .gitignore / .gitattributes
├── doc/项目规范化管理/       # 本规范体系（00-07 八份文档）
├── docs/                    # 设计/方案/验证报告 + plans/ 编号计划
├── server/                  # L1-L3 服务端模块（中文命名）
├── client/                  # 前端工程（src/ 下业务代码）
├── scripts/                 # 测试、构建、运维脚本（70+）
├── office-workspace/        # 用户工作区（受限入库：仅代码/模板，用户数据谨慎）
├── templates/               # 公文/报告模板
├── .oaw/                    # 运行数据（runs/events/pending-asks）——永不入库
├── .github/workflows/       # CI（16 步回归）
└── package.json / package-lock.json
```

**根目录卫生**：根目录每多一个文件，通常意味着它该归到 `server/`、`client/src/`、`scripts/`、`docs/` 或本体系。出现 `test1.js`、`backup/`、`old/`、`新建文件夹/`、一次性日志/媒体，一律视为待清理。

### 3.2 放置规则（新增文件时照查）

| 我要新增 | 放哪 | 禁止放哪 |
|---|---|---|
| 新页面/视图 | `client/src/components/<中文名>.jsx` 或 `client/src/App.jsx` 注册 | `client/` 根目录、`server/` |
| 只被一个组件用的子组件 | 该组件目录内 | 全局组件库 |
| 被 2 个以上视图复用的组件 | `client/src/components/` | 某个页面目录 |
| 前端状态投影 | `client/src/运行展示投影.js` / `运行轨迹.js` | 组件内临时拼装事件 |
| 前端只读开关 | `client/src/运行开关.js` | 组件内直读 `window.__FLAGS__` |
| 服务端业务逻辑 | `server/<中文模块>.mjs` | `server/index.mjs` 内堆业务 |
| REST 路由 | `server/index.mjs`（仅路由与 admission） | 新起 Express 实例 |
| Agent 工具实现 | `server/agent.mjs` 或独立 `server/<能力>.mjs` 后注册 | `client/` |
| 事件类型 | `server/事件注册表.mjs` 登记后再发 | 直接 `emit` 未登记类型 |
| 运行开关 | `server/运行开关.mjs` 统一登记 | 模块内直读 env |
| 测试/回归 | `scripts/<中文名>测试.mjs` | `server/` 内混放 |
| 设计/方案 | `docs/YYYY-MM-DD-主题.md` | 根目录 |
| 编号计划 | `docs/plans/YYYY-MM-DD-NNN-主题.md` | `docs/` 根散落 |
| 规范化文档 | `doc/项目规范化管理/` | `docs/`、根目录 |
| 临时验证脚本 | `scripts/临时-<用途>.mjs`，**当次会话删除** | 提交入库 |

### 3.3 命名规则

- **文档/脚本/服务端模块用中文**：`事件注册表.mjs`、`成果验收.mjs`。代码文件（`.jsx`/`.js`/`.mjs`）按语言惯例，但业务模块仍优先中文。
- 前端组件用大驼峰英文（`ChatPanel.jsx`、`Icon.jsx`）；纯投影/开关用中文小驼峰风格（`运行展示投影.js`）。
- 目录名英文小写（`client/`、`server/`、`scripts/`）；**不新增拼音缩写目录**。
- 单复数一旦确定不混用；禁止 `utils2`、`new`、`temp` 这类命名。

## 4. 模块边界与职责

### 4.1 服务端关键模块

| 模块 | 职责 | 对外暴露 | 禁止 |
|---|---|---|---|
| `agent.mjs` | Agent 会话/Run/工具/HITL 编排 | AgentManager、工具注册、Run 生命周期 | 不写 REST 路由、不直接写前端状态 |
| `index.mjs` | REST + admission + `executeAgentRun` | `/api/*`、SSE 端点 | 不堆业务规则（下沉到 L2 模块） |
| `task.mjs` | 模式与工具白名单、TaskEnvelope、能力计划 | `toolPolicyForMode`、`planTaskCapabilities`、`createTaskEnvelope` | 不做实际工具执行 |
| `运行开关.mjs` | flag 解析/默认值/只读快照 | `RUNTIME_FLAGS`、`readFlagWithDefault` | 业务模块不得绕过 |
| `事件注册表.mjs` | 事件类型登记（lifecycle/persist） | 类型常量、校验 | 未登记类型不得发送 |
| `事件协议.mjs` / `流连接.mjs` | SSE 信封、配额、背压、心跳、陈旧流 | 通道管理 API | 不解释业务语义 |
| `事件存储.mjs` | JSONL 落盘与读取 | append/list | 不做投影 |
| `运行轨迹.mjs` | 工具聚合、完成语义、`mergeCompletions` | `buildRunTrace` 等纯函数 | 不写 UI |
| `写入协调.mjs` / `成果管理.mjs` | 写入锁、快照、暂存/发布、回滚 | 写入清单 API | 不绕过审批写盘 |
| `审批策略.mjs` | allow/always/deny、作用域、超时 | 审批判定与规则 CRUD | 不直接弹 UI |
| `子代理编排器.mjs` | 角色解析、并发 fan-out、verifier 回环 | `SUBAGENT_ROLES`、`orchestrateSubagents` | 不直接 import Pi SDK |
| `内置浏览器.mjs` | CDP 会话、帧流、URL 防护 | `browser_*` 工具实现 | 不暴露任意本地文件访问 |
| `map*.mjs` / `空间分析.mjs` | 图层仓库、地图项目、空间算子 | 地图工具族 | 写操作必须走审批 |
| `office.mjs` / `officecli` | Office 文档受控操作 | `officecli` 工具 | 不做通用 shell |
| `kb.mjs` | 知识库索引/检索/图谱 | `kb_search` / `kb_read` | 不写用户文档 |

### 4.2 前端关键模块

| 模块 | 职责 | 约束 |
|---|---|---|
| `App.jsx` | 页签/画布/模式路由 | Chat/Work/Review 现有样式冻结，不重构布局 |
| `ChatPanel.jsx` | 对话流、输入区、引用、审批/提问卡 | 单文件已很大；新增逻辑优先抽投影/工具函数 |
| `运行展示投影.js` | Run 事件 → 视图对象 | 唯一投影入口，组件不得自行拼事件 |
| `运行开关.js` | 只读消费 `runtimeFlags` | 快照未达 = 全关 = 基线 |
| `DocViewer.jsx` + Viewer 家族 | 按 kind 分流预览 | 三种状态（空/加载/错误）必须齐全 |
| `MapPanel.jsx` / `MapViewer.jsx` | GIS 工作台 | 图层必须经 `图层注册表.js` 注册才显示 |
| `styles.css` | 全局样式 + 动效闸门 | 禁止直写色值；frozen 区只允许 `oaw-*` 关键帧 |
| `Icon.jsx` | 统一图标 | 禁止 emoji/字母图标；`test:icons` 守护 |

## 5. 数据模型（本地文件）

| 位置 | 内容 | 关键字段 | 生命周期 |
|---|---|---|---|
| `.oaw/runs/<runId>/` | 单次 Run 记录 | runId、status、threadId、mode、createdAt、写入清单 | 永久（本地），不入 Git |
| `.oaw/runs/<runId>/写入清单.json` | 产物清单 | path、status、writes、size、publishedAt、before/after | 随 Run |
| `.oaw/events/事件流.jsonl` | 全局事件流 | seq、type、runId、threadId、payload、ts | 按淘汰策略滚动 |
| `.oaw/pending-asks.json` | 待回答提问 | askId、runId、question、createdAt、expiresAt | 回答/超时后清理 |
| `office-workspace/` | 用户文件 | 文件树 | 用户所有 |
| `office-workspace/maps/<project>/` | 地图项目 | `map.config.json`、`style.json`、`layers/*.geojson`、`tiles/` | 用户所有，改动需评审 |
| `memory/` | Agent 长期记忆 | 记忆条目 + 确认状态 | 用户确认后写入 |
| `templates/` | 公文/报告模板 | 模板文件 + 元数据 | 随版本 |

**数据规则**：

- `.oaw/`、`运行日志/`、`dist/`、`node_modules/` **永不入库**。
- 事件是唯一事实来源；任何前端状态都应可由事件流重建。
- 产物写入必须经 `写入协调` + 写入清单；删除/覆盖要留 before/after。
- 用户工作区数据（尤其 `maps/`）不得与代码改动混在同一次提交。

## 6. 外部集成

| 服务/依赖 | 用途 | 凭证 | 失败时的降级 |
|---|---|---|---|
| Pi Agent SDK | 模型会话与工具调用 | 模型供应商 key（`.env` / 设置面板） | 连接失败重试；会话保持；前端提示可切换模型 |

| MCP 服务 | 外部工具桥接 | 各服务自身配置 | 未配置则不声明能力 |
| 高德 MCP（G3） | 地理编码/POI | 环境变量 | 关闭开关，地图基础能力不受影响 |
| 内置浏览器（CDP） | 网页查阅/出图 | 无 | 提示浏览器不可用，不影响主链路 |
| DWG 转换器（ODA/LibreDWG） | DWG ↔ DXF | `OAW_DWG_CONVERTER` | 未安装则降级 DXF 另存并提示 |

## 7. 关键流程

### 7.1 一次 Work 任务（主链路）

1. 前端 `POST /api/agent/prompt`（text / 引用 / 附件）。
2. `index.mjs` admission：模式策略 + TaskEnvelope + 能力计划 + 建 Run。
3. `executeAgentRun` → `promptWithContext` → 排队链 → 压缩检查 → 动态上下文注入。
4. Pi SDK 流式返回思考/文本/工具调用；工具执行（officecli / bash / map_edit…）。
5. 事件规范化 → 注册表校验 → SSE 广播；`persist:true` 写 JSONL。
6. HITL：`ask_user` 阻塞等待（60 分钟）或工具审批（5 分钟超时视为拒绝）。
7. `complete_task`：`mergeCompletions` 合并结论 → `run_finished`。
8. 写入协调：`waitForFlush` → diff → staged → `publishPaths` → 写入清单。
9. 前端结果卡/产物页签自动切换；用户可回滚。

**失败点**：admission 拒绝（模式越权）、模型连接失败、工具审批拒绝、写入冲突、事件通道配额满。每处都必须有可读错误与降级路径。

### 7.2 预览链路

`打开文件 → GET /api/doc/:name?cwd= → kind 分流 → 预览响应带 identity（cwd+revision）→ 前端校验 identity → 渲染`。

- docx：`docx-preview` + `repaginateDocx` + LRU（3×25MB）+ 字体回退。
- xlsx：SheetJS 直读（显示值/合并/列宽/0-based/截断）→ officecli 兜底；保存走 `/api/doc/:name/cells`。
- pptx：Canvas 翻页；pdf：iframe；md/txt/csv/json：`MarkdownBody`。

### 7.3 GIS 链路

`map_read/map_datasets → map_analyze（临时层） → （Work）map_edit/map_import → 审批 → 图层仓库写盘 → style.json 注册 → 图层面板可见`。

- 图层写 `style.json` 但未在 `config.layers` 注册 → 面板不可见（已踩坑）。
- 项目重置/版本回溯必须原子写 + 最后好样式缓存。

### 7.4 会话恢复

冷启动探测 LIVE Run → 首连从 Run 起点回放（上限 4000 事件）→ 水合锚点校验 runId → queued 回答在下一次 prompt 注入。开关 `OAW_REPLAY_RECOVER` 门控。

## 8. 已知技术债（诚实记录，禁止"顺手"修）

| 位置 | 问题 | 影响 | 处理时机 |
|---|---|---|---|
| `server/agent.mjs`（约 300KB）/ `server/index.mjs`（约 300KB） | 单文件过大，职责密集 | 改动风险高、评审困难 | 排期分批拆分（C 阶段），不与新功能同轮 |
| `client/src/components/ChatPanel.jsx` | 超长组件 | 交互改动易回归 | 只做增量，优先抽投影/纯函数 |
| 40+ feature flag | flag 债 | 分支组合多、测试矩阵膨胀 | 按 P3-d 分批并入主路径或删除 |
| 冷启动 ~100s | 根因未定位（疑 runs/事件增长 + Pi 初始化） | 启动体验差 | P4-a 专项 |
| Excel 编辑回写 | 回写显示文本，复杂格式有损 | 格式丢失 | 待决策（06 文档待定项） |
| 双套鉴权/身份概念（如历史文档所述） | 语义漂移风险 | 权限边界 | 需先核对当前代码，再决定是否收敛 |
