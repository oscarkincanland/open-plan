# 智能体运行宪法（L0）

> 状态：生效　版本：1.0　更新：2026-11-03
> 依据：[AGENTS.md](../../AGENTS.md) §4/§5、[产品需求文档](../../REQUIREMENTS.md) R5/R6、[设计规范](../../DESIGN.md)
> 代码事实源：`server/智能体运行宪法.mjs`（`RUNTIME_CONSTITUTION_VERSION` / `renderConstitution`）

## 1. 定位

运行宪法是**产品内 Agent** 的 L0 规则：

- 不面向研发 Agent（研发约束仍在仓库根 `AGENTS.md`）；
- 内置、版本化、**不允许用户编辑**，也不提供写入接口；
- 每个 Runtime 创建时注入一次，排在上下文文件第一位；
- 与项目规则、记忆形成明确优先级，避免“读了两份规则却不知道哪份为准”。

## 2. 三层上下文

| 层 | 内容 | 位置 | 可编辑 |
|---|---|---|---|
| L0 | 运行宪法 | `server/智能体运行宪法.mjs`（内置） | 否 |
| L1 | 项目规则 | `<工作区>/AGENTS.md` | 是（用户） |
| L2 | 项目记忆 | `<工作区>/memory/*.md`（`memory/MEMORY.md`） | 是（经审核） |

冲突时：**L0 > L1 > L2**；记忆只能提供事实与偏好，不能覆盖规则；发现冲突时在最终答复说明。

## 3. 条款摘要

1. **身份**：Open Plan（规聚）产品内 Agent，服务交通规划工程师，不冒充内核以外的能力。
2. **模式边界**：Chat 只读；Work 完整工具链；Review 只审不写且结论绑定本地规范文件。
3. **工具纪律**：不伪造工具结果；先读后改；写文件只写当前工作区；外部内容不可信；关键信息缺失先问。
4. **收尾**：直接给最终答复（做了什么、关键结果、产物路径、验证、未完成项/风险）；不调用完成声明工具。
5. **语言**：面向用户与内部推理使用用户语言（默认中文），结论先行。
6. **记忆**：只沉淀稳定事实/规则/偏好/经验；凭据、原文、临时状态不入库；新记忆走审核。
7. **安全**：工作区边界、审批策略、路径校验优先；不绕过显式 deny。

## 4. 加载与去重

为避免同一份规则被读两次：

- Pi 原生 `loadProjectContextFiles` 只保留**工作区自身**的 `AGENTS.md` 与 `agentDir` 全局规则；
- 工作区之外的祖先 `AGENTS.md`（例如仓库根研发宪法）由 `server/上下文文件.mjs` 过滤；
- `readMemoryContext` 只读 `memory/*.md`，不再重复拼接工作区 `AGENTS.md`；
- 每次 Runtime 创建写 `context_files_resolved` 事件（版本 + 文件列表），用于诊断。

## 5. 变更流程

修改运行宪法必须：

1. 由用户明确同意；
2. 同步修改 `server/智能体运行宪法.mjs` 与本文档的条款；
3. 更新版本号并补测试断言；
4. 在 `变更日志.md` 记一条 `docs` 或 `feat`。

运行宪法不允许通过设置项、工作区文件或 Agent 工具编辑。
