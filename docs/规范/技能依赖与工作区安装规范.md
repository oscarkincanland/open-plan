## 1. 目的与范围

本规范约束本地技能（SKILL.md）如何声明运行时依赖、产品如何只读预检、以及依赖如何以工作区隔离方式安装与清理。

只约束依赖治理；不改变技能的方法论内容、不定义新的 Agent 工具、不改变 Office 生成链路与审批策略。

不做的事：

- 不允许系统级 `pip/npm` 安装，不允许写用户 home、系统目录或项目目录；
- 不允许 Agent 在 Run 内自行执行安装命令；
- 不新增任何可被模型调用的安装工具；
- 不在代码中硬编码第三方镜像源。

## 2. 依赖声明（SKILL.md frontmatter）

技能在 frontmatter 中声明 `requires`，示例：

```yaml
---
name: ultimate-ppt-master
description: >-
  终极融合 PPT 大师 …
requires:
  runtime: [{ kind: python, version: ">=3.10" }]   # 或 node >= 20
  python: [python-pptx, cairosvg, PyMuPDF]
  npm: []                                          # 例：pptxgenjs
  exec: [python]                                   # 需要可执行的解释器/二进制
  network: true
  platform: [win32, darwin, linux]
install:
  python: requirements.txt                         # 仅提示，不自动执行
  npm: package.json
---
```

| 字段 | 必填 | 含义 | 缺失/非法时 |
|---|---|---|---|
| `runtime` | 否 | 解释器种类与最低版本（`python`/`node`） | 记为 `degraded`，不阻塞技能读取 |
| `python` | 否 | Python 包名列表 | 记为 `degraded` |
| `npm` | 否 | npm 包名列表 | 记为 `degraded` |
| `exec` | 否 | 需要的可执行文件（如 `python`） | 记为 `degraded` |
| `network` | 否 | 是否依赖联网 | 缺省按 `false` 处理 |
| `platform` | 否 | 支持平台（`win32/darwin/linux`） | 当前平台不在列表时记 `blocked` |
| `install` | 否 | 依赖清单文件提示，仅展示、不自动执行 | 不视为错误 |

- 解析失败不阻塞技能读取，按 `degraded` 展示，并保留原始 frontmatter 摘要供诊断。
- `requires` 未声明时状态为 `blocked`，并提示"技能未声明依赖，无法自动判断可用性"。
- `description` 支持 `>`、`|`、`>-` 等块标量；解析失败回退正文前 200 字。

## 3. 目录布局与隔离

```text
<workspace>/.oaw/skill-deps/
├─ manifest.json                 # 安装台账：技能名/版本/来源/sha256/时间/解释器路径/包列表
└─ <skill-name>/
   ├─ .venv/                     # Windows: .venv/Scripts/python.exe；POSIX: .venv/bin/python
   ├─ node_modules/              # npm 安装（--ignore-scripts）
   └─ requirements.lock          # 实际解析版本（pip freeze）
```

- 安装根目录固定为 `<workspace>/.oaw/skill-deps/`，随工作区隔离；切换工作区不共享已装依赖。
- **禁止**写系统 Python、全局 npm、用户 home 与项目目录（含 `skills/`、`server/`、`client/`）。
- `manifest.json` 记录每个技能的安装来源、版本与锁文件 sha256，供审计与清理；不得记录密钥、Token 或用户文档内容。
- 同一技能同一时刻只允许一个安装 job；安装期间状态为 `installing`。

## 4. 状态与只读预检

| 状态 | 含义 | 展示与行为 |
|---|---|---|
| `ready` | 解释器与包齐备 | 允许按 SKILL.md 执行；`skills_read` 附 `<skill_requires status="ready">` |
| `degraded` | 部分依赖缺失或声明不完整 | 允许读取技能，提示缺失项与可选安装；不阻塞主任务 |
| `blocked` | 平台不支持、运行时缺失或未声明 | 不执行技能脚本，给出替代方案（`editorial_pipeline`、officecli、内置能力） |
| `installing` | 安装 job 进行中 | 禁用重复安装，展示进度与取消入口 |

- 预检是**只读**的：`where/which`、检查 `.venv` 解释器、`python -c "import x"`、`node -e "require.resolve"`；不联网、不安装、不修改文件。
- `skills_read` 结果附加 `<skill_requires status=...>`；`/api/skills` 增加 `requires/depsStatus` 等 additive 字段。
- 预检失败必须有稳定错误码与人话原因，不允许静默把 `blocked` 当 `ready`。

## 5. 安装流程（仅 UI 触发）

```text
技能广场/设置显示依赖状态（ready / degraded / blocked / installing）
  ↓ 用户点击「安装到当前工作区（需确认）」
  ↓ 二次确认：目标目录 + 包清单 + 预计来源 + 不写系统目录
  ↓ POST /api/skills/:name/deps/install {confirm:true}
  ↓ 后台 job：创建 venv → pip install（逐包，失败重试≤1，120s 超时，超时转后台并返回 jobId）
  ↓ 进度事件（字节/包/状态）→ UI 可取消
  ↓ 完成：写 manifest + 复检 → 状态变 ready
  ↓ 失败：记录原因（网络/SSL/解析/平台），给出替代方案（editorial_pipeline 等）
```

- 二次确认必须展示：目标目录（工作区内）、包清单、包来源、预计耗时与"不写系统目录"承诺。
- Python：`python -m venv <dir>/.venv` + `pip install --no-input`（默认官方源，失败提示可配置镜像）。
- npm：`npm install --prefix <dir> --ignore-scripts`。
- 安装 job 复用后台任务机制：有 jobId、进度、超时、取消；同技能并发只允许 1 个。
- 安装完成后必须复检并把结果写回 `manifest.json`；失败不得把状态改成 `ready`。

## 6. Agent 侧硬规则（提示词 + 闸门双层）

1. Agent **不得**自行执行 `pip/pip3/uv/conda/npm/pnpm/yarn/apt/brew/winget/choco/git clone`；尝试即返回结构化错误并提示"请用户到技能广场安装"。
2. 只允许使用已 `ready` 的依赖；`blocked` 时改用产品能力（`editorial_pipeline`、officecli、内置 ECharts、地图工具）。
3. 安装命令不进入模型工具循环：仅 UI 触发的 server job 执行，Agent 通过 `skill_preflight` 感知状态。
4. 镜像：默认不配置；用户可在设置填写镜像源；不在代码硬编码第三方镜像。
5. 卸载：设置中"清理依赖"→ 删除目录 + manifest 记录（需确认；不删除用户文档）。

## 7. 错误码

| code | 场景 | 提示 |
|---|---|---|
| `SKILL_DEP_RUNTIME_MISSING` | 无 Python/Node 或版本过低 | "需要 Python ≥3.10（当前未安装）；可改用工具体内能力或在此安装" |
| `SKILL_DEP_PACKAGE_MISSING` | 包缺失 | "缺少 N 个包；点击安装（工作区隔离）" |
| `SKILL_DEP_PLATFORM_UNSUPPORTED` | 仅支持其他平台 | "该技能仅支持 macOS/Linux；当前 Windows 不建议使用" |
| `SKILL_DEP_NETWORK_BLOCKED` | SSL/代理导致不可达 | "网络不可达（SSL）；可配置镜像或改用内置能力" |
| `SKILL_DEP_INSTALL_TIMEOUT` | 安装超时 | "安装超时已转后台（jobId），可在任务中心查看" |
| `SKILL_DEP_INSTALL_DENIED` | 未确认安装 | "未获用户确认，已停止安装" |

## 8. 安全边界

- 所有路径必须校验在工作区 `.oaw/skill-deps/` 内，拒绝路径穿越与符号链接逃逸。
- 不接受任意命令字符串；只允许受控的 venv/pip/npm 调用，`--ignore-scripts` 必须开启。
- 安装过程不读取、不上传用户文档与工作区其它文件；网络访问仅发生在用户确认的安装 job 内。
- 安装来源与版本写入 manifest，可审计；清理依赖不得删除用户文档。
- 事件 `skill_dep_install`、`skill_preflight` 等不得包含密钥、Token 或用户文档内容。

## 9. 迁移与回滚

- 迁移：无强制数据迁移；未声明 `requires` 的既有技能按 `blocked` 展示，用户按需补声明。
- 回滚：运行时开关 `OAW_SKILL_DEPS=0` 关闭预检/安装，技能回到只读状态；删除 `.oaw/skill-deps/` 清除已装依赖。
- 兼容：`/api/skills` 只增字段；旧技能读取路径不变；`settings.skillDeps.enabled` 只是开关载体，**自动安装永远关闭**。
