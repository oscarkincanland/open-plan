## 2. 关键实现

- `server/map.mjs`
  - `MAP_SCHEMA_VERSION=2`；`normalizeConfig` 迁移历史 config；`writeConfig/writeStyle` 原子写 + `.bak`。
  - `map.baseline.json`：`getBaseline/setBaseline/applyBaseline`，支持 `{keepExtra}`。
  - `listLayerRegistry`：config 图层 + 磁盘要素数/bbox + 基线标记；`updateLayerMeta`、`logOperation/listOperations`。
  - `resetProject(name, level)`：tree / temp / baseline；快照写 `.trash/{timestamp}-reset-*`。
  - `deleteLayer/replaceLayer`：数据与瓦片移入 `.trash`，不物理删除。
  - `createProject({kind:"blank"})`：只含底图样式、空图层与空基线。
- `server/index.mjs`：注册表 / 元数据 / 导出 / 替换 / 基线 / 重置 / 操作日志路由；创建项目透传 `kind/description`。
- `server/agent.mjs` + `server/task.mjs` + `server/审批策略.mjs`：新增三个工具与白名单/审批；`map_edit`/`map_import` 拒绝锁定图层。
- `server/运行开关.mjs`：`readFlagDefault(name, true)`；五项 GIS 交付能力默认开，`OAW_MAP_*=0` 关闭。
- 前端：`重置对话框.jsx`、`图层属性对话框.jsx`、`临时层转正对话框.jsx`、`AI画布向导.jsx`、`client/src/地图/CSV解析.js`；`MapPanel/MapViewer/LayerPanel/可视面板` 增量接入。

HTTP 联调（3002 现有服务）：

- `POST /api/map/projects {kind:"blank"}` → 注册表 `layers=0/features=0/baselineAt` 已写。
- 导入 1 点 → `layers=1/features=1/addedAfterBaseline=1`。
- `PATCH` 名称/锁定/透明度 → 生效。
- `POST replace` → `features=1`，旧数据进 `.trash/...-replace-probe-point`。
- `reset.tree` → `restored=1`；`reset.baseline` → `removed=1`。
- `POST export`（zhejiang-map/boundary-city）→ `FeatureCollection` 11 个要素。
