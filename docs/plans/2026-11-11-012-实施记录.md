## 1. 交付内容

| 功能 | 结论 |
|---|---|
| F1 项目切换 | `handleMapAction` 对 `project_created` 特判先于跨项目守卫：重拉项目列表 → 列表确认新项目入列 → `setProject` 切换；`switch_project` 走既有 `changeProject` 切换链 |
| F2 地图写工具活动跟踪 | App 全局事件流按 `MAP_WRITE_TOOLS`（9 个地图写工具）驱动 `mapActivity`（project → {active, tool, threadId}）；project 取工具入参，缺省回退 `mapContextsRef` 的会话绑定项目 |
| F3 pill 优先级与点击分支 | `mapActiveCanvas` 改名 `mapActiveTarget`：地图项目态优先（文案"Agent 正在编辑地图项目《X》· 工具名"，点击 `switch_project` 就地切换、不退出地图）；创作画布态其次（原行为不变：退出地图 + 打开画布） |
| F4 Run 终态收口 | `run_finished`/`agent_error`/`run_recovered` 按 threadId 权威清理 `mapActivity`，pill 结束即消失、不残留 |
| F5 会话跟随刷新兜底 | 目标项目不在列表时重拉一次项目列表（`followRefreshRef` 防循环，到达目标复位），覆盖新建项目后切回历史会话/服务重启恢复场景 |
