## 1. 目标与范围

把 GIS 从“地图面板 + 工具集”升级为“**每个项目 = 一个 QGIS 式工程**”：

1. 项目工程化（元数据、基线、操作日志、备份）。
2. 图层分层（底图 / 正式 / 临时）与临时层清单、转正。
3. 一键重置（图层树 / 临时层 / 恢复基线）。
4. AI 画布（空白工程 + 会话绑定 + Agent 从零做图，单活动画布）。
5. 能力补齐（SHP/CSV 导入、M2 两项界面、交付能力默认体验）。

范围只增不减：现有 R10 能力与 G1–G12 已交付项全部保留（对照见 PRD §11）。

## 3. 总体技术方案

### 3.1 数据模型

`map.config.json` 升级 `schemaVersion: 2`（旧字段只增不改）：

```json
{
  "schemaVersion": 2,
  "project": "yiwu-ai",
  "name": "义乌 AI 画布",
  "description": "",
  "archived": false,
  "baseProject": "zhejiang-map",
  "crs": "EPSG:4326",
  "basemap": "gaode-road",
  "center": [120.07, 29.31],
  "zoom": 10,
  "groups": [{ "name": "行政区划", "collapsed": false }],
  "sharedLayers": [],
  "layers": [{
    "id": "boundary-city",
    "name": "地市边界",
    "type": "boundary",
    "group": "行政区划",
    "visible": true,
    "opacity": 1,
    "minzoom": 5,
    "maxzoom": 13,
    "origin": "shared",
    "owner": "",
    "locked": false,
    "source": { "kind": "builtin|import|agent|analysis", "path": "layers/x.geojson", "format": "geojson|shp|csv", "importedAt": "..." },
    "stats": { "features": 128, "bbox": [118, 27, 123, 31] },
    "createdAt": "...",
    "updatedAt": "..."
  }],
  "bookmarks": [],
  "updatedAt": "..."
}
```

- **基线**：`maps/{project}/map.baseline.json`，保存 `layers` 的顺序/分组/显隐/透明度/锁定/样式覆盖与 `groups`；项目创建与“设为基线”时写入。
- **操作日志**：`maps/{project}/operations.jsonl`，追加写，字段 `{ts, actor:"user|agent", action, layerId, before, after, runId}`；不写文档内容与密钥。
- **回收站**：图层删除与“恢复基线”产生的移除统一移入 `maps/{project}/.trash/{timestamp}/`，可手工恢复。
- **临时层契约**：前端 `client/src/地图/临时图层模型.js` 维护 `{id, project, kind, title, source, featureCount, visible, createdAt, persistable}`；不写盘，不进 `config`。

### 3.2 API 增量（只增不改）

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/map/project/:name/layers` | 图层注册表（含 stats/locked/origin/时间） |
| PATCH | `/api/map/project/:name/layer/:layerId` | 改名/改组/透明度/锁定 |
| POST | `/api/map/project/:name/layer/:layerId/export` | 导出单层 GeoJSON |
| POST | `/api/map/project/:name/layer/:layerId/replace` | 替换数据（备份+确认） |
| POST | `/api/map/project/:name/reset` | `{level:"tree"\|"temp"\|"baseline"}` |
| GET/POST | `/api/map/project/:name/baseline` | 读取/设为基线 |
| GET | `/api/map/project/:name/operations` | 操作日志查询 |
| POST | `/api/map/project/:name/import-shp` | SHP（zip 或 base64 `.shp+.dbf`） |
| POST | `/api/map/project/:name/import-csv` | CSV 点表（经纬度列识别） |
| POST | `/api/map/projects`（扩展） | `{kind:"blank"\|"copy"\|"template", inheritBaseLayers}` |
| DELETE | 图层删除（改造） | 改为移入 `.trash`，不物理删除 |

兼容：旧路由与字段保持不变；`/api/map/project` 响应新增 `schemaVersion/stats/baselineAt`。

- `LayerPanel.jsx`：三段式图层树（底图/正式/临时）、临时层角标与转正、锁定标记、双击打开属性。

### 3.5 重置与基线机制

```text
重置图层树  = 基线配置回填 config.layers/groups（不动数据）
清空临时层  = 前端临时层注册表清空 + 画布临时图层移除
恢复基线    = 重置图层树 + 清空临时层 + 基线后新增正式层移入 .trash
```

- 每次重置写快照到 `.trash/{timestamp}/config.snapshot.json`，可回退。
- 影响清单在前端计算并展示“将恢复 N 层 / 将移除 M 层”，恢复基线需输入项目名确认。

### 3.6 AI 画布流程（单活动画布）

```text
新建画布（blank）
  → 创建仅含底图的项目 + 写基线
  → 绑定当前会话（task.mapProject）并在对话栏显示项目标签
  → 注入起步提示（可编辑）
  → Agent: map_datasets → map_analyze/map_import/map_edit（结果全部临时层）
  → 用户预览 → “保存为正式层”（审批）→ 落盘 + 重建瓦片
  → 随时可“一键重置”
```

切换项目即切换画布，自动清理本会话临时层；不支持多画布并存。

失败/取消：临时层保留可重试，不产生正式层；切项目自动清空本会话临时层。

## 7. 风险与回滚

| 风险 | 影响 | 缓解/回滚 |
|---|---|---|
| config v2 迁移破坏旧项目 | 打不开历史项目 | 升级前备份；迁移脚本可重入；`schemaVersion` 回退 |
| 恢复基线误删正式层 | 数据丢失 | 移入 `.trash` + 输入项目名确认 + 快照 |
| SHP 解析兼容性差 | 导入失败/属性错位 | 样例库覆盖 Point/Polyline/Polygon/DBF；失败明确提示；保留 GeoJSON 路径 |
| 重置与 Agent 并发 | 状态不一致 | 重置走审批 + 项目级写锁 + 运行中禁用危险重置 |
| 临时层注册表遗漏 | 清单与实际画布不一致 | 统一注册入口 + 回归断言“画布 id 与注册表一致” |
| GIS 交付能力默认开启改变历史基线 | 既有默认关测试失败/行为突变 | 新增 `readFlagDefault` 与显式关闭测试；`OAW_MAP_*=0` 一键回退；变更日志记录 |
| 性能回退 | 大地图卡顿 | 现有 5 万要素基线 + 阶段 5 扩展 |
