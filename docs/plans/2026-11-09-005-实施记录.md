## 2. 与计划的偏差

1. **不新增任何摘要**：按用户 2026-11-09 反馈，计划 v3 已删除“折叠头 N 步 · M 个站点”和“操作记录 · N 个站点 · 最近 X”。卡片标题只写“浏览器任务”；操作记录收起态只有标题 + 计数徽标。
2. **错误页站点点位**：`browserStepHost("chrome-error://…")` 返回“加载失败”而不是 `chromewebdata`，避免错误页冒充站点；站点聚合只收 http/https。
3. **首次 `browser_open` 的 running 行**：`withBrowserStep` 开始记录时浏览器会话尚未创建（`browserOpen` 内部才启动），`recordBrowserStep` 静默忽略；该步骤在结束时创建记录并显示最终站点。会话流卡片从 `browser_step_start` 起就有行，不受影响。
4. **操作记录清空时机**：浏览器 `close()` 时清空（明细/总数/站点），避免下次打开看到上一次会话。
5. **测试升级**：原“前端时间线”只做源码字符串匹配，改为“投影行为 + 旧路径 + 共享模块 + 无摘要断言”；`test:chat-flow` 的旧白名单断言同步更新。
