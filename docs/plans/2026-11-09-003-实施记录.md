## 2. 契约与已知边界

- 工具错误码：`CANVAS_WORKSPACE_INVALID` / `CANVAS_PATH_DENIED` / `CANVAS_NOT_FOUND` / `CANVAS_INVALID` / `CANVAS_EXISTS` / `CANVAS_REV_CONFLICT`(409) / `CANVAS_LIMIT` / `CANVAS_BUSY`(409) / `CANVAS_CONFIRM_REQUIRED`(409) / `CANVAS_BROWSER_UNAVAILABLE` / `CANVAS_EXPORT_FAILED`。
- 导出视图 URL 唯一构造点 `buildCanvasExportUrl`；PDF 多板要求同尺寸，混合尺寸明确失败并建议逐板 PNG。
- PPTX：对象板文本为可编辑 `<a:t>`，形状为形状，图片为图片；兼容板为整页图片并在导出对话框标注。
- 兼容 `.dc.html`：只读渲染（iframe `sandbox="allow-same-origin"`，不执行脚本），不写回原文件；对象板为 `.board.json`。
- 素材读取：`GET /api/canvas/:slug/asset` 只允许 `project/` 内白名单类型，带 `nosniff` 与 CSP。
- 会话绑定：`creativeCanvas` 写入会话 header；开关关闭时不写、不恢复。

## 4. 偏差、未验证与遗留

1. **未做真实浏览器 PDF/PNG 导出回归**：导出模块测试用注入假浏览器断言调用链；`?export=canvas&boards=A,B` 多页 PDF 已实现逐板 `@page`，但未在真实 Chromium `printToPDF` 下验证分页与字体。建议人工验收时各导出一份 PDF/PNG 检查。
2. **PPTX 的 SVG 块**：当前以矢量 SVG 内嵌（PowerPoint 2016+ 可显示），未走“先栅格化 PNG”的增强路径（需导出视图 `render=svg&element=` 支持，列为后续增强）。
3. **兼容板相对素材**：`.dc.html` 以 `srcDoc` 渲染时，板内相对图片路径无法解析（受控 URL 方案未启用），素材可能显示占位；对象板素材正常。
4. **画布空态不自建板**：无 `addBoard` HTTP 接口，空画布引导由 Agent `canvas_write` 或导入完成；属当前交互约定。
5. **属性条颜色为文本输入**（非 `input[type=color]`），可接受令牌值；真实写入权限（READONLY/EACCES/LOCKED）未联调。
6. **并发编辑**：板级 CAS + 409 冲突提示已实现；同一板多人/Agent 同时编辑的合并策略为“刷新/覆盖二选一”，未做自动合并。
7. **与本计划无关的既有失败**：`test:ui-guard`（LayerPanel/MapViewer/草稿样式 3 处冻结计数漂移）、`test:event-emission`（`map_draft_discarded` 无发射点）、`test:adr-index`（并行会话新增 ADR-0032 未入索引）。以上 HEAD 与工作区一致，非本次引入。

## 5. 回滚

- `OAW_CREATIVE_CANVAS=0`（默认）即基线：无 `design` 标签入口、无 `canvas_*` 工具、画布 API 全部 404；已产生 `designs/` 文件保留。
- 回退代码时新增文件整体删除即可；无存量数据迁移、无新依赖、无持久化格式变更（`creativeCanvas` 为会话 header 可选字段）。

## 6. 人工验收反馈补齐（2026-11-09 第二轮）

用户试用创作画布后反馈 7 项，本轮已实现并补测试：

1. **版本历史**：服务端写板/写索引前留存上一版到 `.history/`（每板一个 JSONL，最多 20 条）；新增 history 列表/恢复 API；工具条“历史”面板可查看时间、rev、操作者并恢复，恢复后板 `rev` 递增且当前版本也进历史。
2. **添加到对话**：工具条“对话”把 `@designs/<slug>/project/canvas.json` 插入输入框；App 传入 `onAddToChat`，最大化时先恢复布局再插入。
3. **播放**：全屏覆盖层逐页放映（deck 按 `order`/`role=slide`），←/→、PageUp/PageDown、空格/Enter、Esc；对象板按元素渲染，兼容板整页只读。
4. **页面主题与间距**：设置面板支持画板背景（默认纸白/面板色/表面色、应用到全部对象板）、网格间距、板间距（“整理画板”写回 `canvas.json`）、安全边距辅助线；本机偏好按工作区 + slug 存 localStorage。
5. **抓手工具**：工具条新增抓手（快捷键 `H`），激活后拖动平移；空格/中键平移保留。
6. **最大化画布**：新增 `.app.canvas-maximized .center-area { display:none }`，隐藏中间对话区与拖动条；关闭画布或取消最大化恢复。
7. **PPT 预览提速**：PptxViewer 原始字节 LRU + 首屏 JPEG 缓存 + 去掉强制 `no-store`（走 ETag 条件请求）+ 8 秒慢渲染提示；服务端 raw 路由已有条件请求支持。

验证：`test:canvas-model` 41 项、`test:canvas-ui` 22 项、`test:canvas-export` 24 项通过；`npm run build` 成功。未做真实浏览器端的人工播放/历史恢复点击验证，建议在桌面端逐项点一遍。
