## 1. 结果摘要

按用户确认的 A2-甲 + B1 落地，并一并修掉同区三个缺陷（S1/S2/S3）：

- 引用 / 附件 / 图片不再作为输入卡**兄弟节点**飘在卡外，统一收进卡内一行只读小 tab（图标 + 短名 + ×，完整路径只进 `title`）；
- 输入框不再出现 `@文件[长路径]` 文本：选中候选只登记引用，发送时由 `expandReferenceMarkers` 补回 `@文件[…]` 标记（写入 prompt 与会话记录），气泡再把标记还原成 chip；
- 忙碌态「立即执行 / 排队执行 / 注入上下文」从常驻整行的文字 + 三按钮 + 9px 提示，收成一个「排队 ▾」chip，点开向上弹三选一；
- `@` 不再同时弹出「文件候选 + 智能体候选」两个重叠面板；引用与文本的同步改成正向合并 + `textBound` 回收，token 化引用不会被误删。
