# GIS 模块 PRD（QGIS 式项目工作区）

> 状态：草案（已按 2026-10-30 决策更新）　版本：v0.2　基线：v0.13.3　日期：2026-10-30
> 依据：[AGENTS.md](../../AGENTS.md)、[REQUIREMENTS.md R10](../../REQUIREMENTS.md#L216-L236)、[DESIGN.md §4](../../DESIGN.md#L83-L91)
> 原则：**功能只加不减**——先完整保留现有 GIS 能力，再叠加“项目即工程、正式/临时图层分层、一键重置、AI 画布”四项主线。
> 已确认：单活动画布；GIS 交付能力默认开启；版本继续在 v0.13.x 线内迭代（不启用 v0.14.0）。
> 生效方式：确认后把新增需求编号回写 `REQUIREMENTS.md` R10；本文件作为模块级细化长期维护。

## 1. 背景与问题

现有 GIS 模块已具备 MapLibre 画布、QGIS 风格图层树、属性表、测量/绘制、等时圈、Agent 地图工具、导出与报告等能力，但组织方式仍是“一个地图面板 + 若干工具”：

- **项目不是工程**：项目只能切换/复制，缺少“工程基线、图层元数据、操作记录、恢复快照”等工程语义。
- **图层没有生命周期**：正式图层（落盘 + 瓦片）与临时图层（分析/绘制/AI 结果）混在同一张画布，临时层只有“清除”按钮，没有清单、来源、未保存状态和转正入口。
- **缺少一键回到起点**：误操作后只能逐层手动恢复；没有“重置图层树/清空临时层/恢复基线”的分级能力。
- **AI 做图缺少入口**：Agent 已能读写项目，但没有“新开一张空白画布，让 Agent 从零开始做图”的闭环，也没有把 AI 结果临时层一键转正的确认流程。
- **能力可见性断裂**：SHP 导入缺失；区域交换、路网结构只有服务端接口没有界面；报告/批量导出/打包/模板长期默认关闭，用户看不到。

## 2. 定位与目标

把 GIS 模块定位为 **“每个地图项目 = 一个可交付的 QGIS 式工程”**：

1. **工程化**：项目拥有独立画布、图层清单、样式、基线快照、操作记录、交付物。
2. **分层化**：底图 / 正式图层 / 临时图层三类作用域清晰，临时层可追踪、可转正、可一键清空。
3. **可控重置**：提供“重置图层树、清空临时层、恢复基线”三级一键操作，危险操作二次确认并留备份。
4. **AI 协同**：支持新建空白 AI 画布，Agent 在项目内生成临时结果，用户确认后转正式层，全程可回退。
5. **交付闭环**：报告、批量导出、项目打包、模板、书签等既有能力默认可见、可开关、可审计。

## 3. 用户与典型场景

目标用户：交通规划工程师（与 PRD §1.2 一致）。

- **场景 A 项目出图**：新建项目 → 导入 GeoJSON/SHP → 配符号/分组 → 属性表核对 → 导出报告图。
- **场景 B AI 做图**：新建空白画布 → 选择数据源并输入“做义乌 OD 期望线” → Agent 生成临时层 → 预览确认 → 一键保存为正式层。
- **场景 C 误操作恢复**：样式被改乱 → 一键“恢复基线” → 图层顺序/显隐/透明度回到项目初始状态。
- **场景 D 换人接手**：打开历史项目 → 查看图层来源/要素数/操作记录 → 复制项目继续做。

## 4. 概念与术语

| 术语 | 定义 |
|---|---|
| 地图项目（工程） | `office-workspace/maps/{project}/` 下的完整工程：`map.config.json`、`style.json`、`layers/*.geojson`、`tiles/`、基线快照、交付物 |
| 画布 | 当前活动项目的 MapLibre 视图；**同一时刻只有一个活动画布**，切换项目即切换画布 |
| 底图 | 在线/离线栅格或基础矢量瓦片，来自项目配置与全局设置，不参与业务图层统计 |
| 正式图层 | 落盘到 `layers/`、注册进 `style.json` 与 `map.config.json`、有瓦片的持久图层 |
| 临时图层 | 仅存在于当前会话画布的分析/测量/绘制/AI 结果，不落盘，带“临时”标识 |
| 基线快照 | 项目创建或“设为基线”时保存的图层顺序/分组/显隐/透明度/样式，用于一键恢复 |
| AI 画布 | 空白项目 + 会话绑定 + 起步提示形成的从零做图入口 |

## 5. 功能需求

> 每条注明【保留】或【新增】；【保留】表示现有能力必须继续可用，不得在改造中删减。

### GI-01 项目即工程【保留 + 增强】

- 保留：创建、切换、复制、重命名、归档/取消归档、删除（默认项目保护，删除入 `.trash`）。
- 增强：`map.config.json` 增加 `schemaVersion`、工程元数据（名称/描述/创建时间/更新时间/基线时间/CRS 固定 `EPSG:4326`）；项目列表展示图层数、要素总数、最近修改时间。
- 验收：旧项目无需手工迁移即可打开；新建项目自动写入基线与 `schemaVersion`；默认项目不可删除。

### GI-02 画布与底图【保留】

- 保留：MapLibre 5.x 矢量瓦片渲染、缩放/指北/比例尺/globe、区域下钻、点选查属性、底图切换（高德路网/卫星/注记、Esri、OSM、Carto、Tencent、OpenTopoMap）、瓦片重建。
- 验收：断网时底图失败给出明确提示，不白屏；切换底图不丢失业务图层。

### GI-03 图层树【保留 + 增强】

- 保留：分组折叠、拖拽排序、显隐、透明度、符号缩略图、样式编辑、字段渲染/分级设色、图例、右键菜单（缩放定位/属性表/重命名/复制/删除/移组）、共享层只读、工作区归属。
- 增强：图层树自上而下分三段——**底图 / 正式图层（按组）/ 临时图层**；临时层显示来源（分析/绘制/AI/测量/等时圈）、要素数、未保存标识。
- 验收：临时层不写入 `map.config.json`；刷新后临时层消失且不报错；正式层删除仍需二次确认。

### GI-04 正式图层属性与元数据【新增】

- 图层属性对话框：名称、id、类型（点/线/面/栅格）、分组、来源（导入文件路径 / Agent / 分析转正）、要素数、bbox、CRS、创建时间、更新时间、owner/共享归属、可编辑性。
- 图层操作：重命名、改分组、锁定（禁止 Agent 修改）、导出单层 GeoJSON、替换数据（覆盖前确认并备份）、删除。
- 验收：每个正式图层都能追溯到来源与统计；锁定层对 Agent 写操作返回明确拒绝原因。

### GI-05 图层导入【保留 + 新增】

- 保留：GeoJSON/JSON 单文件与批量文件/目录导入、`prepare-map-data` 一键路网、导入后自动重建瓦片并热更新。
- 新增：SHP（`.shp`+`.dbf`，可 zip 打包）、CSV 点表（经纬度列自动识别）；画布拖拽导入；导入预检（坐标范围、要素数 `expected vs actual`、重名覆盖确认）。
- 验收：三种格式均能在界面完成导入并出现在图层树；坐标越出中国范围（73–135°E / 18–54°N）立即阻断并产出 `geo_out_of_range`；导入失败不破坏现有项目。

### GI-06 临时图层清单【新增】

- 统一临时层注册表：`{id, project, kind, title, source, featureCount, visible, createdAt, persistable}`。
- 面板能力：逐条定位、显隐、单条清除、全部清除、“未保存”角标、转正入口。
- 验收：分析/绘制/等时圈/AI 结果全部自动登记；清除后画布与清单同步；切项目自动清空本会话临时层。

### GI-07 临时层转正【保留 + 增强】

- 保留：Agent `map_save_analysis` 保存分析结果为正式层。
- 增强：界面上对任意临时层提供“保存为正式层”对话框（名称、分组、是否保留临时层）；写操作走 Work + 审批；覆盖同名层需二次确认。
- 验收：转正后图层落盘、瓦片重建、图层树归位；审批拒绝时临时层保持原样。

### GI-08 一键重置【新增】

- 三级重置，入口在项目菜单与图层树顶部：
  1. **重置图层树**：恢复基线中的顺序/分组/显隐/透明度/样式，不动图层数据。
  2. **清空临时层**：移除全部临时图层与测量/绘制结果。
  3. **恢复基线**：重置图层树 + 清空临时层 + 删除基线之后新增的正式层（移入 `.trash`，不物理删除）。
- 全部操作二次确认，展示影响清单（将恢复/将移除的图层数与名称），完成后刷新画布并记录操作日志。
- 验收：重置后与基线逐项一致；恢复基线可撤销（从 `.trash` 找回）；无临时层时按钮禁用并说明原因。

### GI-09 基线快照与备份【新增】

- 项目创建时自动写基线（`map.baseline.json`）；提供“把当前状态设为基线”。
- `style.json` / `map.config.json` 写入前保留最近一次备份；支持“查看基线差异”。
- 验收：基线文件不参与运行时渲染；设为基线有确认；差异视图能列出增删改图层。

### GI-10 AI 画布【新增】

- 新建画布向导：空白工程 / 复制现有项目 / 从模板；空白工程仅保留底图能力。
- **单活动画布（已确认）**：同一时刻只有一个活动画布，切换项目即切换画布；不提供多画布标签页（后续如需要单独立项）。
- 画布与会话绑定：当前项目写入任务上下文（沿用 `task.mapProject`），对话栏显示项目标签。
- 起步提示：默认注入“当前为空白画布，请先列出可用数据源，再生成临时图层，确认后保存为正式层”，可编辑。
- Agent 结果一律先落临时层；界面提供“保存全部/单条转正”；运行中可随时一键重置。
- 验收：从空白画布到出图全程无手工建层；取消/失败不产生正式图层；同一会话切项目不串数据。

### GI-11 空间分析【保留 + 补齐】

- 保留：热力、OD 流量（CSV 粘贴）、等时圈（单档/多档/路线）、缓冲区/空间筛选/裁剪（`map_analyze`）、可视面板数据源（浙江演示、M2 带宽、市—县 OD、新昌公交、暹粒 OD、工作区文件、HTTP/SQLite 适配器）。
- 补齐：**区域交换（交换桑基）与路网结构**在可视面板提供界面入口（现仅服务端 `/api/map/exchange-sankey`、`/api/map/road-structure`）；演示数据统一“演示数据，请勿当作生产数据”标注。
- 验收：M2 四项（流量带宽/OD 期望线/区域交换/路网结构）均可从界面进入；演示数据在卡片、图层名和导出文件中均有标注。

### GI-12 属性表【保留】

- 保留：字段、搜索、排序、分页、CSV 导出、点击行定位到地图。
- 验收：10 万行以内分页可交互；属性表不阻塞画布。

### GI-13 测量与绘制【保留】

- 保留：距离/面积测量、点/线/面绘制并保存为图层、Esc 取消、清除临时层。
- 验收：绘制结果可转正或清除，不自动写入正式层。

### GI-14 数据源适配【保留】

- 保留：浙江 M2、新昌公交、暹粒 OD、工作区 CSV/GeoJSON、HTTP 端点、SQLite 只读（开关控制）。
- 验收：适配器故障有可理解原因；SQL 只读与路径越界继续拦截。

### GI-15 Agent 工具【保留 + 新增】

- 保留：`map_read / map_edit / map_import / map_analyze / map_save_analysis / map_clear_analysis / map_datasets / map_template`。
- 新增：`map_layer_info`（读图层元数据）、`map_reset`（按级别重置，需审批）、`map_project_create`（新建空白/复制项目，需审批）。
- 约束：Chat 仅只读四件套；写与重置只在 Work；Review 不开放地图写。
- 验收：能力计划声明的工具均可实际调用；拒绝路径返回结构化原因。

### GI-16 导出、报告、打包与模板【保留 + 默认体验】

- 保留：PNG 报告图（A4/方形/自定义、2–3x、标题/图例/比例尺/指北针）、即时截图、批量导出（PNG/PDF 队列）、分析报告 docx、项目打包 zip、OD 通勤模板、视图书签。
- **默认开启（已确认）**：上述 GIS 交付能力默认对用户可见（`mapReport/mapExport/mapPack/mapTemplates/mapBookmarks` 默认 `true`），用户可通过环境变量 `OAW_MAP_*=0` 关闭；不再保留“默认关”的历史基线。
- 增强：在“设置 → 地图”提供能力开关与说明；开关状态经 `/api/status` 下发并在界面即时生效；关闭时隐藏入口而不是报错。
- 验收：默认安装即可从界面进入报告/批量导出/打包/模板/书签；关闭后入口隐藏且无残留报错；关闭基线测试同步更新。

### GI-17 权限、安全与审计【保留 + 增强】

- 保留：共享层只读、工作区自有层可编辑、写操作审批、坐标范围硬约束、演示数据标注、失败不破坏项目。
- 增强：项目级操作日志（时间/来源 user|agent/动作/图层/结果），支持按图层筛选；Agent 触发的图层变更单独标记。
- 验收：任一正式层变更都能在日志中找到操作者与前后状态；审计不记录密钥与用户文档内容。

### GI-18 项目隔离与切换【保留 + 增强】

- 保留：项目独立 `config/style/layers/tiles`；会话绑定 `mapProject`；切换项目重载画布。
- **单活动画布（已确认）**：项目切换即画布切换，不做多画布并存。
- 增强：切换项目时清理临时层与选中态；未保存的绘制结果提示“切换将丢失，是否先转正”。
- 验收：A 项目的临时层不出现在 B 项目；切换后 Agent 默认写入新项目。

### GI-19 性能与可用性【保留 + 增强】

- 保留：5 万要素瓦片索引性能基线。
- 增强：大图层（≥5 万要素）加载/显隐/图层树滚动帧率基线；地图容器随布局变化自动 `resize`；窄屏下图层树与属性表可用。
- 验收：基线脚本可重复执行；拖动对话栏/画布宽度后地图无黑边。

### GI-20 持久化与恢复【保留 + 增强】

- 保留：本地文件 + 瓦片目录；项目打包可跨环境恢复。
- 增强：`config/style` 原子写与备份；项目迁移脚本（`schemaVersion` 升级）；损坏文件可回退到最近备份。
- 验收：写入中断不产生半截 JSON；旧版本项目打开后自动升级并可回退。

## 6. 交互与界面

### 6.1 工作区结构

```text
顶栏：项目选择 / 新建画布 / 底图 / 区域 / 视图 / 导入 / 分析 / 导出 / 重置 / 返回
左栏：图层树（底图 / 正式图层分组 / 临时图层）
中栏：MapLibre 画布（选中态、测量绘制提示、临时层角标）
右栏：地图对话（紧凑模式 + 项目标签 + 临时层转正卡片）
```

### 6.2 图层树信息架构

- 正式图层节点：显隐、符号、名称、要素数、锁定标记、来源角标（共享/本工作区）。
- 临时图层节点：来源角标（AI/分析/绘制/等时圈）、未保存标记、转正按钮、单条清除。
- 组节点：组显隐、折叠、拖拽排序、移组。
- 空态：无正式层时提示“导入数据或让 Agent 开始做图”，并给两个入口。

### 6.3 图层属性对话框

分区：基本信息（名称/id/类型/分组）、数据（来源/要素数/bbox/CRS）、权限（owner/共享/锁定）、样式（符号/透明度/缩放范围）、操作（导出/替换/删除）。

### 6.4 重置菜单

`重置图层树` / `清空临时层` / `恢复基线（危险）`，均展示影响清单；恢复基线需输入项目名确认。

### 6.5 AI 画布向导

三步：选择起点（空白/复制/模板）→ 命名与绑定会话 → 确认起步提示并进入画布。进入后对话栏顶部显示“AI 画布 · {project}”。同一时刻只保留一个活动画布。

## 7. 权限、安全与领域约束

- Chat 只读：仅 `map_read/map_analyze/map_clear_analysis/map_datasets`，不得写层、不得保存分析。
- Work 写与转正走审批；`shared/*` 写按既有策略拒绝或逐次授权。
- 坐标硬约束：WGS84 中国范围 73–135°E / 18–54°N；越界阻断并产出 `geo_out_of_range`。
- 导入完整性：声明记录数与实际要素数不一致时阻断并产出 `data_integrity_failed`。
- 演示数据：文件名、图层名、界面卡片、导出物四处标注，不得表述为真实调查数据。
- 文件边界：只允许读写工作区内 `maps/`；打包/恢复禁止路径穿越。
- 审计：日志脱敏，不写入密钥、Token、用户文档正文。

## 8. 非功能需求

- 性能：5 万要素索引 ≤8s（现有基线）；10 万行属性表分页不卡顿；图层树 100 层滚动流畅。
- 稳定性：重置/转正/导入失败均可回滚，项目文件不损坏。
- 可用性：所有图标按钮有应用内提示与 `aria-label`；重置与删除有二次确认；窄屏可完成导入、转正、重置。
- 兼容：旧项目（无 `schemaVersion`）自动迁移；旧 API 字段保持兼容，新增字段只增不改。

## 9. 非目标

- 不做完整桌面 GIS 编辑器（拓扑编辑、栅格代数、打印布局设计器、插件体系）首发。
- 不做多人协同编辑与云端同步。
- 不引入数据库、消息队列或新地图渲染内核。
- 不在未确认时默认开启运行时开关；不改变 Chat/Work/Review 能力边界。
- 不做多画布标签页（用户已确认单活动画布）。
