## 6. 用户验收反馈增量（2026-11-11 同日）

**反馈**：deck 画布底部出现两条缩略条——本次新增的「画布板条」（浅色）与既有画板/幻灯缩略条 `oaw-canvas-deck`（深色，含拖拽排序，所有画布都会渲染）叠加重复；用户确认"保留一个"。三方案（合并为一条 / 按画布类型互斥 / 只留新板条）经用户选定：**合并为一条**。

**处置**：
- 保留 `oaw-canvas-deck` 条（deck 拖拽排序是既有核心交互），把新板条的三个增量并入：① 点击卡片改为 `定位到板`（设当前板 + `定位板视图` 视口居中，并保留清空选中/编辑）；② Agent 编辑板叠加呼吸点 `.oaw-canvas-deck-agent` 与 `--map-accent` 边框（`.oaw-canvas-deck-item.agent-editing`）；③ 条首加折叠按钮 `.oaw-canvas-deck-toggle`（沿用用户级偏好键 `oaw_canvas_strip_collapsed`，播放态隐藏）。
- 删除独立组件 `画布板条.jsx` 与 `.oaw-canvas-strip`（条容器/滚动/卡片/标签）样式；`.oaw-canvas-strip-thumb/block/skeleton` 三类保留——全览浮层卡片复用。
- 全览浮层（画布全览.jsx）与画布模型纯函数（`定位板视图`/`板缩略块`/`板缩略数据`）保留不动。
- `test:canvas-ui` 零新依赖名单移除 `画布板条.jsx`；`定位板视图`/`板缩略数据` 用例保留。
