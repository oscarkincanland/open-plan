### 2.2 `server/index.mjs`

### 2.3 `scripts/执行句柄契约测试.mjs`（`npm run test:exec-handle`）

1. Run 替身补齐 `validatableRunArtifacts: () => []`，与真实依赖同形。
2. 新增「收尾依赖接线完整」：静态解析 `执行句柄.mjs`，断言所有 `deps.runs.*` 调用都在默认 `runs:` 依赖块里，且每个名字都是 `runs.mjs` 的函数导出（覆盖"漏接 + 拼错"）。

4. 新增「成功回合收尾跑通」：注入替身后执行一轮，短延时后断言 Run 落 `completed` 且收到 `run_finished`；若收尾路径再出现未注入依赖，该用例会失败而不是静默停在 running。
