## 1. 范围与非目标

### 1.1 范围

- GoalBar：六状态、暂停/完成/恢复/继续/提高预算/编辑/清除/详情。
- `/goal`：设定、清除、暂停、恢复、继续、编辑、预算、查看。
- Goal 统计：轮次、Token 用量、活跃时长。
- Links：从会话消息提取链接、去重、打开/复制、页签数量角标。
- 线内回归与 release candidate。
- 可选：WorkPanel 与 Canvas 常驻并存（双面板）。

### 1.2 非目标

- 不做 Team/SOLO、Plan 模式、`/swarm`、终端页签。
- 不修改 Pi SDK，不把 Goal 声称为 Pi 原生能力；Goal 是项目 Harness 的长期目标层。
- 不新增数据库、消息队列、微服务、桌面壳。
- 不在本线实现定时任务、语音、跨设备同步。

## 2. Goal 数据模型

### 2.1 Goal 文件

```json
{
  "version": 1,
  "goalId": "goal_<uuid>",
  "sessionId": "<session uuid>",
  "text": "长期目标文本",
  "status": "active",
  "budgetTokens": 0,
  "maxTurns": 0,
  "usedTokens": 0,
  "turns": 0,
  "activeMs": 0,
  "createdAt": "ISO",
  "updatedAt": "ISO",
  "completedAt": null,
  "lastRunId": null
}
```

状态枚举：

| 状态 | 含义 | 进入条件 | 允许操作 |
|---|---|---|---|
| `active` | 进行中 | 创建/恢复/继续/提高预算 | 暂停、完成、编辑、清除、详情 |
| `paused` | 已暂停 | 用户暂停 | 恢复、编辑、清除、详情 |
| `blocked` | 受阻 | 运行收口为 blocked 且目标仍在 | 恢复、编辑、清除、详情 |
| `max_turns` | 达轮次上限 | `turns >= maxTurns`（若设置） | 继续、编辑、清除、详情 |
| `budget_limited` | 达 Token 预算 | `usedTokens >= budgetTokens`（若设置） | 提高预算、编辑、清除、详情 |
| `complete` | 已完成 | 用户完成或目标达成 | 详情（GoalBar 消失） |

状态迁移：

```text
active → paused | complete | blocked | max_turns | budget_limited
paused → active（resume）
blocked → active（resume）
max_turns → active（continue；保留 turns 统计，不重置）
budget_limited → active（提高预算；更新 budgetTokens）
complete → 终态（可清除；GoalBar 不渲染）
任意非 complete → 清除（删除 Goal 文件）
```

### 2.2 持久化与并发

- 目录：`.oaw/goals/`；文件：`<sessionId>.json`；使用 `持久化工具.mjs` 的原子写。
- 读取：打开会话时读取；不存在则不显示 GoalBar。
- 并发：同一 session 只允许一个写入者；写入前 `fs` 读旧值 + 原子替换；两个标签页同时操作以最后写入为准，并在 UI 显示最新服务端值。
- 会话删除：Goal 文件随会话删除？设计为**保留**，避免误删用户目标；会话删除时写入 `orphaned:true` 或移动到 `.oaw/goals/archive/`。v0.13.0 先保留，v0.13.1 加清理入口（可选）。
- 会话 header：增加 `goalId`（增量字段，兼容旧会话），用于列表/诊断；Goal 文件仍是事实源。

### 2.3 统计口径

| 字段 | 来源 | 更新时机 |
|---|---|---|
| `turns` | 每个绑定该 Goal 的 Run 计数 | `run_started` 或 `run_finished` 一次，避免重复 |
| `usedTokens` | Run 的 usage/上下文统计 | `run_finished` 累计；失败/取消也计入已消耗 |
| `activeMs` | 状态迁移时间差 | pause/complete/blocked 时结算；resume 重新计时 |
| `lastRunId` | 最近一次绑定 Run | `run_started` |

### 2.4 与 Run/预算的关系

- Goal 预算独立于 `运行预算.mjs`/`轮次预算.mjs`；Run 预算仍管单轮工具/回合，Goal 预算管跨轮累计。
- 每次 `run_finished` 后检查：
  - `budgetTokens > 0 && usedTokens >= budgetTokens` → `budget_limited`
  - `maxTurns > 0 && turns >= maxTurns` → `max_turns`
  - Run 终态 `blocked` 且 Goal 未完成 → `blocked`
- 终态检查在 Run 收口之后、下一次 prompt 之前；不得阻塞当前 Run 收尾。
- Goal 状态变化发事件；前端 GoalBar 更新；不修改 Run 终态。

## 3. API 与事件契约

### 3.1 API

| 方法/路径 | 用途 | 请求 | 响应 |
|---|---|---|---|
| `GET /api/sessions/:id/goal` | 读取目标 | — | `{goal}` 或 `{goal:null}` |
| `POST /api/sessions/:id/goal` | 创建/替换目标文本 | `{text, budgetTokens?, maxTurns?}` | `{ok, goal}` |
| `POST /api/sessions/:id/goal/action` | 状态操作 | `{action, text?, budgetTokens?}` | `{ok, goal}` |
| `DELETE /api/sessions/:id/goal` | 清除目标 | — | `{ok}` |

`action` 取值：`pause`、`resume`、`continue`、`complete`、`edit`、`budget`、`clear`。

错误码：

- `GOAL_NOT_FOUND` 404
- `GOAL_INVALID_STATE` 409
- `GOAL_BUDGET_INVALID` 400
- `GOAL_WRITE_FAILED` 500
- `SESSION_NOT_FOUND` 404

### 3.2 事件

在 `server/事件注册表.mjs` 登记，全部 `lifecycle:true, persist:true`：

| 事件 | 载荷 | 说明 |
|---|---|---|
| `goal_created` | `{goalId, sessionId, text, status}` | 创建/替换目标 |
| `goal_updated` | `{goalId, sessionId, status, action, turns, usedTokens, budgetTokens}` | 状态/编辑/预算/统计更新 |
| `goal_cleared` | `{goalId, sessionId}` | 清除目标 |

> 不为每次统计更新单独发高频事件；`goal_updated` 在状态变化或用户操作时发，统计更新可随 `run_finished` 后的同一事件合并。

### 3.3 Prompt 注入

`server/task.mjs` 的 `createTaskEnvelope` 增加 `longTermGoal` 摘要；`taskSummary` 增加一段：

```text
长期目标：<text>
目标状态：<status>；轮次 <turns>；Token <usedTokens>/<budgetTokens>
```

`task.goal` 保持不变（本轮任务描述）；两者标题不同，避免模型混淆。`planTaskCapabilities` 不因 Goal 改变工具白名单。

## 4. UI 设计

### 4.1 GoalBar

- 位置：输入框正上方、QueueDock 之下；`complete` 后消失；无目标不占位。
- 主条：阶段标签（active/paused/...）+ 目标文本（单行省略，title 全文）+ 操作图标 + 编辑/清除/详情。
- 状态操作：
  - active：暂停、完成
  - paused/blocked：恢复
  - max_turns：继续
  - budget_limited：提高预算
  - complete：不渲染
- 详情浮层：轮次、Token 用量、活跃时长；Token 预算输入框；保存；Esc/点外关闭。
- 编辑：整条替换为输入条；Enter 保存、Esc 取消；失败回滚。
- `/goal`：在 ChatPanel 发送前拦截；`/goal <text>` 创建/替换；`/goal clear|pause|resume|continue|edit <text>|budget <n>` 调 action；空 `/goal` 打开详情/查看。
- 无障碍：按钮可 Tab、aria-label；状态变化 `aria-live="polite"`；浮层焦点归还。

### 4.2 Links 页签

- 位置：`工作产物面板` 增加“链接”页签；与预览/改动/产物并列。
- 提取：从已加载的助手消息文本中匹配 `https?://...`；去重；保留首次出现的轮次/消息 id/域名。
- 展示：标题（页面标题不可得时用域名/URL）、域名、来源轮次；点击 `window.open` 打开；复制按钮。
- 角标：链接数、产物数、待办数；0 不显示；随消息/产物变化更新。
- 空态：“暂无访问链接”；外部链接不可信提示；同一 URL 只保留一条。
- 边界：历史分页只加载部分消息时，链接随加载增量补充；不阻塞渲染。

### 4.3 可选：WorkPanel/Canvas 并存

- 双面板：右侧 WorkPanel + Canvas 同时可见；各自拖宽；对话区最小宽度约束。
- 仅容量允许时启动；优先保证 1366/1024 下输入区不被压扁。
- 若启动，必须新增 `DESIGN.md` 布局说明与窄屏降级；否则推迟到 v0.14.0 后评估。
