## 1. 目标与不做清单

**目标**（对应复盘 P0-1/P0-2/P0-3/P1-1）：把「代码能编译、单测能过」与「用户打开页面不崩」之间的缺口补上，且让"既有失败"与"新增回归"可区分。

**不做**：

- 不改 `AGENTS.md`（§11：修改需用户明确同意）；
- 不改 PRD / DESIGN 的视觉基线；
- 不动业务渲染逻辑（除本计划内、被 G1 抓到的缺陷修复）；
- 不引入新依赖（Playwright 本机已有，脚本自带回退到 msedge/chrome 通道）；
- 不把新门禁塞进 `npm run verify`（冒烟需要运行中的服务，避免 CI 误红），改用独立 `verify:flow`。
