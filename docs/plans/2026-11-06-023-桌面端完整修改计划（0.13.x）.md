## 1. 目标与非目标

**目标**
1. Windows 双击安装即用，无需用户装 Node。
2. 内置浏览器改为原生视图（`WebContentsView` + CDP），彻底去掉帧流。
3. 现有 192 个测试与 `npm run verify` 语义不变，web 形态可随时回退。
4. 单个 NSIS 安装包 ≤ 200MB（含 LibreDWG），可升级。

**非目标（本轮不做）**
- macOS / Linux 打包（先 Windows）；
- 多窗口、系统托盘常驻；
- 代码签名证书采购（M3 再议）；
- DWG 原格式写回（需 ODA）；
- 把服务端改写成 IPC（fork 路线，已否决）。

## 2. 进程模型

```
GuiJu.exe (Electron main, Node 22 运行时)
├─ 单实例锁 requestSingleInstanceLock
├─ import('../server/index.mjs') → Express 监听 127.0.0.1:<随机端口>
│    └─ 环境注入：OAW_API_TOKEN / OAW_DESKTOP=1 / OAW_RESOURCES_DIR
├─ BrowserWindow → 加载 client/dist（dev 时 vite devServer）
│    └─ preload.cjs：contextBridge 暴露 { dialog, shell, host, updater }
├─ WebContentsView（浏览器模块 embedded 驱动）
│    └─ webContents.debugger → CDP（工具层复用）
└─ 子进程池：officecli / dwg2dxf（LibreDWG）

退出：关窗口 → 停服务 → 杀子进程 → quit
```

## 5. 浏览器双驱动设计（要点）

```js
// server/内置浏览器.mjs 内
const 驱动 = {
  system:   () => import("./浏览器驱动/系统CDP.mjs"),   // 现有实现
  embedded: () => import("./浏览器驱动/内嵌视图.mjs"),  // 经 desktop 主进程 IPC 落地
}[RUNTIME_FLAGS.browserDriver]();

// 统一接口（工具层只依赖它）
open(url) / snapshot() / click(ref) / type(ref,text) / press(key) /
scroll(dir,amount) / tabs(action,id,url) / screenshot() / back() / close()
```

- 工具层（`browser_*`）零改动；
- `embedded` 驱动的实现位置在 `desktop/src/浏览器视图.mjs`，`server` 侧只保留一个「远程调用桩」（经 `process.send`/本地 socket 与主进程通信，避免 `server` 依赖 electron）；
- 开关：`OAW_BROWSER_DRIVER=system|embedded`（默认：桌面 `embedded`、web `system`）；
- 回滚：设 `system` 即回到现有实现，代码保留到 D5 之后一个版本再评估删除。

## 6. 打包配置要点（`desktop/electron-builder.yml`）

| 配置 | 值 | 原因 |
|---|---|---|
| `asar` | `true` + `asarUnpack: ["bin/**"]` | 子进程不能从 asar 执行 |
| `extraResources` | `bin/` | LibreDWG/officecli 落在 `resources/bin` |
| `files` | `desktop/dist/**`、`server/**`、`client/dist/**`、`package.json` | 服务端需原样 ESM |
| `nsis` | `perUser: true`、`oneClick: false`、`allowToChangeInstallationDirectory: true` | M2 体验 |
| `publish` | `null`（M1/M2）→ `generic`（M3） | 升级通道后置 |

**体积预算**：Electron ~110MB + asar 8–15MB + officecli 30–60MB + LibreDWG ~5MB ≈ **150–190MB**。

**随包二进制流程**（因 `bin/` 被 `.gitignore` 忽略）：

1. `bin/清单.json` **入库**（文件名 + 版本 + sha256 + 来源 URL）；
2. `scripts/桌面/准备随包二进制.mjs`：构建前按清单下载/校验到 `bin/`（已存在则跳过）；
3. CI 缓存 `bin/`；本地开发者首次 `npm run desktop:prepare`；
4. 校验失败即中止打包（不允许带未知二进制出厂）。

## 8. Git 提交规范与双端协作（回答「后期怎么提交、要不要同时改」）

### 8.1 分支策略

- **默认在 `develop` 直接提交**（沿用 ADR 0020）；桌面端**不单开长期分支**。
- 仅当「桌面端改动会长时间破坏 web 构建」时，才申请 `wip/desktop-*` 短分支（需你确认，合并即删）。
- `main` 只在发布时由 `develop` 合入并打 tag（tag 需你确认）。

### 8.2 提交粒度与 scope

| scope | 含义 | 例子 |
|---|---|---|
| `platform` | 适配层本身 | `refactor(platform): 抽出宿主与外部二进制解析` |
| `desktop` | `desktop/` 壳、打包、CI | `build(desktop): M1 内测安装包` |
| `browser` | 浏览器驱动（双端共享） | `feat(browser): Electron 内嵌视图驱动` |
| `web` | 仅影响 web 形态的行为 | — |
| 无 scope | 共享业务层（沿用现有） | `fix(preview): …` |

**硬规则**：一个提交一个意图；不混「共享层改动 + 桌面端适配」；桌面端提交必须能说明「对 web 的影响 = 无 / 有（含验证命令）」。

### 8.3 「要不要两端同时改」判断矩阵（核心回答）

| 改动位置 | web 端 | 桌面端 | 必须双端验证？ | 说明 |
|---|---|---|---|---|
| 共享业务层（`server/*.mjs`、`client/src/components/**`） | 生效 | 生效 | **必须** | 一份源码两端同跑，改一处两端都变 |
| 适配层**接口**（`client/src/平台`、`server/平台`） | 生效 | 生效 | **必须** | 接口变更会影响两端调用方 |
| 适配层**某端实现**（如 `系统CDP` 驱动） | 只影响该端 | — | 否，但需另一端**回归** | 另一端行为不变，跑冒烟即可 |
| 仅 `desktop/` | 无 | 生效 | 否 | web 不加载 `desktop/` |
| 仅打包配置 / CI | 无 | 打包行为 | 否 | — |

**记忆口诀**：**「共享层改一次，两端都要点一遍；壳里改，只管壳」**。

### 8.4 与并行会话协作

- 桌面端改动集中在 `desktop/` 与两个 `平台/` 目录 → 与主线热点文件零交集；
- 必须改热点文件时（`内置浏览器.mjs`、`浏览器面板.jsx`、`index.mjs`）按 hunk 隔离提交，并在提交信息注明「并行风险」；
- 每日开工前 `git log --oneline -5` 对齐基线，避免基于过期内容编辑（本会话已踩过一次：误删并行会话的变更日志小节）。

### 8.5 发布节奏

1. `develop` 上 web 形态先验收（`verify` + 15 套会话流/预览测试）；
2. 打包桌面端，M1/M2 冒烟；
3. 版本号**两端同号**（0.13.x patch 线），`package.json` 仍等于已发布版本；
4. `develop → main` + tag（需确认），**先 web 后桌面**同 tag 发布。

### 8.6 提交示例（可直接照抄）

```text
refactor(platform): 抽出宿主信息与外部二进制解析（行为不变）
feat(desktop): Electron 壳骨架，主进程内起现有 Express
feat(platform): 原生文件/目录对话框与外部打开（web 走回退）
test(platform): 平台边界门禁——共享层禁止依赖 electron
feat(browser): Electron 内嵌视图驱动（CDP 工具层复用）
perf(browser): 移除桌面端帧流链路（桌面无 screencast/SSE 帧）
build(desktop): 随包 officecli + LibreDWG 与 sha256 清单
ci(desktop): windows 打包流水线与安装冒烟
```

## 9. 风险与回滚

| 风险 | 回滚动作 |
|---|---|
| 桌面端启动失败 | `OAW_DESKTOP=0` 走 web 入口；或直接 `npm start` |
| 内嵌浏览器异常 | `OAW_BROWSER_DRIVER=system` 回到外部 Edge + 帧流 |
| 随包二进制损坏 | 校验清单 sha256 不匹配即拒绝启动该能力（CAD/Office 降级并提示） |
| 打包产物体积超标 | 先去掉 officecli 随包（改为首次引导安装） |
