### 2.1 Command Code 路由规则

```text
supported_endpoints 含 /chat/completions → openai-completions + /provider/v1
supported_endpoints 含 /responses        → openai-responses    + /provider/v1
supported_endpoints 仅 /messages         → anthropic-messages + /provider
无 supported_endpoints                   → 套餐预设 api/baseUrl
```

实测 `POST /provider/v1/v1/messages` 为 404，因此 Anthropic 协议必须使用不含 `/v1` 的 baseUrl。
