## 1. 现状定位

### 1.1 消息头像与 `You`

| 位置 | 现状 |
|---|---|
| `ChatPanel.jsx:6247-6252` | 每条消息固定渲染 `.avatar`：用户是 `user` 图标，助手是 `Logo` |
| `ChatPanel.jsx:6255-6263` | 消息头 `.msg-header`：用户显示 `You`，助手显示 `model \|\| "Agent"` + 时间 + 失败/中断徽标 |
| `ChatPanel.jsx:6264-6272` | 用户气泡 `.bubble.user-bubble`，内含图片、当前文件、引用 chip、文本 |
| `styles.css:889-903` | `.msg` 横向 flex + `.msg.user` 反向；`.avatar` 28px；用户气泡强调边框/加粗 |
| `styles.css:8985-9017` | 居中内容列下，头像绝对定位到列外 `left:-39px / right:-39px`；窄屏隐藏头像；`.msg-author` 11px |

**结论**：头像和 `You` 都是独立 DOM，可整体删除；用户气泡内容不需要改，只需去掉头部和头像容器，调整对齐与留白。

### 1.2 历史导轨（ChatTimeline）

| 位置 | 现状 |
|---|---|
| `ChatTimeline.jsx:144-160` | `beads` 的 `top` 按**消息下标比例**计算：`((entry.idx + 0.5) / messages.length) * 100`；消息越多、工具条目越多，短杠越挤/越散 |
| `ChatTimeline.jsx:260-283` | 绝对定位渲染短杠，悬停/点击定位消息并打开弹层 |
| `styles.css:7111-7147` | 导轨在**右侧** `right:3px`，宽 26px；短杠绝对定位，弹层向右展开 |
| 触发条件 | 用户轮次 ≥2 且容器宽 ≥900px；设置里 `showTimeline` 可关 |

**结论**：功能已经存在，问题在**布点算法**（按消息比例）和**位置**（右侧），不是缺少功能。图三的观感是「几根短杠等距并列」，对应把 `top` 改为按**短杠序号**均分，并可选移到左侧。

## 2. 方案

### 2.1 消息极简化

**目标形态**

```
                         ┌───────────────────────────┐
                         │ 当前文件: 报告.docx        │
                         │ 根据 需求.md 生成一份 PPT   │   ← 只有用户气泡
                         └───────────────────────────┘

opencode-go/claude-haiku-5-5  11/04 14:24  生成失败   ← 助手头部保留
● 失败  ⌄
任务执行失败...
```

**改动**

1. 删除 `Message` 里的 `.avatar` 整块（用户和助手都删）。
2. 用户消息不再渲染 `.msg-header`：去掉 `You`、时间、失败徽标（用户消息本来没有这些）。
3. 用户气泡保留现有内容：`images`、`currentDoc`、`references`、`text`；右对齐，宽度仍受 `--msg-content-max` 与 `min(78%, 540px)` 约束。
4. 助手消息保留 `.msg-header`（模型名/时间/失败/中断）——已确认保留，便于判断模型与失败归属。
5. CSS：
   - `.msg` 去掉 avatar 占位与 `gap`；`.msg.user` 不再 `row-reverse`，改为 `.msg-main` 右对齐。
   - 删除 `.center-chat-slot .msg > .avatar`、`left/right:-39px`、窄屏隐藏规则。
   - 用户气泡与助手正文的左右边界重新对齐到内容列；输入框宽度不变。
6. 影响：`hideHeader` 逻辑中用户分支不再需要；相关测试（含 `工作区面板与输入栏收敛测试` 里“头像应恢复”的断言）同步改为“无头像、无 You”。

**不做**：不改气泡颜色/圆角/字号；不改助手运行过程折叠；不改空态。

### 2.2 历史导轨：等距并列

**推荐形态（左侧竖列）**```
│▬│  ← 第 1 轮
│▬│
│▬│  ← 当前阅读（加长/主题色）
│▬│
│▬│  ← 第 N 轮
```

**改动**

1. `ChatTimeline.jsx`：
   - `top` 从「消息下标比例」改为「短杠序号均分」：
     `top = ((beadIndex + 0.5) / beads.length) * 100`。
   - 保留现有采样上限（最多 24 根）与 `hover/click/active/error` 状态；弹层仍列出窗口内全部消息。
2. CSS：
   - 导轨从右侧移到左侧：`left: 3px; right: auto`；弹层从 `right:28px` 改为 `left:28px`，避免挡住正文。
   - 短杠宽度 14–20px、高度 2px、圆角 pill；`.active` 加长到 20px 并主题色；`error` 红色。
   - 窄屏（<900px）继续隐藏；若左侧留白不足，可只在 `≥1100px` 显示，避免压正文。
3. 交互不变：悬停/点击定位、弹层、↑↓/Enter/Esc/Home/End、设置开关。
4. 导轨增加 `aria-label="对话历史定位"` 与每根短杠的 `title`（已有摘要）。

**为什么改左边**：已确认按 ZCode 的左侧布局；本轮又去掉头像，左侧留白刚好放导轨，不会和头像/正文抢空间。

### 2.3 图标体系迁移到 Tabler Icons

**范围**

- 保留：
  - `Logo.jsx`（规聚 Logo）；
  - `ProviderIcon` / `供应商品牌图形.js`（模型供应商品牌）；
  - `ChatPanel.jsx` 上下文用量圆环（数据可视化，不是图标）；
  - `LayerPanel.jsx` 的 `LegendSymbol`（由图层 paint 的颜色/线型/点半径驱动的图例，属于数据可视化，不是图标库；替换会丢失图例语义）；
  - `内置浏览器面板.jsx` 的 Agent 光标（交互定位指示，带 ripple/品牌色，不是菜单图标）。
- 替换：
  - `Icon.jsx` 的 83 个业务图标 → `@tabler/icons-react`；
  - `文件类型图标.jsx` 的字形 → Tabler `IconFileTypeDoc / Xls / Ppt / Pdf / Html / Txt / Markdown / Code`，**保留现有实色底与颜色令牌**（避免文件树失去类型颜色）；
  - `DocxViewer.jsx` / `DocViewer.jsx` 的 Word 预览工具栏与头部图标 → Tabler（详见 §2.4）。

**实现方式**

1. `client/package.json` 增加 `@tabler/icons-react`（已确认；MIT，按需 named import，Vite 可 tree-shake）。
2. 重写 `Icon.jsx` 内部为「旧名称 → Tabler 组件」注册表，**保持现有 `<Icon name=... size=... className=... strokeWidth=... />` API 不变**，避免 100+ 调用点大改。
3. 映射原则：
   - 文件类型：`IconFileType*`；
   - 界面操作：`IconX / IconPlus / IconChevron* / IconArrow* / IconTrash / IconCopy / IconDownload / IconUpload / IconExternalLink / IconMaximize / IconMinimize`；
   - 状态：`IconCheck / IconAlertTriangle / IconInfoCircle / IconLoader2 / IconCircleX`；
   - 地图/GIS：`IconMap2 / IconStack2 / IconRoute / IconRoad / IconChartBar / IconChartSankey / IconArrowsSplit2 / IconMapPin / IconBus`；
   - 其他：`IconSearch / IconRefresh / IconLock / IconPin / IconStar / IconSun / IconMoon / IconSparkles / IconMenu2 / IconHistory / IconEye / IconEyeOff / IconShieldCheck / IconShield / IconPencil / IconDots / IconMessagePlus / IconTerminal2 / IconCode / IconPlug / IconPackage / IconBook / IconTool / IconWorld / IconSettings / IconFilter / IconColumns / IconLayoutGrid / IconList / IconLink / IconSend / IconPlayerStop`。
4. **图标去重规则（本轮硬约束）**：
   - 一个语义只对应一个 Tabler 字形；`ICON_NAMES` 映射表的**目标组件值必须唯一**，不允许两个旧名称指向同一字形。
   - 语义重复的旧名称合并调用点，而不是保留别名：
     - `edit` / `penTool`：统一用 `edit`（`IconPencil`）；`penTool` 调用点改为 `edit`；
     - `close` / 可能的 `x`：统一 `close`（`IconX`）；
     - `back` / `chevronLeft`：语义不同（返回 vs 折叠箭头），保留两个不同字形；
     - `more` / `menu` / `list` / `grid`：分别用 `IconDots` / `IconMenu2` / `IconList` / `IconLayoutGrid`，不互相复用。
   - 如果确实需要“同义但不同尺寸”的场景，通过 `size`/`strokeWidth` 表达，不新增重复映射。
   - 契约测试断言映射目标组件 `Set` 大小 === 映射条目数（ProviderIcon/Logo 不计入）。
5. 未映射名称在开发期告警、生产期回退 `IconHelpCircle`，不再静默消失。
6. 新增 `scripts/图标体系契约测试.mjs`：
   - `ICON_NAMES` 全部有映射；
   - 映射目标无重复；
   - 除白名单（`Logo.jsx`、`ProviderIcon`、上下文圆环、文件类型底图）外，`client/src/components` 不再出现裸 `<svg>`；
   - `Icon` 包装器仍接受 `name/size/className/strokeWidth`；
   - `ProviderIcon` 不依赖 Tabler；
   - Word 预览工具栏无文本箭头 `‹ ›`。
7. 构建后对比 bundle 体积；若 `@tabler/icons-react` 让主包增长超过阈值（建议 gzip +80KB），改为按需子路径导入或只引入实际用到的组件。

**图标尺寸/风格**：Tabler 默认 24 viewBox、stroke 2；现有 `size`/`strokeWidth` 继续生效。小尺寸（14px）保持 stroke 2，避免线条发虚；需要更细的图标在映射表里单独给 `stroke={1.75}`。

### 2.4 Word 预览工具栏（图四红框）

`DocxViewer.jsx` 当前工具栏包含：预览/编辑分段、批注、修订、目录、页码上一页/下一页（文本 `‹ ›`）、缩放、适应宽度、保存、更多；`DocViewer.jsx` 头部包含批注、刷新、信息、系统打开、文件管理器、文件类型 tab。

**替换清单**

| 位置 | 当前 | 替换为 Tabler |
|---|---|---|
| 预览/编辑 | `eye` / `penTool` | `IconEye` / `IconPencil` |
| 批注 | `comment` | `IconMessage`（与聊天评论区分可用 `IconMessageCircle`） |
| 修订 | `history` | `IconHistory` |
| 目录 | `list` | `IconList` |
| 上一页/下一页 | 文本 `‹` / `›` | `IconChevronLeft` / `IconChevronRight` |
| 缩放/适应宽度 | select + 文本 | select 不变；适应宽度可加 `IconArrowsHorizontal` |
| 保存 | `check` | `IconCheck` |
| 更多 | `more` | `IconDots` |
| 高保真预览 | `eye`/`globe` | `IconEye`（与预览分段区分时用 `IconWorld`） |
| 刷新渲染 | `refresh` | `IconRefresh` |
| 信息 | `info` | `IconInfoCircle` |
| 系统打开/文件管理器 | `externalLink`/`folderOpen` | `IconExternalLink` / `IconFolderOpen` |
| 关闭 | `close` | `IconX` |
| 文件类型 tab | `ICONS[ext]` | 复用彩色底 + Tabler 文件类型字形 |

**去重要求**：Word 工具栏的 `IconEye`、`IconPencil`、`IconHistory`、`IconList` 等沿用全局映射，不单独换一套；`IconComment` 与聊天评论的 `comment` 若同时存在，优先统一到一个语义（评论/批注用 `IconMessage`，群聊消息用 `IconMessageCircle`），并在映射表里保持唯一目标。
