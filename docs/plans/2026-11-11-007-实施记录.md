## 1. 交付内容

```
.claude/skills/echarts-canvas-chart/
├─ SKILL.md                       # frontmatter（requires: npm:[echarts]）+ 使用流程/排错手册
├─ scripts/render-chart.mjs       # SSR 渲染脚本（echarts 经 createRequire 从 --depsDir 解析；不 eval）
└─ templates/
   ├─ bar-compare.json            # 柱状对比（区县客运量）
   ├─ line-trend.json             # 折线趋势（公铁水三年）
   ├─ pie-share.json              # 占比环图（出行方式）
   ├─ bar-stack.json              # 堆叠柱（分时段出行）
   └─ sankey-od.json              # OD 桑基（县市→莲都，DAG）
```

- 技能可被项目 agent 发现：`listSkillCatalog({workspace, projectDir})` 命中 `echarts-canvas-chart`（source=project.claude，目录 68 项），description 经块标量正常解析。
- 渲染脚本约定：`--option/--out/--width/--height/--depsDir`；echarts SSR（`renderer:"svg", ssr:true`）；退出码 0/2(缺依赖)/3(参数)/4(option 非法)；option 仅纯 JSON、≤512KB、不 eval。

## 3. 实施偏差

| # | 偏差 | 原因 | 处置 |
|---|---|---|---|
| 1 | 桑基模板初版数据成环（松阳→莲都 与 莲都→松阳），echarts 报 "Sankey is a DAG… cycle" | 模板数据设计疏漏 | 改为单向 OD（县市→莲都 + 青田→缙云、松阳→云和县际），并替换弃用 API `focusNodeAdjacency` → `emphasis:{focus:"adjacency"}`；SKILL.md 排错表提示桑基须 DAG |
| 2 | echarts 安装实测为 6.1.0（计划预期 5.3+） | npm 默认 latest | SSR `renderToSVGString` 在 v6 保留，实测通过；requires 未锁小版本 |
