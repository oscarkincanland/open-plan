## 7. 风险与回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| ChatPanel 语义移植不全 | 引用徽章/HITL ask 卡片/活动摘要丢失或错位 | 冲突块之外逐段对照本地 diff；浏览器冒烟 + 定向测试 |
| 远程删除旧会话样式 | 本地样式块引用失效 | 合并后全局检索本地新增类名，确认无孤儿规则 |
| `activitySummary` 与 RunFold 双摘要 | 过程区重复信息 | 按 D-3 并入折叠行；必要时开关默认关 |
| Office 闸门自动开启 | 非写作路由行为变化 | 核对 `officeGateActiveFor` 判定；跑基线对照测试 |
| 设计令牌计数变化 | `test:design-tokens` 红灯 | 先确认远程是否改变基线，再决定调阈值或修本地硬编码 |
| ADR 编号错位 | 文档引用断链 | 合并后 grep `0012`/`0013` 全量核对 |
| 网络不稳定 | fetch/推送失败 | 临时 IP + Host 头（仅拉取），完成后恢复配置 |

**回滚路径**：`backup/pre-merge-v0.13.13-20261102` 分支 + `snapshot-20261102` tag；必要时按合并提交整体 revert，不 `reset --hard`。
