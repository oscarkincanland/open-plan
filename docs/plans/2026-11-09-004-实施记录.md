## 2. 实际改动

### 服务端

- `server/创作画布.mjs`
  - 新增 `createBoard` / `duplicateBoard` / `updatePages`；
  - `writeBoard` 支持 `page/title/role/layout/runId/summary`，新建板一次原子登记；
  - `deleteBoard` / `updateCanvas` / `writeBoard` / `createCanvas` / `importCanvas` 接入画布级版本；
  - 新增 `.history/index.json` + `objects/<sha256>`、`listCanvasVersions` / `readCanvasVersion` / `diffCanvasVersions` / `restoreCanvasVersion`；
  - 恢复板时从当前文件 rev 起算，保持 rev 单调；
  - 恢复整画布时把版本中不存在的板移入 `.trash/restore-<时间戳>/`；
  - 保留旧 `.history/*.jsonl` 板级快照与 `restoreBoardHistory` 兼容。
- `server/index.mjs`
  - 新增 `POST/DELETE /api/canvas/:slug/board`、`POST /api/canvas/:slug/board/duplicate`、`PATCH /api/canvas/:slug/pages`、`GET /api/canvas/:slug/operations`；
  - `GET /api/canvas/:slug/history?scope=canvas`、`GET /history/:n`、`GET /history/diff`、扩展 `POST /history/restore`；
  - 所有画布写路由统一 `canvasEvent()` → `appendEvent()` 广播全局事件；
  - 导出完成发 `canvas_exported`。
- `server/agent.mjs`
  - `canvas_write` 新增 `duplicate_board`，`add_board` 支持 `page/template/role` 并改走 `createBoard`；
  - `canvas_delete` 的 `delete_board` 改走模块软删；
  - 事件补 `scope/boardPath/changedPaths/actor/runId`。
- `server/事件注册表.mjs`
  - `canvas_changed` 增加可选 `scope/pageId/changedPaths/runId`；`canvas_created` 补 `actor/runId`；`canvas_exported` 补 `workspace/actor/runId`。
- `server/context.mjs`
  - `parseReferences` 支持 `@画布[...]`；
  - `resolveCanvasReference` 校验路径并返回画布/板/页/元素元数据；
  - `readReference` 生成 ≤4000 字符的结构化上下文（含选中元素 JSON 与“只改引用范围”约束）。

## 4. 偏差与边界

1. **版本时间线替代板级历史面板**：UI 使用画布级版本；旧板级 JSONL 与 `restoreBoardHistory` 保留，供兼容/回退，不再作为主交互。
2. **整画布恢复会移动多余板**：版本中不存在的 `*.board.json` 移到 `.trash/restore-<时间戳>/`，不物理删除；兼容 `.dc.html` 不参与版本。
3. **HTTP 事件走全局流**：ChatPanel 不再转发 `canvas_changed`，避免双重刷新；线程 SSE 中的工具活动仍用于“正在编辑”。
4. **UI 编辑也会广播**：同标签保存回环到全局事件时，组件用本地 rev 跳过自身变更，避免清空撤销栈。
5. **新画布自动打开**：仅当前会话（threadId 匹配）自动开标签；其他会话不抢焦点。
6. **元素级引用已实现**：`#element=<id>` 进入 range，服务端返回选中元素 JSON；元素不存在时明确提示。
