## 0. 判定标准

**算“摘要”（本次要收敛）**：对已经发生的内容做二次概括/统计，且不提供新的可操作信息。

- 步数、工具调用统计、事件数、token 用量、任务摘要段落、折叠头“N 步”。

**不算“摘要”（保留）**：

- 答案正文（`SummaryBlock` 承载的模型终稿）——删掉它等于删掉回答。
- 数据卡片：产物卡、改动卡、站点 chip、读取字数、耗时/状态。
- 状态与动作：运行中、当前动作、等待审批、需行动提示。
- 错误与风险提示：失败原因、重定向标注、未完成项。

## 2. 收敛后的终态

一轮结束后，会话流只剩：

```
[折叠头]  已完成 · 用时 1 分 23 秒        ← 状态 + 用时，无步数
[答案]    模型终稿（连续 Markdown）
[产物卡]  本轮产物 · N 个文件（有才显示）
[改动卡]  本轮改动 · N 个文件（有才显示）
[需行动]  仅 blocked/partial/failed/cancelled
```

运行中仍直铺时间流，消息头显示“已运行 X · 当前：动作”。

**删除**：token 用量行、执行过程事件统计、旧过程 meta、产品面板任务摘要段、浏览器卡步数、恢复态步数与“完成后自动汇总”。
**保留**：答案、产物/改动卡、站点 chip、状态/耗时、错误与未完成项。
