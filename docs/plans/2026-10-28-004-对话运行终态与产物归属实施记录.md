## 一、实际改动

| 文件 | 改动 |

| `server/agent.mjs` | `emit` 推送前检查 `isRunTerminal`，迟到事件只审计 |

| `client/src/App.jsx` | 本轮范围“跟随最新/钉住历史”；自动打开焦点守卫与“本轮新产物”入口；`file_changed` 合并刷新 |
| `client/src/components/工作产物面板.jsx` | 疑似变更分组；会话范围按路径去重；刷新合并；历史轮次标题 |

| `client/src/components/ExcelGrid.jsx` | “仅显示单元格值”标注；高保真只读预览 |
| `client/src/components/PptxViewer.jsx` | Canvas 能力提示 |
| `client/src/预览能力.js` | 新增预览能力矩阵 |
| `client/src/components/DocViewer.jsx` | 预览头部展示能力标签 |
| `client/src/styles.css` | 范围提示、疑似分组、Office iframe 样式 |
| `scripts/产物归属与终态测试.mjs` | 新增 `test:run-attribution` |
| `scripts/Office预览能力测试.mjs` | 新增 `test:office-preview` |
