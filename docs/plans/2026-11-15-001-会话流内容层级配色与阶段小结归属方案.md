## 2. 待决策：阶段小结怎么处理（D7）

### 问题

1. **视觉无层级**：阶段小结（过程里的中间结论）与本轮总结（终稿）**同色同字号 14px**，读者无法一眼分出"这是过程里的过渡"还是"这是最终答案"。
2. **归属与规范冲突**：`REQUIREMENTS.md` R3 与《会话流前端规范》§2 都写着「**折叠的是过程，中间小节结论与本轮总结留在折叠体外常显**」；实测 5/5 阶段小结都在折叠体内，收起整轮时它们一起消失。
3. 阶段小结与本轮总结内容可能高度重叠（模型常在阶段里先给半成品结论），收起后读者只剩终稿——从"信息不丢"看是退化。

### 选项

| # | 阶段小结颜色/字号 | 是否移出折叠体 | 影响 |
|---|---|---|---|
| **A（推荐）** | `--muted` + 13px（次级但可读），首行加「阶段小结」标签（现有 `.tb-cap`） | **是**，按 R3 常显 | 与 R3/规范一致；收起过程后仍能看到中间结论；需要改 `buildProcessSegments`：`text` 段落在 v3 下渲染到折叠体之外 |
| B | `--muted` + 13px | 否（仍随过程收起） | 只解决视觉层级；与 R3 的"常显"仍冲突，但改动最小 |
| C | 保持 `--text` + 14px，仅靠「阶段小结」标签区分 | 否 | 等于不改，不推荐 |

### A 的实现要点（若确认）

- `ChatPanel.jsx`：v3 分支把 `text` 类段落提到 `<RunFoldBar>` 之外渲染（保持真实输出顺序：过程组 → 阶段小结 → 过程组 → …）；
- 折叠头文案不变（R3 口径：`{状态} · 用时 · {N} 步`）；
- 规范 §2/§8 同步一句"v3 下阶段小结常显、颜色取 `--muted`/13px"；
- 新增断言：`test:transcript-rows` 检查"阶段小结不在 `.run-fold-body` 内"。

## 3. 关于「每轮的澄清」

代码检索结论：**本仓 UI 里没有「澄清」这个字样的组件或文案**（`grep -rn 澄清 client/src` 无命中）。

与"每轮澄清"最接近的有三处，请你确认指哪一个：

| 候选 | 代码位置 | 现状 | 与阶段小结是否冲突 |
|---|---|---|---|
| ① ask_user 提问卡 / 审批卡 | `timelineInteractionItems` → 渲染在折叠体外（`ChatPanel.jsx:7427`） | 折叠外常显 ✓；`interactionHub` / `composerUnified` / `askAssumption` 开关当前均为**关** | 不冲突（位置正确，且与阶段小结不同层） |
| ② 每轮总结（本轮总结 SummaryBlock） | `ChatPanel.jsx:7428` 起 | 折叠外、`--text`/14px | **有冲突感**：与阶段小结同色同字号，读者会以为重复 |
| ③ 模型在每轮里自行写的"澄清/确认"段落 | 属于 `text` 块（就是阶段小结本身） | 被折叠进过程 | 与 ② 视觉重复，见 D7 |

如果你说的是 ①，那答案是"不冲突，位置正确"；如果是 ②，冲突点就是 D7-A 要解决的；如果是 ③，那就是把同一种文本块当两种东西用了。

## 5. 用户确认与落地（2026-11-15）

用户口径：

> 本轮综合和模型这个澄清有冲突的还是保持既有模型的澄清吧，本轮总结不放了，ask 这个继续保留吧，然后思考的字体也没有变化呢？

落地为 **D7-A 变体**：

| 决定 | 实现 |
|---|---|
| 保留模型自己的正文（澄清 / 阶段小结 / 最终答复） | `hiddenFinalTextIndex` 在 v3 下置 -1，最终文本块不再被隐藏；**阶段小结随过程一起折叠（折叠体内）**，**只有最终答复渲染在折叠体外**（`.tl-list-replies`，不带「阶段小结」标签） |
| 取消「本轮总结」卡片（SummaryBlock） | v3 下不渲染 `SummaryBlock`；`showTimelineSummary` 仅基线生效 |
| 折叠体只装过程 | `RunFoldBar` 的 children 只放 `segment.type === "group"`；正文 item 渲染在折叠头之后 |
| ask / 审批卡保留 | `timelineInteractionItems` 位置不变（折叠体外） |
| 思考再淡一档 | 新增 `.tl-row-think`：动词/对象 `--dim` + 12.5px；展开正文 13px `--muted`；运行中思考行回 `--muted` |

实测（无头 Edge，真实历史会话，v3 开）：`.sum-block` 0 个；单条消息内 折叠体内 3 块「阶段小结」+ 折叠体外 1 块最终答复；折叠体 `hidden="until-found"`、折叠态可见文本 = 折叠头 + 结论（无「阶段小结」标签）；无控制台报错。思考行 `#828d83`/12.5px、思考正文 `#9ca69d`/13px、工具行 `#9ca69d`/12px、折叠头 `#828d83`/12px。
