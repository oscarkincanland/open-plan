## 2. 三件事的落地

### A. 视频/图片加载不出来（缺陷修复）

- 根因（已实测）：元素 `src` 按**板目录**保存（`../assets/canvas_5x.mp4`），素材接口按**项目根**解析且拒绝 `..` → `400 CANVAS_PATH_DENIED`；同一接口用 `assets/canvas_5x.mp4` 返回 `200 video/mp4`。
- 修复：渲染前用 `素材项目相对路径()` 归一化（`boards/vid1.board.json` + `../assets/canvas_5x.mp4` → `assets/canvas_5x.mp4`）；接口安全边界不变（仍拒 `..`、仍要求 project 内）。
- 覆盖 image / svg / video 三种元素及 video 的 `poster`；播放浮层与编辑视图都传板路径。

### B. HTML 导出（新格式）

- 导出对话框新增「HTML · 单文件网页，图片与视频内嵌、可直接播放」。
- 产物：`designs/<slug>/exports/<标题>-<时间戳>.html` 一个文件，媒体全部 base64；对象板逐元素绝对定位（文本保留换行/对齐/字号/色值），兼容板 `html` 用沙箱 iframe `srcdoc`（不执行脚本）、`svg` 板内嵌为图片。
- 视频为真 `<video controls preload=metadata playsinline>`（可播放），与 SVG/PPTX 的静态降级不同；底部页码 + ←/→ 与按钮翻页；不需要内置浏览器。

### C. 显式保存按钮

- 工具条「保存」：`有脏 && !只读 && !保存中` 时可用并高亮；点击清掉 400ms 去抖定时器，立刻提交待补画布索引 + 所有脏板；`Ctrl/Cmd+S` 等效（阻止浏览器另存为；只在画布编辑区可见时接管）。
- 自动保存（400ms 去抖 + `expectedRev` CAS + 冲突保留）完全保留。
