**验收**：`test:chat-timeline`、`test:chat-layout`、`test:browser`、`test:motion`、`test:chat-flow`、`test:design-tokens`、`test:a11y`、`npm run verify` 全绿；`git status` 中会话流残留清零。

### P0-1 收敛 `collectReferencedPaths` 语义

**问题**：003 的 T-06 为修复 `create` 目标被误判为缺失，改为无条件跳过 `args[1]`，打破了 `Review报错修复回归测试` 的既有契约（`add 报告.docx` 的文档自身也算引用）；`test:office-ref-preflight` 又要求 `add` 目标不算引用，两套测试互相矛盾。

**决策建议**：只对 `create` 跳过目标文件；`add` / `set` / `batch` 仍把目标文件当引用（物化无害，且历史测试依赖）。

**内容**：`server/office参数.mjs` 按 `args[0]` 判定；同步 `scripts/Office引用预检测试.mjs` 与 `scripts/Review报错修复回归测试.mjs`。

**验收**：`test:office-ref-preflight`、`test:review-fixes`、Office 13 条链路、`npm run verify` 全绿。

### P0-2 处理剩余两个红项

| 失败 | 现状 | 处置 |
|---|---|---|
| 成果可信度测试 | `autoDeliverable` 期望 true，实际 false；与 10-31 计划无明显关系 | 先定位 `finishRun` 的归属规则；若是真实缺陷，修代码并补回归；若是陈旧期望，按语义更新测试。不得直接改断言迁就实现 |

**验收**：38 项 CI 全绿，或只剩已确认、已登记的基线失败（当前目标是不留红项）。
