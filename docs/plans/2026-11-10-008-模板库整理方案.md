## 1. 目标 / 非目标 / 成功标准

### 1.1 目标

1. 模板库 UI 只展示**真实存在且可预览**的模板；空分类不再出现。
2. opendesign 保留与"交通规划汇报"目标匹配的资产，移除无关/死目录；库体积从 28.4MB 降到 ~6MB（D1+D2 中档后）。
3. traffic-material 14 份全部达到"结构完整、引用现行"状态（03 修复为唯一 P0）。
4. agent 提示词中的模板数量/清单与实际一致。

### 1.2 非目标

- 不动创作画布模板线（`server/创作画布.mjs` 内置 4 模板 + `designs/.templates/`），那是计划 004 的范围。
- 不重写 14 份模板的领域内容（只修结构缺陷与引用年份，不推翻既有骨架）。
- 不给 opendesign 模板做逐个渲染验收（工作量大且不影响本次整理）。
- 不引入模板元数据/标签系统（tpl.mjs 保持目录扫描约定）。

### 1.3 成功标准

- `/api/templates` 每个分类都有 ≥1 条记录；模板库页面无"该分类暂无模版"的分类标签。
- `templates/opendesign` 下无 open-design-landing；前端 `npm run build` 通过、模型列表品牌图标正常（SVG 内联验证）。
- 03 模板编号连续（3.1→3.2→…→§10 完整）、§4 覆盖第一章全部 8 条、§5 存在或重排后连续。
- 05/09 的标准引用为现行版本；新增完整性测试通过。
