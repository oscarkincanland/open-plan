## 3. 方案 A：工作区开始页（新视图 `home`）

### A1 触发与定位

- 新增单例画布视图 `kind: "home"`（标题「开始」，图标 `grid`），**默认不占持久化标签**：每次切换工作区时以「临时视图」打开，切走后即销毁。
- 触发点：
  1. 点左侧项目卡片（`handleProjectChange` 成功后）；
  2. 顶栏工作区下拉切换成功后；
  3. 画布为空且当前会话是新会话时（可选，见待确认 1）。
- 不打断已有工作：切换工作区时若画布已有标签，开始页**以新标签打开并激活**，不关闭用户原有标签（受 `MAX_CANVAS_TABS=12` 限制）。

### A2 页面内容（重做图三 + 图二）

```

│  /D:/老U盘/金东农村公路网规划      12 个文件 · 3 个会话 · 最近 2 小时有改动 │
│  [搜索文件或命令  Ctrl P]                                        │
├ 入口卡片（2 列自适应，图标 + 标题 + 一句说明）─────────────────────┤
│  工作区文件      浏览/搜索当前工作区文件            [打开文件树]      │
│  任务摘要        本轮结论、产物与验收               →               │
```

- 入口卡片复用图三现有动作名与分发逻辑（`onPlusAction` 的 action 常量），新增 `diagnostics`（会话数据诊断）与 `more`（更多工具：对象栏/工作流等按开关显示）。
- 「更多工具」不是新的浮层：点击后把剩余入口就地展开成第二行卡片（避免再次出现向下弹窗）。
- 搜索框复用现有命令面板（`CommandPalette` / `setPaletteOpen(true)`），不新写一套搜索。
- 地图/画布入口沿用现有可用性判断（未绑定地图项目时给禁用态与原因，与图三一致）。

### A3 与「+」菜单的关系

保留「+」菜单作为熟练用户的快捷入口（DESIGN 已定义），开始页是同一批动作的**可视化版本**；两者共用同一份 action 常量，避免两处文案漂移。

## 4. 方案 B：本轮产物卡重做

### B1 只列主要交付物 + 其余折叠（推荐）

- 排序：`交付(deliverable)` 优先 → 类型优先级（docx/xlsx/pptx/pdf > md/html > svg/png > 其他）→ 本轮写入顺序。
- 默认展示 **3 条**；其余折叠为一行 `还有 N 个文件 · 展开`，展开后完整列表（不再用 320px 内部滚动截断）。
- 卡片头部把计数改成人话：`主要交付 2 · 其他 4 · 待确认 0`，并保留「在产物面板查看」。
- 新增一行改动摘要：`本轮改动 6 个文件（新增 6 / 修改 0 / 删除 0）`，点击跳「文件改动」页签。

### B2 图标/缩略（待确认口径）

- 先修可见性：`.product-card-icon` 只做容器，需保证内部 `.file-type-icon` 的彩色底与字形可见（实测后决定是提高对比度还是把 30px 容器底色去掉）。
- 可选的「预览缩略」：图片（png/jpg/svg/webp）直接显示缩略；HTML/PDF/Office 取首屏截图成本高，**不建议**默认做（需额外渲染/缓存），可作为后续独立项。

### B3 「打开方式」（不要向下弹窗）

三个候选（见待确认 2）：

| 选项 | 形态 | 评价 |
|---|---|---|
| **B3-甲（推荐）** | 每条产物右侧常驻两个图标按钮：`打开`（内置预览）+ `在文件夹中显示`，再加一个 `系统打开`（用默认程序）；全部是图标 + title，无浮层 | 无弹窗、一眼可见、键盘可达；占位略宽 |
| B3-乙 | `打开` 主按钮 + 点击后弹出**居中对话框**「选择打开方式」（内置预览 / 系统默认程序 / 在文件夹中显示） | 信息最全，但多一次点击，且要新建对话框组件 |
| B3-丙 | 维持单个 `打开`，把系统打开/文件夹放进右键菜单 | 最省空间，但发现性差（用户已抱怨"找不到"） |

无论哪个：都需要把「在文件夹中显示」从文件树右键菜单**抽成可复用函数**（现在只在 `SessionSidebar.jsx:733`），供产物卡调用。

## 5. 验收口径

1. 点左侧任一项目卡片 → 右侧画布打开「开始」页并激活，页内工作区名/路径与点击的项目一致；已打开的其他标签不被关闭。
2. 开始页每个入口都能打开正确视图（工作区文件树 / 工作产物 / 改动 / 浏览器 / 地图预览 / 创作画布 / 会话诊断），未满足条件时是禁用态并给出原因。
3. 开始页不产生向下弹出的浮层；「更多工具」为就地展开。
4. 本轮产物卡：默认只显示 3 条主要交付物 + `还有 N 个文件`；展开后能看到全部且不再出现 320px 内部滚动截断。
5. 图标：同一条卡片链路上，docx / html / md / svg 的图标与底色肉眼可区分（截图对比）。
6. 「打开方式」：能从产物卡直接在内置预览 / 系统默认程序 / 文件夹三种方式之间选择，且不出现向下浮层。
7. 回归：`npm run verify` + `test:chat-layout`、`test:workspace-panel`、`test:artifact-icon`、`test:preview-identity`、`test:run-attribution`、`test:ui-guard`、`test:a11y`（后两者有既有失败，需证明未新增）；新增开始页与产物卡回归测试各至少 1 条。
8. 真实浏览器在 1440×900 / 1280×800 / 1024×768 三档 + 暗/亮主题截图。
