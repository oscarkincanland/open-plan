## 1. Context

四项需求：

1. **绑定 bug**：新建图层/画布后 Agent 仍工作在 `zhejiang-map`。
2. **地图文件树**：地图模块新增文件树入口，可查看项目/工作区文件、按文件夹搜索、`@` 到对话。
3. **agent 归档目录**：每个新建项目内建生成内容目录，集中存放 Agent 在地图模块生成的内容。
4. **初始页地图预览**：画布“新会话”页签点击地图会话时显示上一轮地图样式（全部可见图层），并可从该页继续编辑；绑定需跨重启持久化。

**P0 已实施**（上一轮）：`client/src/地图/地图上下文.js`、`App.jsx` 合并上下文、`MapPanel` `initialProject`、`MapViewer` 视口带 `project`、`agent.mjs` 默认项目文案；`test:map-binding` 10 项通过、`test:map-canvas` 17 项通过、`npm run build` 通过。本计划在此基础上完成 P1–P4，P0 只补运行时复核。

## 3. P1 地图文件树（项目 + 工作区）

### 3.1 服务端

- `server/map.mjs` 新增 `listProjectFiles(name, { q = "", maxDepth = 4, maxFiles = 500 })`
  - 根为 `projectDir(name)`；跳过 `tiles/`、`.trash/`、隐藏文件；`path.resolve` 前缀校验防穿越。
  - 返回 `{ project, files: [{ rel, name, dir, ext, size, mtime }], truncated }`。
  - `q` 对 `dir + name` 大小写不敏感匹配（按文件夹搜索）。
- `server/index.mjs` 新增 `GET /api/map/project/:name/tree?q=`（项目不存在 404）。
- 复用既有：`projectDir`、`MAPS_ROOT`、`readJson`、`/api/files`、`/api/files/search`（工作区页签）。

### 3.2 客户端

- 新建 `client/src/components/地图文件树.jsx`
  - props：`{ project, workspace, insertChatText, onOpenFile }`。
  - 两页签：**项目文件**（`mapProjectTree`，按目录分组 + 搜索框 + `@` 按钮）；**工作区文件**（复用 `listFiles/searchFiles`，目录导航 + 搜索）。
  - 行渲染复用 `文件类型图标.jsx`；`@`：`insertChatText("@" + relPath)`（项目文件路径 `maps/{project}/layers/x.geojson`）。
  - 点文件：`onOpenFile?.(relPath)`；不支持预览的类型给出提示。
- `client/src/components/MapPanel.jsx`：顶栏新增 `folder` 图标按钮（`btn-sm` + `title="项目文件树"`），`fileTreeOpen` 状态 + 右侧浮层；关闭不销毁地图。
- `client/src/api.js`：新增 `mapProjectTree(name, q)`。
- 复用：`Icon`（folder/file/search/at 已注册）、`文件树页签.jsx`、`文件排序.js`、`App.insertChatText`。

## 5. P3 初始页地图预览与会话持久化

### 5.1 会话持久化

- `server/index.mjs`
  - 新增 `POST /api/sessions/:id/map-context`：校验 `mapProject` 存在于 `maps/`（否则 400）；`mapView` 白名单（`center[2]/zoom/bounds[4]/updatedAt`，数值有限性）；复用 `updateSessionHeader`（L3141）原子写。
  - `GET /api/sessions` 列表与详情回传 `mapProject / mapView`（只增字段）。
- `client/src/api.js`：`updateSessionMapContext(sessionId, payload)`。
- `client/src/App.jsx`
  - `handleSelectSession` 写入 `mapContexts[conversationId] = { ...(session.mapView || {}), mapProject: session.mapProject || "" }`。
  - 新增 `persistMapContext`（1500ms 防抖 + 内容相等跳过），`currentSessionId` 非空时写。
  - 会话列表刷新后用当前会话的 `mapProject` 回填 `mapContexts`（重启恢复）。

### 5.2 只读小地图

- `client/src/components/MapViewer.jsx`
  - 新增 `readOnly`：隐藏导入工具条/文件选择/属性写操作/绘制；保留只读点击查询。
  - 新增 `initialView`：加载后 `jumpTo({ center, zoom })`（优先 `initialView`，否则 `config`）。
- 新建 `client/src/components/MiniMapPreview.jsx`
  - props `{ project, view, height = 160, onOpen }`；`mapProject(project)` → `config` → `<MapViewer project readOnly initialView={view} onViewportChange={() => {}} />`。
  - 项目不存在/加载失败显示空态与“打开地图”；标题显示项目名/图层数。
- `client/src/components/新会话页签.jsx`
  - 会话卡片带 `mapProject` 的显示地图徽标；点击卡片设置 `expandedSessionId`（**同一时间只渲染一个 MiniMap**）。
  - 展开卡片内嵌 `MiniMapPreview` + “继续编辑地图”按钮（`onOpenMap(session)`）；其余卡片保持原切换行为。
- `client/src/App.jsx`
  - `handleOpenMapOfSession = async (session) => { await handleSelectSession(session); setActiveModule("map"); }`，传给 `新会话页签`。

## 6. 接口与数据结构

```json
GET /api/map/project/:name/tree?q=layers
→ { "project": "yiwu-ai", "files": [{ "rel": "layers/x.geojson", "name": "x.geojson", "dir": "layers", "ext": ".geojson", "size": 123, "mtime": 0 }], "truncated": false }

POST /api/sessions/:id/map-context
{ "mapProject": "yiwu-ai", "mapView": { "center": [120.07, 29.31], "zoom": 10, "bounds": [..4], "updatedAt": "..." } }
→ { "ok": true, "mapProject": "...", "mapView": {...} }
```

会话 header 新增：`mapProject: string`、`mapView: { center, zoom, bounds, updatedAt }`（只增不改）。
`agent/manifest.jsonl`：`{"ts":"...","sessionId":"...","runId":"...","action":"analysis","layerId":"heat-1","paths":["layers/heat-1.geojson"],"title":"热力图","bytes":1024}`。

**人工验收（不自动执行，避免真实模型调用与写操作）**：
1. 新建 blank 画布 → 等待视口上报 → 发送地图指令 → 检查 `/api/runs` 最新 run 的 `task.mapProject` 为新项目。

## 8. 风险与限制

- **临时层不回放**：`map_action` 事件 `persist:false`；初始页小地图只显示项目正式图层与上次视口。若要回放临时分析层，需新增事件持久化，单独立项。
- 会话 header 写入频率：1500ms 防抖 + 内容相等跳过；复用原子写。
- 文件树大目录：跳过 `tiles/`，硬上限 500 条 + `truncated`；不做懒加载递归。
- 工作区页签沿用 `/api/files` 扩展名白名单，不显示 geojson/shp；地图项目文件由项目页签覆盖。
- MiniMap 性能：单实例、点击才挂载、160px、卸载即销毁。
- 不改批量导出路径，避免破坏跨项目批次语义与既有测试。
- P0 已有未提交改动；本轮继续在其之上增量实现，提交统一在用户确认后执行。
