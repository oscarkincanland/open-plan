## 2. 目标与非目标

**目标**：以上 8 项一次性收口；全部走既有令牌与动效闸门；`npm run verify` + 目标 test:* 全绿后提交。
**非目标**：不改 SSE 事件契约；不改 RunSummary（任务中心/Review）的产物卡逻辑本身（F6 只改消息流内新路径的引用格式）；不做亮色主题重设计；不引入 npm 依赖。

## 3. 分项设计

### F2 打字机（新 hook `useTypewriter`，文件 `client/src/components/会话流/useTypewriter.js`）

- 复用 [流式文本队列.js](../../client/src/components/流式文本队列.js) 的 `计算展示字符数`（90 字/秒、积压 0.24s 内自动追赶、reducedMotion 直通全量）。
- 实现：`useTypewriter(fullText, { enabled })` → rAF 循环里按帧调用 `计算展示字符数({ remaining, elapsedMs, reducedMotion })`，返回「应显示的子串」；`enabled=false` 或文本变短（流被替换/历史回放）时直接返回全文，不播动画。
- 接线点（仅两处）：
  1. `renderTimelineItem` 的 `text` 分支：`streaming && isStreamingText` 时 `enabled=true`；
  2. thinking：展开态且该思考块仍在流式（`streaming` 且为最后一个 thinking 项）时 `enabled=true`。
- 文本切换保护：fullText 变化时保留已展示字符数，只追加不回退（`Math.max(shown, prevShown)`）。

### F2-b 思考折叠态滚动预览（复用既有跑马灯，不自造新动效）

- 折叠态的一行条目 `obj` 槽位改为：展示**最新未读完的思考片段**（截 ~60 字），用既有 [跑马灯文本.jsx](../../client/src/components/跑马灯文本.jsx)（`.marquee` 体系）做横向滚动。
- 依据：跑马灯已纳入统一动效闸门（marquee-scroll / marquee-shine 等 keyframes 与降级规则齐备），不新增无限动画，动效治理测试零改动风险。
- 展开态：打字机（见上）；流式结束后恢复静态全文（思考行显示字数+耗时）。

### F3 子代理默认折叠

- `renderTimelineItem` 的 subagent 分支改用 `TimelineRow`：头 = flow 图标 + 「子代理」+ `role · task 前 40 字` + 耗时/状态点；detail = 原 `SubagentCard`。
- 默认 `defaultOpen=false`；运行中（block.status 运行态）也默认收起，仅状态点脉冲提示。

### F4 字重统一

- styles.css 会话流分区全部 `font-weight: 600/700` → `400`（`.rf-title`、`.tl-verb`、`.sum-what b`、`.sum-conclusion`、`.sum-label`、`.ac-*`、`.rf-chip`）。
- 层级只剩字号（见 §4 参数表）与颜色（正文 `--text`、次要 `--dim`、元数据 `--muted`）。
- Markdown 内容内的 `<b>/<strong>`（模型强调）保留原样——那是内容语义，不是 UI 样式。

### F5 字体 B：内置 MiSans

- **资产**：MiSans Regular（400）+ Demibold 不引入——按 F4 只需 400 一档；woff2 子集（常用 CJK 3500 字 + ASCII + 项目高频字），目标 ≤ 900KB。
- **获取**：实施时从 MiSans 官方发布页（hyperos.mi.com）或 npmmirror 静态 CDN 下载 TTF/OTF 后，用 `pyftsubset`（fonttools）离线子集化为 woff2，产物入库 `client/src/assets/fonts/`；**若实施环境无外网**，回退方案 A（系统栈升级 `"Segoe UI Variable Text"` 优先），并在实施记录注明。
- **接线**：
  - `client/src/styles.css` 顶部新增 `@font-face { font-family: "MiSans"; src: url(...woff2) format("woff2"); font-display: swap; font-weight: 400; }`；
  - `body` 字体栈改为 `"MiSans", "Segoe UI Variable Text", "Segoe UI", system-ui, "Microsoft YaHei UI", "PingFang SC", sans-serif`（MiSans 加载失败/未覆盖字符自动回退）；
  - 等宽栈不变（Cascadia Code / Consolas）。
- **验收**：`test:design-tokens`（色值棘轮不受影响）、构建体积增幅 ≤ 1MB gzip、亮/暗主题截图各一张。

### F6 本轮产物恢复既有格式

- `ArtifactCard` 内部渲染改为复用既有产物行标记/类名（与 RunSummary 产物页签一致）：类型图标 + 名称 + `类型 · 格式 · 大小` + 「待确认」徽标（!attributed 时）+ 「打开」按钮 + 行尾「在产物面板查看」链接。
- 保留：卡头「本轮产物 N 个文件」、>8 个折叠「+N」、打开回调走 `onOpenFile(path)`。
- 移除：自创 `ac-file-row` 结构与「交付/定位/回滚」按钮组（回滚入口保留在任务中心运行视图；「定位」并入产物面板链接语义）。
- 数据源不变：`artifactsFromView(runCardView)` + `buildArtifactIndex`。

### F7 已运行时间修复

- **事件源**：`runTraceForTimeline` 的事件改为「anchor 轮优先实时流」：`executionFlow?.events?.length ? executionFlow.events : (runSummary?.events || [])`——运行中折叠头秒数、当前动作、工具 run 状态点才能实时走。
- **startedAt 回退链**：`trace.startedAt → runSummary.startedAt → 消息 createdAt`。
- **已完成轮 0 秒**：`durationMs<=0` 且有 startedAt/endedAt 时重算；仍为 0 显示「不足 1 秒」，不再显示「0 秒」。
- tick 不变（live 时 1s interval）。

### F8 宽度统一

- 新令牌：`--msg-content-max`（默认 `min(100%, 720px)`，跟随现有容器 460/720/820 档位取 min）。
- `.msg-main` 内：`.rf-round`、`.sum-block`、`.ac-card`、`.run-result-action`、用户 `.bubble` 统一 `max-width: var(--msg-content-max)`。
- 用户气泡：`width: fit-content; max-width: var(--msg-content-max); margin-left: auto`（右缘与时间流右缘对齐）；padding 10px 14px → 12px 16px；圆角 12px（与 rf-round 同档）。
- 不改 `--chat-w` 与 center-chat-slot 容器宽度（那是布局层），只统一消息内容列。

### F1 ask/审批卡新视觉

- `renderTimelineInteraction` 外层包一行头（`TimelineRow` 壳，`defaultOpen`、不可收起）：ask = comment 图标 + 「等待你回答」+ 问题前 40 字；approval = shield 图标 + 「等待审批」+ 工具名。
- 卡体沿用 `AskBlock`/`ApprovalBlock` 本体（交互逻辑不动），仅外层视觉统一；位置保持在折叠头下方。

## 4. 排版参数表（实施基准）

| 令牌/规则 | 值 | 应用 |
|---|---|---|
| 字体栈 | `"MiSans", "Segoe UI Variable Text", "Segoe UI", system-ui, "Microsoft YaHei UI", "PingFang SC", sans-serif` | body 全局 |

| 块间距 | rf-round / sum-block / ac-card 相互 12px；时间流条目间 2px（不变） | |
| 内容列宽 | `--msg-content-max: min(100%, 720px)` | 消息内容列统一 |
| 气泡 | padding 12px 16px、圆角 12px、max 同内容列、右对齐 | 用户气泡 |
