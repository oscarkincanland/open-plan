# 工作区画布浏览器式整合实施记录

> 状态：已实施（有偏差，待用户验收）　日期：2026-10-31　分支：`feature/workspace-canvas`
> 关联计划：[2026-10-31-001-工作区画布浏览器式整合计划.md](2026-10-31-001-工作区画布浏览器式整合计划.md)
> 关联需求：R1、R5、R8、R13

## 一、实施范围

将右侧画布从“多个独立开关 + 双面板 + 两级页签”改为浏览器式单画布：

- 文档、工作产物、改动、浏览器、对象栏、领域工作流、子代理统一为画布标签；
- 画布只有一个宽度 `--canvas-w`，一个主拖拽条；
- 文件树改为右侧可收起抽屉 `--canvas-side-w`，支持目录导航；
- 工作产物内部为任务摘要卡 + “产物 / 链接”分段；
- 新建对话改为 `+` 菜单动作；
- 移除双面板与分页签宽度。

## 三、行为结果

### 画布

- `canvasTabs` 为唯一标签列表；`canvasOpen = tabs.length > 0 && !collapsed`。
- 文档标签按文件身份去重，可多实例；`artifacts/changes/browser/objects/workflows` 单例；`subagent` 临时标签。
- 标签 `×` 关闭；关闭当前标签选右邻、再选左邻；关闭最后一个标签画布收起。
- 右上角 `⌄` 收起画布但保留标签；顶栏“工作区画布”恢复。
- 标签支持拖拽排序、横向滚动、中键关闭、`Ctrl/Cmd+W` / `Delete` / 左右方向键。
- 画布宽度 `--canvas-w`（320–760）持久化；文件树抽屉 `--canvas-side-w`（200–340）持久化。
- 按工作区持久化标签；刷新后恢复视图标签与文档标签（文档通过重新打开恢复内容）。

### 文档

- `DocViewer` 不再渲染内部 `.doc-tabs`；打开文件直接创建/激活 `doc` 标签。
- 文档标签切换保持 DocViewer 挂载；文件 revision 更新时刷新原标签。
- 文档标签上限受总标签上限 12 约束。

### 文件树

- 抽屉自己请求 `/api/files?dir=`，不改变左侧文件页 `currentDir`。
- 目录优先显示；点击目录进入；面包屑返回；点击文件用完整相对路径打开文档标签。
- 第一版为“进入目录 + 面包屑”，未做原地懒加载展开。

### 工作产物

- 顶部任务摘要卡读取最近 Run 的 `completion/summary/verificationStatus`，展示结论、未完成项与阻塞。
- “产物 / 链接”分段；链接复用 `LinksPanel`，不再占一级标签。
- 全页“成果”模块仍通过 `WorkProductPanel tab="artifacts"` 工作。

### 新建对话

- `+` 菜单“新建对话”调用现有 `handleNewSession`：当前工作区新建独立 thread，并切换主对话；旧会话保留在历史。
- 不提供并排侧边对话。

### 手工验收

在隔离 worktree 启动 `PORT=3102 node server/index.mjs`，用内置浏览器验证：

1. 打开 `测试文档.md`：画布出现单个文档标签，DocViewer 不再显示内部文件标签栏。
2. 从文件树进入 `资料/` 并打开 `说明.md`：出现第二个标签；关闭当前标签后自动切回 `测试文档.md`。
3. 文件树显示 `资料`、`maps` 目录，可进入子目录、面包屑返回；点击文件打开预览。
4. `+` 菜单打开“任务摘要”：工作产物标签出现，含“产物 / 链接”分段；链接段显示空态。
5. `+` 菜单打开“浏览器”：出现浏览器标签。
6. 右上角 `⌄` 收起画布，标签保留；顶栏“工作区画布”重新打开后标签仍在。
7. `+` 菜单“新建对话”：文档标签清空，视图标签保留，主对话切换。
8. 刷新页面：文档标签、视图标签与文件树抽屉按工作区恢复。
9. 右侧始终只有一个画布，无双面板/第二列。

## 五、偏差与未完成项

1. **未单独新增 `工作区画布.jsx`**：画布容器直接在 `App.jsx` 渲染，新增 `画布标签栏.jsx` 与 `画布状态.js`。
2. **标签溢出菜单未做**：当前用横向滚动；未做“更多标签”下拉。
3. **文档 dirty 标记/关闭确认未做**：DocViewer 内部子编辑器未暴露统一 dirty 状态；关闭文档标签暂不提示未保存修改。
4. **真正并排侧边对话未做**：按计划延后。
5. **标签拖拽排序未做浏览器级自动化验证**：源码与逻辑已实现，手工未用鼠标拖拽验证；键盘 `Delete`/`Ctrl+W` 已手工验证。
6. **窄屏覆盖层、浏览器全屏、宽度持久化未做完整手工矩阵**：代码保留断点规则，建议验收时补测。

说明：`+` 菜单“搜索文件名”复用现有命令面板（计划允许的两种实现之一）；文件树第一版按计划只做“进入目录 + 面包屑”，原地懒加载展开属于计划中的第二版。
