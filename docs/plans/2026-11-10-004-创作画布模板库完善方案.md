## 1. 背景与现状

### 1.1 用户目标

画布主要用于制作 **PPT 与 HTML 汇报材料**；希望有“模板”概念：能选择模板、能导入模板，并明确如何操作。

### 1.2 现状（工作树已有一版未提交实现）

| 能力 | 现状 | 证据 |
|---|---|---|
| 内置模板 | `blank/cover/onepager/deck` 4 个 id；`deck` 实际只有 1 页封面 | `server/创作画布.mjs:1092-1149` |
| 用户模板库 | `designs/.templates/<slug>/project/`，格式 `oaw-canvas-template`；列表/导入/另存/删除函数已实现 | `server/创作画布.mjs:1151-1490` |

### 1.3 与“PPT/HTML 汇报”目标的差距

1. HTML 汇报画布（`.dc.html`）无法成为模板；用户最典型的“现成 HTML 版式复用”路径被堵死。
2. 内置 PPT 模板只有封面，不能作为“一份汇报”的起点。
3. 模板只能新建时选、导入只能手输路径、没有预览与管理，离“模板库”还有距离。
4. Agent 不能按模板生成，无法“一句话套模板做 PPT”。

## 2. 目标 / 非目标 / 成功标准

### 2.1 目标

1. 用户能在**新建画布**和**已有画布**两个场景选择模板，并在选择前看到预览（缩略图/板数/尺寸/类型）。
2. 模板可**导入**：工作区画布、本地目录、zip 包三种来源；导入前可预览、可命名/打标签。
3. 模板可**管理**：列表、预览、重命名、标签、删除（软删）、导出 zip、复制到工作区。
4. 内置一套可用的 **PPT deck 骨架**（≥8 页）；HTML 兼容模板按 D1 决策支持。
5. Agent 能用模板：按模板新建画布、给当前画布套用模板页。
6. 模板文件与画布文件同构，导入/导出可跨机器复用；不引入数据库/新服务。

### 2.2 非目标

- 不做在线模板市场/远程下载（本地库为唯一来源；后续可另立 ADR）。
- 不做设计系统（`designSystems`）与组件库。
- 不把 HTML 兼容板变成可编辑对象（仍只读渲染）。
- 不做模板版本升级/依赖追踪（模板是快照；另存为新模板即可）。
- 不做多人协同模板共享。

### 2.3 成功标准

- 新建时选“PPT deck 骨架”得到 8 页可编辑画板；选“我的模板”得到保存时的版式。
- 已有画布能把模板插入为新页，且原内容不变；可撤销。
- 导入本地目录/zip 的模板出现在“我的模板”，预览与实际一致；原文件不被修改。
- HTML 兼容模板（若 D1=A）实例化后只读渲染、可导出 PNG/PDF/PPTX（图片页），界面有只读标注。
- Agent 说“用 X 模板新建/加一页”时能命中模板（工具参数/能力计划可追溯）。
- 关闭 `OAW_CREATIVE_CANVAS` 时模板能力同画布一并不可用（基线一致）。

## 3. 用户操作设计（重点：具体怎么操作）

### 3.1 新建画布时选模板

入口：顶栏「工作区」→「创作画布」→ 空态表单（或 `+` 菜单 → 创作画布）。

```text
新画布
┌──────────────────────────────────────────────┐
│ 标题 [________]   类型 [普通画布 ▾]           │
│ 模板 [ 默认（按类型） ▾ ]  [预览] [导入模板]  │
│ ┌─ 预览卡 ─────────────────────────────────┐ │
│ │ [缩略图]  PPT deck 骨架                  │ │
│ │ 8 页 · 1280×720 · 对象板 · 内置          │ │
│ │ 说明：封面/目录/章节/要点/数据/图表/…     │ │
│ └──────────────────────────────────────────┘ │
│                        [取消] [从模板新建]    │
└──────────────────────────────────────────────┘
```

- 模板下拉分组：`默认（按类型）`、`内置模板`、`我的模板`；每项显示“标题 · 页数”。
- 选中后预览卡展示缩略图（首板或封面）、板数、尺寸、对象板/兼容板数量、来源（内置/我的）。
- “导入模板”打开导入对话框（见 3.3），导入完成后自动选中新模板。
- 类型下拉：当选择模板时，类型由模板决定（灰显并提示“由模板决定”）。

### 3.2 已有画布套用模板

工具栏新增「模板」按钮（与「存为模板」并列）→ 右侧模板抽屉（或对话框）：

```text
模板库                                   [导入模板] [×]
[内置] [我的]   搜索 [________]
┌ 模板卡 ─────────────────────────────┐
│ [缩略图] PPT deck 骨架 · 8 页       │
│ [预览] [套用 ▾]                     │
│        ├ 新建页并插入               │
│        ├ 追加到当前页               │
│        └ 替换当前画板               │
└─────────────────────────────────────┘
```

- **新建页并插入**（推荐默认）：在目标页后新建一页，把模板所有板按顺序放入；模板每页对应画布一页。
- **追加到当前页**：模板板追加到当前页（按模板 x/y 偏移或自动排版，避免重叠）。
- **替换当前画板**：仅当模板只有 1 块板时可用；用模板板内容替换当前板（保留路径/rev 递增）。
- 套用前展示影响清单（新增 N 板/M 页、是否含只读兼容板）；确认后写入；结果可撤销（画布版本记录）。
- 若当前画布有未保存修改：先提示保存或取消，不静默丢弃。

### 3.3 导入模板（三种来源）

点「导入模板」→ 导入对话框：

```text
导入模板
来源： (•) 工作区画布目录   ( ) 本地目录   ( ) 模板 zip 包
[选择目录/文件]  [________________________]
[预览] → 显示：标题、板数、页数、尺寸、对象板/兼容板数量、首板缩略图
名称 [________]  标签 [汇报, 政务]   [ ] 包含只读兼容板（若 D1=A）
[取消] [导入]
```

- **工作区画布目录**：用目录选择器（基于 `/api/files` 或画布列表）选择 `designs/<slug>`，默认取该画布标题。
- **本地目录**：系统目录选择（后端新增“选择目录”能力或前端上传路径协议）；服务端只读复制到 `.templates/<slug>/`，**原目录不动**；工作区外路径需显式确认。
- **zip 包**：上传/选择 zip；服务端解压到临时目录并校验（路径穿越、文件数/大小上限、必须含 `template.json` 或 `project/canvas.json`），通过后移入模板库；失败回滚。
- 预览不落盘（dryRun）；确认才复制。重名时给“重命名/覆盖（软删旧模板）”选择。

### 3.4 另存为模板

工具栏「存为模板」→ 对话框：名称、描述、标签、是否包含只读兼容板（若 D1=A）、封面选择（默认首板）。

- 保存到 `designs/.templates/<slug>/`；slug 由名称推导（中文允许，禁空格/点/斜杠），重名提示。
- HTML 兼容板：D1=A 时原样复制并在模板 `template.json` 标记 `compat.html=true`；D1=B 时明确提示“HTML 板不会进入模板”，并列出被排除的板。

### 3.5 模板管理

模板库抽屉（“我的模板”页签）：

- 卡片：缩略图、标题、类型（board/deck）、页数/板数、尺寸、更新时间、标签。
- 操作：预览（大图/逐板）、重命名、编辑标签/描述、删除（软删到 `.templates/.trash/`，可恢复）、导出 zip、复制到工作区（生成一份普通画布）。
- 内置模板只读：可预览、可“复制为我的模板”（复制后可改），不可删除/重命名。

### 3.6 Agent 使用

- “用『政务汇报-A』模板新建一份 PPT” → `canvas_write create_canvas {templateSlug:"政务汇报-a"}`。
- “在当前画布加一页‘数据页’模板” → `canvas_write apply_template {slug, templateSlug, mode:"new-page"|"append", board?}`。
- “把当前画布存成模板” → `canvas_write save_template`（或 `canvas_template` 工具的 save 动作）。
- “有哪些模板” → `canvas_read action:"templates"` 或新工具 list。
- 工具返回模板摘要（标题/页数/类型/是否只读兼容板）；套用后发 `canvas_changed`。

## 4. 模板格式与数据模型

### 4.1 目录包（唯一事实来源）

```text
designs/.templates/<slug>/
├─ template.json                 # 新增：库元数据（可选，缺省按 canvas.json 推断）
└─ project/
   ├─ canvas.json                # format: "oaw-canvas-template"；boards/pages/order 与画布同构
   ├─ boards/*.board.json        # 对象板（可编辑，实例化后仍可编辑）
   ├─ assets/                    # 图片/字体等，相对引用
   └─ legacy/*.dc.html           # 兼容板（D1=A 时保留，只读）
```

`template.json`（新增，向后兼容）：

```json
{
  "schemaVersion": 1,
  "slug": "政务汇报-a",
  "title": "政务汇报 A",
  "description": "封面/目录/章节/数据页",
  "kind": "deck",
  "tags": ["汇报", "政务"],
  "cover": "boards/cover.board.json",
  "boardCount": 8,
  "pages": 1,
  "compat": { "html": false },
  "source": { "type": "workspace|path|zip|canvas", "ref": "designs/xxx", "importedAt": "2026-11-10T…" },
  "createdAt": "…",
  "updatedAt": "…"
}
```

规则：

- 模板仍是“画布包”超集：没有 `template.json` 时按 `canvas.json` 推断（标题/kind/boards/pages），保证现有实现与外部 claude-design 包可用。
- 模板不参与画布 `rev`/版本历史/导出任务；实例化时深拷贝、对象板 `rev` 从 1 起、替换 `{{title}}` 占位符。
- `assets/` 整树复制；对象板 `src` 仍按相对板文件路径解析。
- 模板目录以 `.` 开头，天然不出现在 `listCanvases`；软删到 `.templates/.trash/`。
- 限额：单模板 ≤ 50 板、≤ 512 文件、≤ 128MB；zip 解压后同样受此限额（防 zip 炸弹）。
- 兼容板（D1=A）：仅复制原字节，不解析内部；实例化后只读。

### 4.2 zip 模板包

- zip 根目录可直接是 `template.json + project/…`，也接受只含 `project/canvas.json` 的包（按 4.1 推断）。
- 导入校验：拒绝绝对路径、`..`、符号链接、可执行文件；限制文件数/解压后总大小；只解压白名单扩展名（json/svg/png/jpg/webp/gif/woff2/css/js/html）。
- 导出模板：同一目录包打包为 zip（含 `template.json`），可用于备份/换机/分享。

## 5. 内置模板

- 存放：仓库 `templates/canvas/`（只读随代码发布），启动或首次访问时读取；不在用户工作区生成副本，避免升级冲突。
- 保留现有 id（`blank/cover/onepager/deck`）兼容；新增/扩展：
  - `ppt-deck`（8 页）：封面 / 目录 / 章节过渡 / 要点 / 数据 / 图表 / 结论 / 结尾；
  - `ppt-onepager`：一页纸汇报；
  - `html-report`（若 D1=A）：2–3 块 `.dc.html` 只读兼容板，演示 HTML 汇报模板；
  - 后续按用户材料补充“政务汇报”“可研汇报”“年度总结”等，均为本地只读模板。
- 内置模板与用户模板同格式（`template.json` + `project/`），代码不再写死版式（`buildTemplateBoards` 仅保留兜底/迁移）。
- 内置模板可“复制为我的模板”，修改后成为用户模板。

### 6.2 Agent 工具

- 扩展 `canvas_write`：`create_canvas` 增加 `templateSlug`；新增 `apply_template`、`save_template` 动作（或独立 `canvas_template` 工具，list/import/save/apply）。
- 工具描述明确“模板是本地工作区内的版式包，HTML 兼容板只读”。
- 工具元数据：`canvas_template` 读=allow；import/save/apply=ask；delete=forceConfirm；新增工具须走"加工具五步清单"（实现/白名单/元数据/事件/契约测试）。
- 能力计划 `planTaskCapabilities`：Work + 开关开时声明 `canvas`（已存在），模板作为其子能力说明，不新增模式。

### 6.3 权限

- 读模板：allow；导入/另存/套用：写工作区，按审批策略（默认 ask 或沿用 `canvas_write` allow，需确认）；删除模板：ask + forceConfirm。
- 模板导入不执行模板内脚本；HTML 兼容板 iframe sandbox 无脚本；
- 工作区外目录只读复制需显式确认，不写入源目录。

## 7. UI / DESIGN 增补（DESIGN §8.4）

- 新建表单：模板下拉分组 + 预览卡；类型由模板决定时灰显并说明。
- 模板库抽屉：`[内置][我的]` 页签、搜索、卡片（缩略图/标题/页数/尺寸/标签）、操作菜单（预览/套用/重命名/删除/导出/复制）。
- 导入对话框：来源三选一、目录/文件选择、预览区、命名/标签、重名策略、错误可执行。
- 套用对话框：应用方式三选一、影响清单（新增页/板、只读板数量）、确认。

- 无障碍：预览卡可键盘聚焦；导入对话框 dialog 语义；缩略图有可访问名称。

## 10. 风险与回滚

| 风险 | 影响 | 对策 |
|---|---|---|
| HTML 模板被误认为可编辑 | 用户改不动而报缺陷 | D1=A 时界面明确“只读·兼容板”；导出对话框标注图片页 |
| zip 导入安全 | 路径穿越/zip 炸弹 | 解压前校验、限额、白名单扩展名、临时目录+失败回滚 |
| 模板与画布格式漂移 | 旧模板导入失败 | `template.json` 可选 + canvas.json 推断；版本字段与迁移测试 |
| 内置模板升级覆盖用户修改 | 用户定制丢失 | 内置只读；用户“复制为我的模板”后才能改 |
| 模板资产大量复制 | 工作区膨胀 | 限额（≤128MB/512 文件）；提示可清理；软删 .trash |
| 套用模板导致内容冲突 | 用户丢失编辑 | 影响清单 + 确认 + 画布版本记录可恢复；有脏先保存 |
| 模板能力与画布开关不一致 | 关闭开关仍可见入口 | 模板 API/UI 同受 `OAW_CREATIVE_CANVAS` 门控；关闭态测试 |

**回滚**：不新增数据库/服务；模板是 `.templates/` 目录，删除即回滚；代码回退不影响已生成画布。开关置 0 时模板入口/API 一并关闭。
