## 2. 改动文件

- `server/runs.mjs`：Run 记录 `owner { pid, instanceId }`；实例心跳（`startOwnerHeartbeat` / `stopOwnerHeartbeat`）；`recoverActiveRuns` 跳过 owner 仍存活的 Run
- `server/index.mjs`：`OAW_DISABLE_RECOVERY=1` 开关；启动与退出时管理本实例心跳
- `server/写入协调.mjs`：`stageWriteWithRetry()`；`acquireWriteLockWithRetry` 统计 `attempts`/`waitedMs` 并把 `retryable`/owner 写进错误 details；等待上限可用 `OAW_WRITE_LOCK_TIMEOUT_MS` 调整（默认 20 秒不变）
- `server/agent.mjs`：`write`/`edit`/子 Agent 写入改走 `stageWriteWithRetry()`
- `server/office规范/执行闸门.mjs`：只读 bash 逐段判定
- `scripts/验证脚本.mjs`：改用临时 `OAW_RUNS_DIR`/`OAW_WRITE_LOCK_DIR`/`OAW_EVENT_DIR`/`OAW_INSTANCE_DIR` 并关闭恢复，结束时清理
- 新增 `scripts/恢复隔离测试.mjs`、`scripts/多任务并发回归测试.mjs`

## 4. 遗留与边界

- **2 标签页 + 3 并发任务时会出现"会话列表读取失败"横幅**：根因是浏览器同源 6 个连接槽被 SSE 占满（服务流达 7 条），控制面请求 8 秒超时。服务端直连读接口零失败，单标签页时横幅消失——属既有边界，不在本次修复范围，已记入审查报告 §10.3。
- **写锁等待上限仍是 20 秒**：若另一个任务的 `bash` 命令持续更久，写入仍可能失败；可通过 `OAW_WRITE_LOCK_TIMEOUT_MS` 调整。
- **`map_template` 归位**：本轮收敛时确认它"有元数据、有测试、却不在任何白名单"（Work 模式调不到），已加入 Work 白名单。
