# 创作画布视频元素支持计划

> 日期：2026-11-15　基线：v0.13.25（develop）　状态：**已确认**（2026-11-15 用户确认 D1–D5，进入实施；原编号 004 与"一次性系统提示自动隐藏方案"冲突改号 005）
> 关联需求：REQUIREMENTS.md R17 创作画布（扩展对象类型）　关联设计：DESIGN.md §8.4
> 性质：新功能（画布新增 `video` 元素类型），纯 Work 模式受控能力，不改变模式边界。

## 1. 背景与目标

用户需求：创作画布目前支持 text / rect / line / image / svg 五类元素（[创作画布.mjs#L90](../../server/创作画布.mjs)），无法在画板中放置视频。本计划在画布对象模型中新增 **`video` 元素**：

- Agent 可通过 `canvas_write → patch_board` 写入视频元素（与 image/svg 同级的一等公民类型）。
- 画布编辑视图可渲染视频（封面、双击播放、选中缩放）。
- 导出（SVG/PNG/PDF/PPTX）对视频给出静态降级（封面帧/占位框），不阻塞既有导出。
- 安全边界与 image 完全一致：`src` 只允许 project 内相对路径，禁止外链 URL。

## 3. 方案设计

### 3.1 数据模型（video 元素）

```json
{
  "id": "el-video-1",
  "type": "video",
  "x": 120, "y": 80, "w": 640, "h": 360,
  "src": "../assets/demo.mp4",
  "poster": "../assets/demo-cover.jpg",
  "fit": "contain",
  "loop": false,
  "muted": false,
  "autoplay": false
}
```

- `src`（必填）：project 内相对路径，复用 `validateAssetSrc`；支持扩展名 `.mp4 / .webm / .ogv`。
- `poster`（可选）：封面帧图片路径，同为素材路径；无 poster 时渲染占位样式。
- `fit`（可选）：`cover/contain/fill`，默认 **contain**（视频裁切比图片更易丢关键信息，与 image 的默认 cover 不同）。
- `loop / muted / autoplay`（可选布尔，默认 false）：服务端校验为布尔；前端 autoplay 强制带 `muted`（浏览器自动播放策略），避免无声卡死。

### 3.2 服务端改动（server/创作画布.mjs、server/index.mjs）

1. `ELEMENT_TYPES` 增加 `"video"`；`validateElement` 增加 video 分支：src 必填走 `validateAssetSrc`；poster 可选走 `validateAssetSrc`；fit/loop/muted/autoplay 校验；错误提示文案更新为六类可用类型。
2. 模块层 `ASSET_MIME_BY_EXT` 增加 `.mp4→video/mp4`、`.webm→video/webm`、`.ogv→video/ogg`（`readCanvasAsset` 导出读字节随之放行）。
3. 路由层 `CANVAS_ASSET_MIME` 同步增加同名映射；**为视频 MIME 启用 Range 请求**（`Accept-Ranges: bytes` + 206/Content-Range 单区间实现，多区间拒绝退化为 200）：浏览器 `<video>` seek 依赖 Range，不支持会导致拖动进度条失效或大文件整读。非视频扩展名行为不变（保持 200 流式）。
4. 素材路由 CSP 头对视频放行 `media-src 'self'`（现值 `default-src 'none'; ...` 会阻断 `<video>` 加载自身，需追加；`<img>` 走 img-src 不受影响）。
5. 不新增画布级配额字段：沿用 project 总配额（256MB/512 文件）。视频素材由 Agent 文件工具直接落盘（与 image 素材同一进入路径，不经画布 API，服务端无法在写入时拦截大小），在工具描述中给出"单视频建议 ≤64MB"的软约定。

### 3.3 前端改动（client/src/画布/画布模型.js、client/src/components/创作画布.jsx、创作画布导出视图.jsx）

1. `元素类型` 增加 `"video"`；`兜底尺寸.video = { w: 640, h: 360 }`。
2. `normalizeElement` 增加 video 分支：src 解析复用 `素材路径`；poster 同；fit 默认 contain；loop/muted/autoplay 布尔归一化。
3. 渲染组件增加 video 分支：
   - `poster` 有值显示封面 `<img>` 形态（未播放态），与 image 渲染复用样式类；无 poster 显示中性占位（播放图标 + "视频"文案，样式遵循设计令牌与卡片化圆角）。
   - **双击进入播放态**：切换为 `<video controls>`（`src` 走受控素材地址），再次双击/点击画布空白处退出回封面态；不播放时零流量（仅 `preload="metadata"`）。单选/拖动/八向缩放/删除等交互全部沿用现有元素通道，不与播放态冲突。
   - 属性条（选中态）提供 fit 切换与 loop/muted 开关；沿用现有属性条控件样式。
4. 播放（deck 全屏放映）与导出视图中 video 一律渲染为**封面/占位静态形态**（不用 `<video>`），保证放映截图与导出稳定。
5. 缩略色块（板缩略数据）对 video 元素按占位块处理，不加载视频。

### 3.4 导出策略（server/创作画布导出.mjs）

| 格式 | video 处理 |
|---|---|
| SVG（服务端逐元素） | 复用 `svgImageElement`：有 poster 输出封面图，无 poster 输出占位框 + "视频"文字 |
| PNG / PDF（导出视图截图） | 导出视图已按 3.3-4 渲染静态封面/占位，无需额外分支 |
| PPTX | poster 有值 → `addImage`；无 poster → 占位矩形 + 文本（与 rect 映射风格一致）；**V1 不嵌真实视频**（pptxgenjs addMedia 依赖外部媒体文件封装，稳定性和兼容性风险大，留作后续评估） |

导出 warnings 机制沿用：video 元素无法解析素材时记 warning 不中断导出。

### 3.5 Agent 工具链（server/agent.mjs）

- `canvas_write` 工具描述的"元素类型"行更新为：text、rect、line、image、svg、**video（src 为 project 内相对路径，poster 可选封面，支持 mp4/webm/ogv，建议单文件 ≤64MB）**。
- 不新增工具、不改白名单（`canvas_write` 已在 task.mjs 白名单中）、不改审批策略（`canvas_write` 现行 `allow` 不变）；`test:capability-contract` 无需变更。
- Agent 把视频文件放入 `designs/<slug>/project/assets/` 的方式与 image 素材一致（内置文件工具/bash），工具描述中说明。

### 3.6 安全与边界

- `src/poster` 全部走 `validateAssetSrc`：project 内相对路径，禁 URL/绝对路径/越界（与 image 同强度）。
- 视频文件本身非脚本类型，XSS 风险低于 SVG；路由保留 `X-Content-Type-Options: nosniff` 与白名单 MIME。
- Chat/Review 模式不涉及（canvas_* 工具仅 Work 持有），不新增能力计划项。

## 4. 决策点（2026-11-15 用户确认）

| # | 决策 | 结论 |
|---|---|---|
| D1 | 画布内视频播放交互 | **双击播放/暂停**（3.3-3），不用常驻 controls |
| D2 | `fit` 默认值 | contain（区别于 image 的 cover） |
| D3 | 支持的容器格式 | **mp4 / webm / ogv** 三种 |
| D4 | PPTX 导出是否嵌真实视频 | **否，用封面帧静态图** |
| D5 | UI 是否加"上传视频"入口 | **不加**（与 image 现状一致，素材由 Agent/文件系统进入 assets/） |

## 7. 风险与回滚

- Range 改动只对视频 MIME 生效，图片/字体路径零变化；若异常可单独回退该分支。
- 大视频受 project 256MB 总配额约束，Agent 写入超限会由 Pi 内核文件工具的自然失败兜底，不产生半坏画布文件。
- 类型白名单是硬闸门：旧前端收到带 video 的板会丢弃该元素（归一化返回 null），先发后端后发前端存在短暂的"元素不可见"，反之（先前端）无风险——**实施顺序按本计划服务端先行**。

## 8. 不做清单（V1）

- 不做 UI 素材上传入口（视频与图片一致，均经 Agent/文件系统落 assets/）。
- 不做视频转码、剪辑、时间轴、倍速。
- 不做外链视频 URL 与 iframe/嵌入页元素。
- 不做 audio 音频元素（另行评估）。
- PPTX 不嵌真实媒体，SVG/PNG/PDF 导出为静态封面/占位。
