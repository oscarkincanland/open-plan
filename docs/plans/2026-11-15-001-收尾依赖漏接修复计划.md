# 2026-11-15-001 收尾依赖漏接修复计划

> 状态：已确认（2026-11-15，用户「帮我修改落地一下吧」）　基线：v0.13.25（develop @ 487b5d37 + 未提交 010/011/012 改动）　需求来源：用户现场反馈「结论都生成了、任务还没结束、本轮产物也没有出现」

## 1. 现象与证据

用户 2026-11-15 晚连续四轮 Work 任务都是同一形态：模型已给出结论、界面一直显示「执行中」、约 3 分钟后变成「已中断」且产物面板为空。

现场证据（`.oaw/` 与 `运行日志/` 均为运行时产物，不入库）：

| 证据 | 内容 |
|---|---|
| `运行日志/服务监督.log` | 每轮一条 `[agent] 后台 Run 收尾失败 TypeError: deps.runs.validatableRunArtifacts is not a function`（`server/执行句柄.mjs:490`） |
| `run_3ecf4b63-*.json` | `assistant_final` 12:20:50 → 无 `run_finished`；12:24:05 才出现 `run_finished(status=cancelled)`，`error=运行已静默 3 分钟且运行时不再执行，按中断收尾`，`staging.status=discarded`，`artifacts=[]` |
| `run_7f6b3179` / `run_04c9fac5` / `run_7eee3bc6` | 同形态：收尾 TypeError → 静默回收按中断收口 → 暂存产物丢弃（`规聚介绍片_v1.html`、`分镜脚本与成片流程.md`、`规聚介绍_网页动画版.html`、`汇报框架分页规划.md` 等未落盘） |

## 2. 根因

2026-11-11-010「五项体验修复」新增了 `validatableRunArtifacts()`（`server/runs.mjs`），把 4 处送检清单从 `listRunArtifacts(...).map(...)` 换成它，但**装配处漏接**：

1. `server/执行句柄.mjs` 的默认 `runs:` 依赖包没有 `validatableRunArtifacts`，而 `执行回合` 的成功路径（L490）与失败路径（L432）都在调它 → **每一轮成功收尾都抛 TypeError**。收尾是 fire-and-forget（L315-317 只 `console.error`），前端完全看不到。
2. `server/index.mjs` 从 `./runs.mjs` 的 import 没有 `validatableRunArtifacts`，但 L5459（prompt 兜底）与 L5532（续跑恢复）在用 → 那两条路径会抛 `ReferenceError`。
3. 收尾一挂，`run_finished` 不发出 → 前端 Run 状态停在 running；3 分钟后静默回收器（`server/index.mjs:7691`，`OAW_RUN_STALL_MS` 默认 180s）按 `cancelled` 收口，`finishRun` 的取消分支调用 `discardStagedRun` → 暂存产物被删除，所以「产物没出现」。

现有测试没拦住：`scripts/产物归属与终态测试.mjs` 直接 import 函数测逻辑，`scripts/执行句柄契约测试.mjs` 的 Run 替身没有该函数、也不断言收尾跑通。

## 3. 修复方案（最小侵入）

### 3.1 接线（3 行）

- `server/执行句柄.mjs`：import 增加 `validatableRunArtifacts`；默认 `runs:` 依赖包增加同名字段。
- `server/index.mjs`：`from "./runs.mjs"` 的 import 增加 `validatableRunArtifacts`。

### 3.2 回归测试 — `scripts/执行句柄契约测试.mjs`（`npm run test:exec-handle`）

- Run 替身补 `validatableRunArtifacts: () => []`（与真实依赖同形）。
- 新增「成功回合收尾跑通」：注入替身执行一轮，短延时后断言 Run 状态 `completed` 且收到 `run_finished`——缺依赖时会停在 running，直接失败。
- 新增「收尾依赖接线完整」：静态解析 `执行句柄.mjs`，`deps.runs.*` 用到的方法必须都在默认 `runs:` 依赖块里，且每个方法都是 `runs.mjs` 的导出（防漏接/拼错）。
- 新增「index.mjs 使用 runs.mjs 导出必须先 import」：静态比对导入集合与调用点，排除本地同名函数定义（`index.mjs` 自身有 `snapshotWorkspace`）避免误报。
