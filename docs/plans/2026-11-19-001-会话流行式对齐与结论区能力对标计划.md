## 2. 业界对标（设计依据）

基于产品行为观察，不是源码核查。

**2.1 对齐靠共用网格，不靠逐条 padding**
Claude Code / Cursor 的过程行统一为「chevron 列 + 图标列 + 文字列」三段网格，组头与单行工具共用同一网格。Vercel AI Elements 的 `Reasoning` 与 `Tool` 共用同一套 `Collapsible` 触发器 padding。

当前实现有三套结构：组头（dot 6px）、时间线行（chevron 12px + icon 16px）、工具行（条件渲染的状态图标 + 语义图标，gap 6）。这是三种左缘的根因，**只改组头不够，工具行必须一起并入同一网格**。

**2.2 结构线**
Claude Code / Cursor 不用竖线或横线分隔过程行，靠缩进与行距。本项目 11-18 已去横线，竖线同理。

**2.3 动效**
动画只表达「正在进行」，结束即静止；思考预览是静态摘要，不应引入与状态无关的色彩。

**2.4 结论区**
结论是普通 Markdown，图片走 `![](path)` + 本地灯箱；标题层级用原生 `##` / `###`，编号是渲染层的可选增强。

## 3. 三批实施

### 批次 1：三栏网格统一与层级收敛

**改哪里**：`client/src/styles.css`（v3 行式段、`.tool-header`）、`ProcessGroup.jsx`、`ChatPanel.jsx` 的 `ToolCard`。

**统一网格**：12px chevron 列 + 8px gap + 16px 图标列 + 8px gap = **44px**（`--tl-lead`）。

1. **组头**：补 12px chevron 占位；`.tl-group-dot` 包进 16px 居中容器、`margin-left` 归零；`gap` 6→8。
2. **时间线行**：已是 12 + 8 + 16 + 8（`.tl-row-head` 基线 `gap: 8px`），只需确认 v3 段没有覆盖 gap。
3. **工具行（本批真正的结构改动）**：`.tool-header` 从「12 + 6 + 16 + 6」改为「12 + 8 + 16 + 8」，与行头一致：
   - 补 12px chevron 占位（`.tool-chevron` 移到最右，占位另加）；
   - 状态图标并入 16px 图标列：运行/未结转态显示 spinner，完成态显示工具语义图标，失败态显示语义图标并把颜色落到 `--error`；
   - 不再按状态条件渲染额外图标位（11-18 已去掉完成对勾，本批把剩余的状态槽也收进图标列）。
4. **组体与旁白**：`.tl-group-body` 的 `margin-left` / `border-left` / `padding-left` 归零（当前共 15px）；折叠体内 `.textblock` 的 `padding-left` 改为 `var(--tl-lead)`。
5. **明细缩进不属于同轴范围**：`.tl-detail { margin-left: 22px }` 保留——它是「展开明细相对行文字的再缩进」，展开后的思考正文/工具明细在 66px，这是层级而非错位。
6. **去掉两层竖线**：`.tl-list` 与 `.tl-group-body` 的 `border-left` 同时去掉。
7. **思考预览配色**：`.tl-think-preview .marquee { --marquee-a: currentColor; --marquee-b: currentColor; }`。该选择器与 `[data-marquee-color="x"] .marquee` 同为 (0,2,0)，必须**写在后者之后**（或提高特异性为 `.tl-think-preview .marquee.is-active`），否则不生效。
8. **同步规范**：§4 第 37 行（竖线表述）、§9 第 197 行（两句：竖线与「行内左缩进与图标列对齐」）一并改；组头字重维持 400（§4 表），层级用颜色深浅与行距表达，不引入 600。

**验收（像素级）**：`.tl-group-label`、`.tl-verb`（思考行）、`.tool-phrase`、`.tl-list:not(.tl-list-replies) .textblock` 四者 `getBoundingClientRect().left` 两两差 ≤1px；`.tl-list` 与 `.tl-group-body` 的 `borderLeftWidth` 均为 `0px`。
若 `OAW_TRANSCRIPT_V3` 关闭导致无组头 DOM，改为离线 CSS 断言，并在报告里注明未做像素验证。

## 7. 风险与回滚

| 风险 | 缓解 | 回滚 |
|---|---|---|
| **工具行结构改动影响最大**：`.tool-header` 并入网格后，运行态 spinner 与完成态语义图标共用一列，可能出现列宽跳动 | 16px 列固定宽度，spinner 与图标同为 14–16px；G1 看运行中与完成态的 x 是否稳定 | 恢复按状态条件渲染的两段结构 |
| **既有断言会转红**：`会话流排版回归测试.mjs` 死锁 `.textblock { padding: 2px 8px 4px 0 }`；`.tool-icon` 相关断言也可能命中 | 同批更新断言为新网格口径，并在变更日志注明「断言随契约更新」 | 恢复旧 padding 与旧断言 |
| 组体归零后组头与组内行看起来平级 | 组头 `--dim` + 行内 `--muted` 的颜色差、组头行高与组体行距拉开 | 恢复组体 8px 缩进（lead 需重算） |
| 思考预览变量覆盖不生效 | 必须写在 `[data-marquee-color]` 规则之后或提高特异性 | 恢复跟随配色 |
| 提示词加图片约定后模型引用不存在路径 | `resolveImgSrc` 渲染为破图，不影响其他内容 | 删除该条提示词 |
| h3 编号与模型手写编号冲突 | `alreadyNumbered` 整篇跳过；h2/h3 同一遍扫描 | 关闭 h3 编号 |

## 8. 对抗审查（§7.3）

**审查者**：独立子代理（general-purpose，只读）　**日期**：2026-11-19　**结论**：两轮后仍要求修订（v2 复审结论）

**已修复项（v3）**：工具行纳入统一网格并写明结构改动（第 3.3 条）；验收四项改为组头 label / 思考 verb / 工具 phrase / 旁白 textblock，去掉 `.tl-thinking-text`；明细缩进明确不属于同轴；`SummaryBlock` 改为三处；规范定位到 §4:37 与 §9:197 两句且组头维持 400；scoped 变量写明插入位置或提高特异性。
