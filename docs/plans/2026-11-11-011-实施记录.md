## 1. 结果摘要

按用户确认的四项决策落地（点工作区即打开开始页 / 打开方式用常驻图标 / 「缺图表」指图标没区分 / 允许重启验收）：

- **工作区开始页**：新增画布视图 `start`（单例、不持久化），切换工作区后自动注入并激活；页内含工作区名/路径/统计、搜索入口、7 个常用入口卡片（工作区文件 / 任务摘要 / 代码审查和变更 / 浏览器 / 地图预览 / 创作画布 / 新建对话）、「更多工具」就地展开 3 项（对象栏 / 领域工作流 / 运行记录）、最近 5 条会话、底部新建对话与工作产物。**不新增任何向下浮层**。
- **本轮产物卡**：默认只列 **3 条主要交付物**（交付优先 + 文档类优先），其余折叠成一行「还有 N 个文件」；折叠行移出滚动容器，产物卡不再有 320px 内部滚动截断。每条产物常驻 **三种打开方式**：内置预览（打开）/ 系统默认程序 / 在文件夹中显示，全部是图标按钮。
- **图标「没区分」的真因已修**：`文件类型图标` 只认 `file.name || file.path`，而产物卡/产物面板/改动面板/命令面板传入的是**路径字符串**，解析成空串后一律落回 `other`（灰色通用图标）。现在组件同时接受字符串与对象；同时按 DESIGN §5.8 恢复「实色类型底 + 白色字形」，并去掉产物卡外层那层灰底方块（方块套方块会吃掉类型色）。
- **一处结构收敛**：RunSummary 里那份内联产物列表删除，统一由 `ArtifactCard` 渲染，消除两处口径漂移（6 vs 8、是否有内部滚动）。
- **顺手修**：`平台/外部打开.js` 是死代码且指向不存在的 `/api/native/*`，改为真实端点 `/api/system/open`、`/api/system/reveal` 后由产物卡复用。

## 7. 追加修正（2026-11-12，用户反馈后）

用户反馈两点：「并行任务打开后没办法收起」「工作区打开怎么还是弹窗，应该是开始页面呢？」。前者是真缺陷，后者是首轮实现漏掉的触发路径。

| 问题 | 根因 | 修正 |
|---|---|---|
| 顶栏「工作区」仍弹卡片面板 | 首轮只做了「点击左侧项目卡片 / 切换工作区」注入开始页；顶栏入口沿用 2026-11-03 的 `topbar-tools-panel`，与开始页功能重复 | 顶栏入口改为 `ensureStartPage()` 直接打开开始页；删除整个 `topbar-tools-panel` DOM（不留死代码）；原面板能力全部由开始页入口承接 |
| 点「新建会话」后看不到开始页 | 用户原话「如果新建的话直接形成一个导航页」在首轮被漏掉，当时只在切换工作区时注入 | `handleNewSession` 增加 `openStart` 选项，默认新建即 `ensureStartPage()`；切换工作区链路传 `openStart:false`，由 `pendingStartPageRef` 统一注入，避免两条路径互抢 |
| 刷新后画布空白、看不到开始页 | 恢复 effect 只恢复已保存标签，空工作区恢复出空画布 | 恢复时若 `allowed` 为空则注入开始页 |
| 任务中心弹层无法收起 | 弹层仅有 `Escape` 关闭，标题栏没有可见关闭入口（`hideTrigger` 让外部入口也不常驻） | 标题栏右侧加「关闭任务中心」按钮（`aria-label`/`title` 同名），样式 `.task-center-close`；全页模式仍走「返回对话」 |

同步更新：`DESIGN.md` §5.4（顶栏工作区入口）与 §5.7（开始页）；`scripts/工作区面板与输入栏收敛测试.mjs` 顶栏三例按新契约重写。

实测（构建 `index-Co2iGBFZ.js`，1440×900）：

- 点顶栏「工作区」→ 开始页出现、标题=当前工作区名、旧面板 DOM 不存在、原设计画布标签保留；
- 开始页「更多工具 → 运行记录」打开任务中心 → `.task-center-close` 存在（`aria-label="关闭任务中心"`）→ 点击后 `.task-center-panel` 消失。
