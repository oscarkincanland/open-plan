## 2. 目标 / 非目标 / 成功标准

### 2.1 目标

1. **运行中**：会话流平铺时间流里实时出现浏览器步骤行，每行是“动词 + 站点”，随事件到达更新。
2. **运行中**：浏览器面板地址栏显示当前站点；操作记录展开后可见站点 chip 与逐条记录（收起时不写摘要）。
3. **运行后/刷新后**：展开“执行过程”仍能看到同一张浏览器卡片与站点。
4. **站点归属真实**：错误页、登录跳转、跨站重定向不冒充目标站点。

### 2.2 非目标

- **不新增任何摘要**（D2）：折叠头不显示“N 步 / M 个站点”；面板收起态不显示“最近访问”；卡片不加副标题。
- 不改画布宽度（D3），不改帧质量基线。
- 不做访问历史持久化（动作记录只在内存）。
- 不新增工具名、事件名、工具白名单、能力计划、审批策略。
- 不给 Chat/Review 开放浏览器能力。
- 不解决桌面端原生覆盖层（D6）。

### 2.3 成功标准

- Given 一轮包含 `browser_open → snapshot → click → snapshot`；
  When 运行中查看会话流；
  Then 每开始/完成一步，时间流出现/更新一行“打开 / 读取页面 / 点击 + 站点”，无需等整轮结束。
- Given 同一轮运行中；When 打开浏览器面板并展开“操作记录”；
  Then 看到站点 chip（`docs.trae.cn`、`codebuddy.cn`）与逐条记录；收起时只有“操作记录”标题，无摘要。
- Given 结束后刷新页面；When 重新打开历史会话并展开“执行过程”；
  Then 浏览器卡片与站点仍在。
- Given 打开 `trae.cn/pricing` 被重定向到登录页；
  Then 该行站点为最终 `trae.cn`，并标注“已重定向”。
- Given 打开不可达域名；
  Then 该行标注加载失败，不冒充目标站点。

   ```js
   export const BROWSER_ACTION_LOG_LIMIT = 20;
   export function upsertBrowserAction(log, entry, limit = BROWSER_ACTION_LOG_LIMIT) {
     const list = Array.isArray(log) ? log.slice() : [];
     const item = {
       toolCallId: String(entry.toolCallId || ""),
       kind: String(entry.kind || ""),
       url: String(entry.url || ""),
       title: String(entry.title || ""),
       status: String(entry.status || "done"),
       note: String(entry.note || ""),
       durationMs: Number(entry.durationMs) || 0,
       at: Number(entry.at) || Date.now(),
     };
     const index = item.toolCallId ? list.findIndex((row) => row.toolCallId === item.toolCallId) : -1;
     const created = index < 0;
     const urlChanged = !created && String(list[index].url || "") !== item.url;
     if (!created) list[index] = { ...list[index], ...item };
     else list.push(item);
     while (list.length > limit) list.shift();
     return { list, created, urlChanged, entry: item };
   }
   ```

2. 站点聚合单独累计（不受 20 条明细上限影响）：
   ```js
   export const BROWSER_SITE_LIMIT = 50;
   export function mergeBrowserSites(sites, entry, limit = BROWSER_SITE_LIMIT) {
     const list = Array.isArray(sites) ? sites.slice() : [];
     let host = "";
     try { host = new URL(String(entry.url || "")).host.replace(/^www\./, ""); } catch {}
     if (!host) return list;
     const index = list.findIndex((row) => row.host === host);
     if (index >= 0) {
       const next = { ...list[index], count: list[index].count + 1, lastAt: entry.at };
       list.splice(index, 1);
       list.push(next); // 列表顺序 = 最近访问顺序
     } else {
       list.push({ host, count: 1, lastAt: entry.at });
     }
     while (list.length > limit) list.shift();
     return list;
   }
   ```

### T3（P1）站点归属准确：错误页与重定向

**纯函数** — `server/内置浏览器.mjs`

```js
export function classifyNavigation({ requestedUrl = "", finalUrl = "" } = {}) {
  const final = String(finalUrl || "");
  if (/^chrome-error:\/\//i.test(final)) {
    return { failed: true, code: "NAV_ERROR_PAGE", redirected: false, finalUrl: final, reason: "页面加载失败（站点不可达/证书/网络）" };
  }
  let requestedHost = "";
  let finalHost = "";
  try { requestedHost = new URL(requestedUrl).host.replace(/^www\./, ""); } catch {}
  try { finalHost = new URL(final).host.replace(/^www\./, ""); } catch {}
  const redirected = Boolean(requestedHost && finalHost && requestedHost !== finalHost);
  return {
    failed: false,
    code: redirected ? "NAV_REDIRECTED" : "",
    redirected,
    finalUrl: final,
    requestedHost,
    finalHost,
    reason: redirected ? `已重定向到 ${finalHost}` : "",
  };
}
```

- `navigate()` 结束后读取 `location.href`（失败回退 `this.state.url`），调用 `classifyNavigation`：
  - `failed`：`state.error = reason`，`stateView().navigation` 附结果。
  - `redirected`：`state.error = null`，`navigation` 附 `reason`。
- `browser_open` 结果（`agent.mjs:2584`）：
  - `failed` → `已打开失败：…；当前显示的是浏览器错误页。`
  - `redirected` → 首行追加 `（注意：已重定向到 <finalHost>）`。
- `browser_step_end` 增加可选 `warning`（`事件注册表.mjs:54` schema 增补 `warning: "string"`）；`withBrowserStep` 从 `result.details.navigation?.reason` 取值，作为 `note` 写进面板记录。
- 面板：`state.error` 已有 `.browser-msg` 展示位，补“重试”按钮（`send({action:"reload"})`）。

2. 运行中看会话流：每步是否立即出现/更新“动词 + 站点”。
3. 运行中看面板：地址栏当前站点是否正确；展开“操作记录”看站点 chip 与逐条记录；收起后只有“操作记录”标题。
4. 结束后刷新 → 历史会话 → 展开“执行过程”看卡片是否仍在。
5. 关闭面板 → Agent 继续 `browser_snapshot` → 本轮不拉起；下一轮恢复。
6. 面板切走再切回/重连 → 记录保留；20 条上限生效。
7. 不可达域名 → 行内加载失败；`trae.cn/pricing` → 行内最终站点 `trae.cn` + 重定向标注。
8. 画布 420/569/760 各看一次：网页按画布宽度自适应。

## 7. 风险与回滚

| 风险 | 影响 | 缓解 | 回滚 |
|---|---|---|---|
| 时间线卡过长 | 折叠区变高 | 卡片自带折叠；`reduceBrowserSteps` 单轮上限 30 条 | 关闭卡片 |
| 动作记录进入 state 下发 | SSE 帧略微变大 | 明细 20 条、站点 50 个，字段裁剪 | 移除 `stateView` 字段，只用 `actions` 事件 |
| 自动展开更积极 | 打断阅读 | `browserAutoOpenBlockedRef` 保留；排除 `browser_close` | 恢复 5 工具白名单 |
| 开始记录误用旧 URL | 实时列表短暂显示上一站点 | 开始优先 `params.url`；结束用最终 URL upsert | 只在结束时记录 |
| 导航失败误报（站点自定义错误页） | 误标红 | 只对 `chrome-error://` 判定 failed；重定向只提示 | 关闭 `warning` |
