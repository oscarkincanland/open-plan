# 2026-11-11-008 历史定位导轨右侧并列与显隐规则修改计划

> 状态：已确认（2026-11-11）　基线：v0.13.25（develop @ 81689b71 + 未提交 2026-11-11-005 改动）　需求来源：用户截图（dsh 风格竖排刻度导轨）

## 1. 背景与问题

用户反馈「对话历史的导航栏不见了」。排查结论：

- 会话消息目录栏（历史定位导轨，`ChatTimeline.jsx`，竖列短横杠）**组件仍在**，2026-11-04 起已是「按短杠序号均分的并列排布」（与用户截图形态一致）。
- 不可见的根因是**显示门槛过严**：组件内部要求对话容器宽 ≥900px（`ResizeObserver`）。右侧栏（工作区画布/工作产物面板）展开时对话区被压窄（实测可到 414px），导轨整个卸载。
- 现行导轨位于对话区**左侧**（`styles.css` `.chat-timeline.beads { left: 3px }`），DESIGN.md §8.4 也如此规定；用户参照截图期望它在**右侧**。

## 2. 需求（R 映射：R4 会话流 / DESIGN §8.4）

1. 导轨呈**右侧竖排并列**形态：每条用户轮次一根等距短横杠，当前阅读项加长并主题色——排布算法保持现状不动。
2. **右侧栏展开时隐藏导轨**；右侧栏收起时恢复显示。显隐改为显式规则，不再依赖 900px 宽度间接推导。
3. 悬停/点击刻度打开会话导航弹层的行为保留（弹层改为向左展开）。

## 3. 改动清单（最小侵入）

### 3.1 显隐规则 — `client/src/components/ChatTimeline.jsx`

- 新增 prop `hidden`（布尔）：为 true 时直接 `return null`（右侧栏展开即隐藏）。
- 宽度门槛从 **900px 降为 640px**：仅作极窄屏保护（弹层 720px 以下已有贴底抽屉形态），不再是「右侧栏展开就消失」的间接开关。
- 保留：用户轮次 ≥2、设置开关 `showTimeline !== false`（原行为不变）。

### 3.2 Props 链路 — `client/src/App.jsx` / `client/src/components/ChatPanel.jsx`

- `App.jsx` sharedChatPanel 传入 `canvasOpen={canvasOpen}`（右侧栏展开状态，App.jsx:496-504 已有）。
- `ChatPanel.jsx` 接收 `canvasOpen`，渲染处（ChatPanel.jsx:5592）改为
  `<ChatTimeline messages={visibleMessages} containerRef={bodyRef} hidden={canvasOpen} />`。
- 地图 compact 模式行为不变（宽屏下仍显示，与现状一致）。

### 3.3 位置与弹层方向 — `client/src/styles.css`

- `.chat-timeline.beads`：`left: 3px` → `right: 2px`（贴对话区右缘，紧邻滚动条内侧）。
- `.timeline-bead` / `.bead-dot`：对齐方向改为 `justify-content: flex-end; padding-right: 4px`。
- `.timeline-popup`：`left: 28px` → `right: 28px`（弹层向左展开）；≤720px 贴底抽屉媒体查询同步核对。

### 3.4 测试同步 — `scripts/AVA时间线测试.mjs`

- 900px 门槛断言改 640px；新增 `hidden` 显隐断言。
- 「导轨应在左侧」「弹层应向右展开」两条断言反转为右侧/向左展开。

## 4. 文档同步

- `DESIGN.md` §8.4「历史定位导轨」条目：左侧 → 右侧、弹层向右展开 → 向左展开、补「右侧栏（工作区画布）展开时隐藏，收起即恢复；宽度门槛 640px 仅护极窄屏」。
- `变更日志.md` 记一条。

## 5. 不做清单

- 不动顶部「历史」抽屉（chat-hist）的隐藏状态——会话历史入口维持左侧栏「项目 → 最近会话/查看全部」。
- 不改弹层内容结构（10 条窗口、键盘 ↑↓/Enter/Esc/Home/End、顶部/底部快捷跳转均保留）。
- 不改刻度均分算法（已是并列排布）。
- 不改右侧栏本身任何行为。

## 6. 验证口径

1. `node scripts/AVA时间线测试.mjs` 通过；`npm run verify` 通过。
2. 浏览器实测：收起右侧栏 → 导轨出现在对话区右缘、等距并列、悬停弹层向左展开、点击跳转、当前项高亮；展开右侧栏 → 导轨消失；再次收起 → 恢复。
3. 长会话（多轮）抽样：跳转定位准确，窄窗口（<640px 对话区）导轨隐藏。
