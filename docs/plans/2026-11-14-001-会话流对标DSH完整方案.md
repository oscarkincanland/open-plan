## 0. 一页摘要

| 项 | 内容 |
|---|---|
| **要解决什么** | ① 折叠时"我正在读的那一行被顶走"；② 过程区一排卡片外框，信息噪音大；③ 运行中/已完成没有视觉区分，看不出"现在在干什么" |
| **对标什么** | DSH 的 4 件事：滚动意图控制器、折叠-滚动单帧钟、解析式位置补偿、运行态 `TextShimmer` + 行式 process row |
| **不做什么** | 客户端插件槽位体系、字体单 px 轴、四档展示模式、品牌素材（鲸鱼 APNG / Montserrat）、整棵对话树虚拟化 |
| **交付形态** | 会话流过程区改为"裸行 + 发丝线 + 组内竖线"；运行行扫光、完成行转灰；折叠由"高度驱动 + 补偿"接管；分组摘要进入组头 |
| **分期** | 6 个阶段、3 个迭代、约 **14–18.5 人日**；每阶段可独立验收、可独立回滚 |
| **开关策略** | 全部改动置于运行时开关 `OAW_TRANSCRIPT_V3` 之下，**默认关闭**；验收通过后再议默认开启 |
| **硬指标** | 折叠漂移 ≤ 2px；折叠/滚动帧间隔 P95 ≤ 20ms；`npm run verify` + 受影响 `test:*` 全绿；无新增运行时依赖 |

## 2. 对标事实（DSH 0.2.2-rc.3）

> 路径前缀 `chat/src` = `@deepseek-ai/dsh-client-ui-chat/src/client/chat`；`theme/src` = `@deepseek-ai/dsh-client-ui-theme/src`。

### 2.1 滚动四件套

| 能力 | 事实 | 引用 |
|---|---|---|
| 意图控制器 | `following`（意图）+ `target`（动画在途）两字段表达三态；阈值 `24`（+1），阅读采样 `500ms`；手势事件 `wheel/touchstart/pointerdown/keydown → interrupt()` | `use-chat-reading.ts:7,8,159-190`；`use-scroll-follow.ts:24-31,60` |
| 手势判定 | 不用 programmatic 标记，用基线差值 `|top − min(observation.top, floor)| > 0.5` | `use-chat-viewport.ts:658-660` |
| 折叠帧钟 | 单 rAF：`linear=(elapsed−50)/110`，`p=smoothstep(linear)`；同一 `p` 同时写行高与 `scrollTop`；fade 70ms | `flow-motion.ts:10-16,272-288` |
| 落点策略 | 跟尾 → `max(target, content−clientHeight, 0)`；阅读 → 首个可见参考行 + finish 纠偏 | `use-chat-viewport.ts:309,443-447,461-484` |
| 补偿层 | 尾部 0 高 spacer（运行时写 inline px）；一次性隐藏 cap = 半屏；顶部 prepend 分流 `scrollTop ≤ 0.5 ? prepend : native` | `use-chat-viewport.ts:221-226,359,589-604,1029` |
| 动画禁区 | 分页插入放弃 motion；切模式先 cancel + interrupt；首屏不挂动效域 | `use-chat-viewport.ts:1025；use-chat-navigation.ts:166-170；ChatView.tsx:245` |

### 2.2 运行态：TextShimmer + 色阶

- 组件：`TextShimmer`（`dsh-client-ui-primitives`），被 `ToolRow` / `ReasoningRow` / `ChatGroupSeat` / `RunningStatus` / `SkillRow` / `QuestionToolRow` 使用。
- 实现（构建产物 `index-CSAdOBx6.css`）：文字 + 装饰层；装饰层内 `.sweep`：
  - `mask-image: linear-gradient(105deg, transparent 0%, black 40% 60%, transparent 100%)`
  - `transform: translateX(-100%) → translateX(100%)`，`@keyframes 0% → 66.6667%,100%`
  - `animation: 1.5s steps(48, end) .3s infinite`
  - 颜色 `--dsw-alias-label-shimmer`（亮 `neutral-1000` 30% / 暗 `neutral-00` 45%）
- 语义：**运行中的行**叠加扫光 → 视觉上"一道亮带扫过灰字"；行结束 `active=false`，装饰层移除。
- 降级：`@media (prefers-reduced-motion: reduce) { .decoration { display:none } }`。

### 2.3 行式化与分组

| 事实 | 值 | 引用 |
|---|---|---|
| 过程行尺寸 | `height: 33px + font-delta`，`padding: 0 0 8px`，`border-bottom: .5px solid border-l2` | `TurnProcessNodeView.module.css` |
| 行色 | `color: label-tertiary`；hover → `label-secondary`；`transition: color 100ms` | 同上 |
| chevron | 14px，`rotate(180deg)`，100ms | 同上 |
| 组头 | 图标 + 文本；hover/focus 时图标淡出、chevron 淡入（opacity 100ms） | `ChatGroupSeat.module.css:1-80` |
| 组体 | `max-height: min(400px, 50vh)`，`scrollbar-gutter: stable`，方向渐隐 `mask-image` 24px | `ChatGroupSeat.module.css:104-133` |
| 折叠保留 | 折叠行不卸载，`hidden="until-found"`（浏览器查找可命中） | `searchable-hidden.ts:31-35；ChatNodeSeat.tsx:153-165` |

> 注：DSH 的**行级与组级展开没有高度动画**（条件渲染 + `contain: size layout`），高度动画只用于「整轮折叠」这一个高价值场景。这一点直接决定我们要移除现有的卡片 `grid-template-rows` 过渡。

## 4. 目标规格（可验收）

### 4.1 视觉规格

| 项 | 规格 | 备注 |
|---|---|---|
| 过程行 | 无背景、无圆角、无阴影；`min-height: 33px`；底部 `0.5px` 发丝线；`padding-bottom: 8px` | 与 DSH 一致 |
| 缩进 | 行左内边距 0；组体左侧 `1px` 竖线 + `padding-left: 6px` + `margin-left: 6px`；行内图标 16px | 组内缩进 24px 观感 |
| 行文字 | 完成态 `--muted`（tertiary）；hover `--muted-strong`（secondary）；`color 100ms` | 不用底色区分 |
| 运行态文字 | `--text`（primary）提亮；行首状态点改为图标 | 与完成态形成对比 |
| 扫光 | 105° 遮罩、`1.5s steps(48,end)`、`delay .3s`、无限；亮色主题用黑色 30%、暗色主题用白色 45% | 复用设计令牌，不写死色值 |
| 组头 | 33px 行高 + 发丝线；运行中文字带扫光；完成后纯灰 + 次数摘要 | |
| 整轮折叠头 | 保持 R3 格式：`{状态词} · 用时 {时长} · {N} 步`，不加产物/工具数 | 不改文案口径 |

### 4.2 行为规格

| 项 | 规格 |
|---|---|
| 跟随阈值 | 灰度 **40px** → 稳定后 **24px**（+1 容差） |
| 阅读采样 | 500ms（仅用于状态展示，不参与落点计算） |
| 手势中断 | `wheel / touchstart / pointerdown / keydown` 立即退出跟尾；程序滚动不得触发退出 |
| 折叠时序 | `delay 50ms` + `height/margin 110ms` + `opacity 70ms`，缓动 `cubic-bezier(.4,0,.2,1)`，单 rAF 帧钟 |
| 落点 | 跟尾 → 落底；阅读 → 参考行（首个可见非折叠头行）位置不动；用户自己发消息/steering → 强制落底 |
| 补偿上限 | 一次性隐藏按半屏 cap；超出则内容尾停在视口中央 |
| 动画禁区 | 分页插入、模式切换、首屏加载、reduced-motion 一律落定不补间 |
| 动效窗口 | 仅"运行中 + 结束 800ms 内"挂 `data-chat-motion`；静止阅读零动效 |

### 4.3 内容规格

- 组头摘要沿用 §R3 与 DSH 的"类别计数 + 前 3 类"规则：`已读取文件并执行了命令`、超过 3 类加「等」；运行中显示"正在{动作} · {详情}"，详情字段优先级 `title → description → task → command → query → url → file_path`，截断 160 字素簇。
- 完成后 150ms 内切换到完成摘要（运行中文案最短停留 150ms）。
- 折叠头文案不动（R3 验收口径不变）。

### 4.4 性能预算

| 指标 | 预算 | 测量方式 |
|---|---|---|
| 折叠漂移 | ≤ **2px** | demo v3 同款：锚点 rect 前后差 |
| 折叠帧间隔 | P95 ≤ **20ms**、max ≤ 33ms | rAF 间隔采样 |
| 滚动帧间隔 | P50 16.7ms / P95 ≤ 20ms | 同上 |
| 首字延迟 | 不回退（`test:first-token-latency` 基线 ±5%） | 现有测试 |
| 长会话 | 1000 条历史滚动 FPS ≥ 55 | 手工 + `test:chat-flow` |

### 5.2 数据流

```
SSE / 历史回放事件
  → 会话流投影.buildRunTimeline（现有）
  → 分组归约（新增：group 成员、类别计数、运行中活动）
  → 行渲染器（过程行 / 组头 / 折叠头 / 回复 / 小结 / 产物）
  → 滚动意图（决定落点）
  → 折叠驱动（写高度与 scrollTop）
```

约束：实时与历史回放必须同构（R3 验收口径），因此分组归约只能基于事件，不得读取 DOM。

### 5.3 接口契约（内部，不对外）

```js
// 滚动意图
const intent = createScrollIntent({ scroller, threshold: 40 })
intent.isFollowing()                 // boolean
intent.interrupt()                   // 用户手势 / 模式切换
intent.toBottom({ smooth = false })  // 程序落底
intent.dispose()

// 折叠驱动
await runFoldBatch({
  scroller, anchor,                  // anchor = 需要保持位置的行
  bodies: [{ el, from, to }],        // 一次折叠的全部盒子
  timing: { delay: 50, duration: 110, fade: 70 },
  landing: 'tail' | 'keep-anchor',
})                                    // → { drift, frames: { p50, p95, max } }
```

### 5.4 兼容与迁移

- 开关 `OAW_TRANSCRIPT_V3`（默认关）：关闭时完全走现有渲染路径，输出与基线逐字等价；
- 阶段 1–4 在开关下开发；阶段 5 完成后评估是否默认开启（需用户确认，符合"不得默认开启运行时开关"）；
- 旧会话历史回放必须与新渲染同构：通过同一 `buildRunTimeline + 分组归约` 保证；
- 一个迭代后删除旧卡片分支，避免双实现长期并存。

## 9. 风险与回滚

| 风险 | 影响 | 对策 |
|---|---|---|
| 折叠驱动与 `grid-template-rows` 过渡并存 | 双重缓动、行距抽动 | 二选一；实现时先清 `transition`、`void offsetHeight` 一次 |
| 帧内读几何 + 写滚动 | 每帧强制同步布局 → 掉帧 | 只测一次，解析式补偿；用 `test:scroll-follow` 的帧采样兜底 |
| 阈值 80 → 40 → 24 | 误触发跟尾 | 常量可配 + 一周灰度 |
| `test:motion` 漏登记 | CI 直接红（004 已有先例） | 阶段 0 先登记，阶段 2 再接样式 |
| 双渲染器并存期 | 维护成本、行为分叉 | 开关默认关，一个迭代内删除旧分支 |
| 去外框影响既有 UI 断言 | `test:ui-guard` 失败 | 阶段 0 列清单，阶段 1 同步调整 |
| 规范与代码口径不一致 | 文档落后于实现 | 阶段 0 先改规范草案，实施中逐条勾选 |

### 13.3 术语
