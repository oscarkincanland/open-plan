## 4. 偏差与遗留

1. **激活语义**：计划 §10 待确认项按“显式点击即激活”实现；agent 事件/兜底同步不激活。若产品要求“后台打开”，只改 `resolveMapPreviewAction` 调用处的 `activate` 使用。
2. **视口晚到竞态（未完全消除）**：`MapViewer` 只在建图时应用 `initialView`；若地图模块挂载时 `mapContext.center` 尚未回填，仍会以 config 默认相机建图并上报。建议后续在 App 侧加“header 未回填前忽略该会话视口上报”的保护，需另立小项。
3. **归档恢复入口范围**：侧栏与设置面板已联动；ChatPanel 对话栏历史抽屉里的 `SessionList` 未传 `onRestored`（该文件正被并行改动，未触碰）。若需要一致行为，后续补传 prop。
4. **人工验收未做**：真实工作区多点几个地图会话、草稿固化前后对照、录屏验收留待用户执行。
5. **与本计划无关的既有失败**（HEAD 与工作区计数一致，非本次引入）：`test:ui-guard` 3 处硬编码色值（LayerPanel 39>37、MapViewer 45>43、草稿样式对话框 2）、`test:event-emission` 的 `map_draft_discarded` 无发射点、`test:adr-index` 缺并行会话新增 ADR-0032 的索引行。
