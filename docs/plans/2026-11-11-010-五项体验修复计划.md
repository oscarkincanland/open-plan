## 1. 范围

### 1.1 本次要做

- **F1 本轮产物收敛**：画布内部文件（`designs/<slug>/project/**` 与 `designs/<slug>/operations.jsonl`）从"产物展示 + 送检清单"中隐藏；导出文件（`designs/<slug>/exports/*`）、数据产物（GeoJSON/CSV 等）、文档产物照常显示；"改动"面板与版本时间线不受影响（画布文件变化仍可见）。
- **F2 终态误报修复**：① 送检/产物清单跳过 `status === "deleted"` 的条目；② map_export 越界校验改为"产物必须落在 outDir 内"（不再用调用方 workspace 前缀）；③ "浏览器连接已关闭"记录为已知问题（不修）。
- **F3 地图模式画布活动可见**：地图模式下有画布活动时，在地图视图渲染浮动指示 pill（"Agent 正在编辑画布《标题》"+ 查看按钮），点击退出地图模块并激活对应画布标签。
- **F4 新建画布自动切换**：`canvas_created`（当前会话）在地图模式下自动退出地图模块并打开新画布标签（对齐用户"及时切换"要求）。
- **F5 模型选择器紧凑 + 默认模型**：地图模式模型选择器不再独占整行（图标+模型名紧凑胶囊，隐藏副标题）；初始化链改为服务端默认优先于"上次使用"（仅影响新会话显示层，会话内缓存不变）；运行设置默认改为 `opencode-go/deepseek-v4.1-flash`。

### 1.2 非目标

- 不修"浏览器连接已关闭"（内置浏览器 CDP 生命周期，另行排查）。
- 不改完成语义本身："待办未完成 → partial（有风险）"的诚实降级保留（修掉 map_export 误报后此类场景大幅减少）。
- 不动三模式边界、工具白名单、事件注册表（无新事件）。
- 不改"上次使用"在设置页/选择器里的展示逻辑（只改新会话初始化优先级）。

## 2. 设计

### 2.1 F1 产物收敛（server/runs.mjs）

- 新增导出 `isCanvasInternalArtifactPath(relativePath)`：匹配 `designs/<slug>/operations.jsonl` 与 `designs/<slug>/project/**`（canvas.json、boards/**、pages.json 等）。
- `publicRunView`（L1744）噪音过滤处合并：`!isNoiseArtifactPath && !isCanvasInternalArtifactPath`——产物面板、会话产物列表、`/api/runs` 读取全部收敛。
- `finishRun` 的 `finishedData.artifacts`（L1497，会话结果卡数据）同口径过滤。
- 送检清单（执行句柄.mjs / index.mjs 共 4 处 `listRunArtifacts(...).map(...)`）同口径过滤（画布内部文件无需结构校验）。

### 2.2 F2 终态误报（server）

- **送检跳过 deleted**：4 处 `listRunArtifacts(...)` 消费处统一 `.filter((item) => item.status !== "deleted")`（`执行句柄.mjs:432,490`、`index.mjs:5460,5532`——实施时以实际行号为准）；`finishRun` 的 validations 传参随调用方修正。
- **map_export 越界**：`地图导出执行器.mjs:66` 改为 `if (!target.startsWith(path.resolve(dir) + path.sep))`——不变式是"产物必须落在调用方指定的 outDir 内"；workspace 仅用于缺省 outDir（G7 口径不变，`test:map-export-executor` 回归）。

### 2.3 F3+F4 地图模式画布联动（client/App.jsx）

- **F4 自动切换**：`pendingCanvasOpen` 消费 effect（App.jsx:862-870）中，若 `activeModule === "map"` → 追加 `closeExternalModules()`（setActiveModule(null) 退出地图回工作区视图）再 `openDesignCanvas(slug, title)`；仅当前会话事件（sameThread 判断既有）触发，后台会话的新画布不打断地图视图。
- **F3 活动指示**：`activeModule === "map"` 且 `Object.values(canvasActivity).some(i => i.active)` 时，在地图对话槽上方渲染浮动 pill（fixed 定位、`--map-accent` 描边 + 呼吸点，复用 `oaw-agent-pulse`）：`Agent 正在编辑画布《标题》` + 「查看」按钮 → `closeExternalModules()` + `openDesignCanvas(slug, slug)`（带 009 的 10s 手动切换守卫逻辑复用？——地图模式无标签切换操作，守卫不需要；直接切换）。活动结束 pill 自动消失（canvasActivity 驱动，run 终态已收口）。

### 2.4 F5 模型选择器（client + 配置）

- **紧凑化（styles.css:10347-10358）**：`.toolbar-agent-group` 改 `flex: 0 1 auto`；`.model-control-trigger` 改 `width: auto; max-width: 220px`；map 模式隐藏 `.model-control-current small`（副标题）并收敛 strong 宽度（参照 compact 既有断点 L6768-6779 的做法）。
- **默认模型链（ChatPanel.jsx:2415）**：`const preferred = cachedModel || storedThreadModel || d.default || saved || ""`——服务端默认（运行设置）优先于"上次使用"（localStorage oaw_model）；会话级缓存（thread 缓存/sessionStorage）不受影响，刷新后当前会话模型仍保持。行为变化：新会话不再继承"上次使用"，改为服务端默认。
- **运行设置（环境配置，非代码）**：`.oaw/规聚/运行设置.json` 改为 `{"defaultProvider": "opencode-go", "defaultModel": "deepseek-v4.1-flash"}`（等价于设置页"设为默认"操作；模型 ID 已在目录中且 vision=true）。
