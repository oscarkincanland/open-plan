## 5. 偏差与说明

- **开关策略**：`OAW_TRANSCRIPT_V3` 默认关闭；关闭时全部新分支不生效（`TimelineRow` 不包 `TextShimmer`、`RunFoldBar` 走原 grid 过渡、滚动仍 80px + 60ms 定时器）。
- **阈值**：按方案灰度取 **40px**（未直接切 24px）。
- **折叠体隐藏方式**：v3 暂用内联 `height: 0` + `overflow: hidden`；`hidden="until-found"` 留在阶段 6。
- **行级展开动画**：按 DSH 结论，行/组展开不做高度动画（仅 chevron 旋转），避免与折叠帧钟叠加。
- **折叠体保留方式**：v3 折叠体仍用内联 `height: 0`（动画中需要高度）；`hidden="until-found"` 已用于**组体**。若要把"浏览器查找命中折叠整轮"也做全，需要给折叠体加"动画结束后再置 hidden"的二段状态（阶段 6 收尾项）。
- **live 视觉验证未完成**：无头浏览器多次尝试（首页 → 项目卡 → `.project-session-open`）均未进入会话视图（`.chat-body` 不存在，`attr: null`），因此"组头 / 扫光 / 折叠补偿在真实会话中的观感"没有截图级证据。逻辑层已由单测 + `buildRunTimeline` 联调覆盖，构建产物里也确认包含 `data-transcript-v3` 与 `.tl-group-head`；建议开启开关后按 §7 手测矩阵人工过一遍（6 条）。
- **折叠体 `hidden="until-found"`**：已实现"收起动画结束后 260ms 再置 hidden"，避免动画期间被隐藏；组体同样使用该属性。

## 7. 2026-11-15 缺陷修复：打开会话即「组件出错，请刷新页面」

**现象**：进入任意会话，ChatPanel 错误边界捕获异常，整块显示「组件出错，请刷新页面」。与 `OAW_TRANSCRIPT_V3` 开关无关（默认关也复现）。

**根因（三处，均为本次 v3 改造引入的作用域/API 误用）**：

| # | 位置 | 问题 | 表现 |
|---|---|---|---|
| 1 | `ChatPanel.jsx` `Message()` | `transcriptV3` 只在 `ChatPanel` 内声明，但 4 处引用（段落 useMemo、思考行 shimmer、RunFoldBar v3）实际位于同级组件 `Message` | `ReferenceError: transcriptV3 is not defined` |
| 2 | `Message()` → `RunFoldBar` | 传了 `scrollRef={bodyRef}`，而 `bodyRef` 是 `ChatPanel` 的 ref，`Message` 作用域没有 | `ReferenceError: bodyRef is not defined` |
| 3 | `RunFoldBar.jsx` | 补丁把第二个 `useLayoutEffect` 插进了第一个 useLayoutEffect 的回调里 | React error #321（Invalid hook call） |

**修复**：

1. `Message()` 内自行声明 `const transcriptV3 = flag("transcriptV3")`（两个组件各自读开关，flag 快照是不可变模块级数据，不重复请求）；
2. `RunFoldBar` 去掉对 `bodyRef` 的依赖：滚动容器优先用传入 `scrollRef`，否则 `el.closest(".chat-body")` 就近解析；
3. 重写 `RunFoldBar.jsx`，把「高度控制」「hidden 置位」「settle 定时」拆成三个独立 effect；
4. 顺带修正 `hidden="until-found"`：React 18 把 `hidden` 当布尔属性会把字符串压成 `hidden=""`，改为 `setAttribute("hidden","until-found")`（组体 + 折叠体）。
