## 5. 验收口径

```bash
node scripts/规范索引守护测试.mjs          # exit 0（含索引/版本/别名三项）
npm run -s test:harness                    # exit 0
npm run test:known-failures                # exit 0
npm run verify                             # exit 0（含新增架构边界棘轮）
node scripts/架构边界检查.mjs               # exit 0，且不新增违规
node scripts/CI全量复跑.mjs                # 逐条与基线比对：未登记失败数 = 0
```

- 每条改动能指回本计划阶段号；变更日志记一条 `docs`/`test`。
- 未修完的红套件必须在基线里有签名，不允许「知道红但不登记」。
- CI 步骤数会随批次变化，规范只写「以 ci.yml 为准」，本计划不写死数字。
