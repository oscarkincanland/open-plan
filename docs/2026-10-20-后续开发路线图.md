## P2 · GIS 与数据（根目录 `后续开发计划.md` 为准）

## 版本与发布策略

- 语义化小版本在当前稳定基线递增（v0.11.x）；正式版 tag 用附注类型标注验收基线
- 每轮提交前 `npm run verify` + 相关 `test:*`；feat/fix/docs/chore 提交头
- 桌面端（openplan-desktop）独立仓库、独立发布，与本仓库零耦合
