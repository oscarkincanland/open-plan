# 0025 地图采用草稿层与显式固化审批边界

- 状态：已采纳
- 记录日期：2026-11-07
- 决策者：用户
- 基线：v0.13.24（未发布）
- 关联：计划 [2026-11-07-001-地图临时图层固化与审批边界修改计划](../plans/2026-11-07-001-地图临时图层固化与审批边界修改计划.md)、`REQUIREMENTS.md` R10、`DESIGN.md` §9.3、`AGENTS.md` §1/§5/§6

## 1. 背景

地图模块此前同时支持 Chat（只读查询 + 临时可视化）与 Work（可写），Agent 生成的分析结果通过 `map_action` 事件落到前端运行时图层，刷新即丢失；"保存为正式图层"依赖内存态 `entry.lastMapAnalysis`，且 `map_save_analysis` 存在未绑定变量导致必然失败。审批策略对地图写工具覆盖不足，共享数据可被覆盖，`auto` 自动批准模式会把 ask 提升为 allow。演示数据也混入了默认项目。

## 2. 问题

Agent 生成的地图结果缺少"先预览、再确认"的可信中间态，正式写缺少统一审批边界，导致：用户无法可靠地决定哪些结果进入正式图层；正式写可能未经确认落盘；演示数据可能被当成正式成果。

## 3. 备选方案

### 方案 A：保留 Chat 常驻，仅给现有保存链路补审批

- 做法：保留地图内 Chat/Work 切换，修补 `map_save_analysis` 与审批规则。
- 优点：改动最小。
- 代价：模式边界继续分裂（UI 与 Agent 两套实现）；临时层仍依赖内存态，刷新不可恢复。

### 方案 B：地图收敛为 Work 专属 + 草稿层 + 用户确认固化 + 审批边界（采纳）

- 做法：Chat/Review 不持有地图工具；Agent 生成草稿（只写 `agent/drafts/`，免审批），用户确认后固化（审批 + 事务化写入）；共享/锁定/演示数据受硬约束；取消刷新时长承诺。
- 优点：生成与采纳分离，用户保留最终控制权；审批按可逆性/作用域分级；与 PRD/AGENTS 的模式边界一致。
- 代价：新增草稿存储、事件、REST 与前端面板；需要迁移测试与文档。

### 方案 C：所有写入都要求审批

- 做法：草稿生成也逐次审批。
- 优点：最安全。
- 代价：Agent 连续生成/调整时频繁打断，体验不可接受。

## 4. 决策

选择**方案 B**：

1. 地图模块仅在 Work 模式开放；Chat/Review 不持有任何 `map_*` 工具；历史 Chat 地图会话仅保留只读预览。
2. 新增草稿层（`agent/drafts/`）：点/线/面，不进入 `layers/`、`style.json`、`tiles/`、`map.config.json`；免审批、可丢弃、刷新可恢复。
3. 固化为正式图层必须由用户确认（UI 对话框 + `confirmed:true`）或 Agent 经审批（`map_fixate_layer`）。
4. 审批边界：草稿免审批；固化/导入/改样式/删除/替换/重置/项目生命周期需审批或显式确认；共享数据集禁止写入；锁定图层任何路径都拒绝；`auto` 模式不得自动批准固化与破坏性操作。
5. 刷新语义改为事件驱动 + 手动刷新兜底，不承诺秒数。
6. 演示数据只能作为草稿存在并带 `provenance.demo`；固化后保留“演示数据”标记；不得写入默认项目正式层。

## 5. 理由

- 草稿层把"生成"与"采纳"分离：Agent 保持效率，用户保留最终控制权。
- 审批按可逆性与作用域分级（草稿可逆免审批，正式写不可逆必确认），避免"每次生成都打断"。
- Work 专属消除双模式实现分叉，使 PRD/DESIGN/AGENTS 与代码一致。
- 草稿持久化解决了 `map_action` 刷新丢失与 `lastMapAnalysis` 内存态问题。

## 6. 影响

- **API/SSE**：新增 `map_draft_changed / map_draft_confirmed / map_draft_discarded` 事件与 `/api/map/project/:name/drafts*` 路由；`map_action` 保留兼容；`file_changed` 语义不变。
- **工具白名单/审批**：Chat 移除地图工具；新增 `map_draft_layer`（免审批）/`map_fixate_layer`（ask）；`map_save_analysis` 修复并保留兼容（ask）；工具元数据新增 `forceConfirm`。
- **数据**：草稿在 `agent/drafts/`（gitignored）；默认项目不再混入演示数据；`validateGeoJSON` 增加几何族/中国范围/记录数校验；导入与替换事务化。
- **文档**：PRD R10、DESIGN §9.3、AGENTS §1/§5 已同步；变更日志记录。

## 7. 不适用

- 不做多用户实时协同编辑（仍为单用户本地工作台）。
- 不承诺刷新时长 SLA。
- 不允许 Agent 自动固化（必须用户确认或审批）。
- 不改变 MapLibre 渲染栈与瓦片管线。
