# 0006 保留皮肤系统并锁定状态色语义

- 状态：已采纳
- 记录日期：2026-10-28
- 决策者：项目负责人（设计一致性整改 D1 决策，经用户确认）
- 基线：v0.13.2
- 关联：[DESIGN.md](../../DESIGN.md) §5.5、§5.7、§13；[整改计划](../plans/2026-10-28-005-前端设计一致性问题整改计划.md) D1；[实施记录](../plans/2026-10-28-006-前端设计一致性实施记录.md)

## 1. 背景

DESIGN 曾把“暗/亮主题 + Qoder 受控视觉层”定义为唯一视觉基线，但代码里同时存在 `proma / glass / ocean / forest / sunset / violet` 六套皮肤，并允许皮肤覆盖全部语义令牌，包括 `--success / --error / --warning`。结果是：

- 同一状态在不同皮肤下显示成不同颜色，用户无法跨皮肤建立稳定认知；
- 状态色被当作模式品牌色使用（如 Review 用琥珀色），语义漂移；
- 设计令牌棘轮测试无法给出稳定基线。

整改计划给出三个选项：删除皮肤（A）、保留皮肤但补 ADR 并锁定状态色（B）、只留 Proma（C）。

## 2. 问题

皮肤系统是删除、收敛，还是保留并施加约束？

## 3. 备选方案

### 方案 A：删除皮肤，只保留暗/亮主题 + Qoder 受控层

- 做法：删除 `theme.jsx` 的 `SKINS`、设置页“工作台风格”、三段皮肤 CSS，迁移 `localStorage.oaw_skin`。
- 优点：视觉基线唯一，令牌棘轮最容易收敛。
- 代价：已选皮肤的用户观感突变；属于删除既有能力，需要迁移与告知。

### 方案 B：保留皮肤，但皮肤只能改中性色与强调色

- 做法：皮肤允许覆盖背景/面板/文本/边框/`--accent`；禁止覆盖 `--success / --error / --warning`；新增色相锁定测试；玻璃皮肤的正文面板改为不透明，模糊只留给关键浮层。
- 优点：保留用户已有选择，状态语义全局一致，改动可测。
- 代价：DESIGN 需要明确“皮肤是受控子集”的写法；需要新增守护测试。

### 方案 C：只保留 Proma 一套并写进 DESIGN

- 做法：删除其余皮肤，Proma 成为默认。
- 优点：实现简单。
- 代价：仍属多主题，需要修订 DESIGN 的“不做清单”；用户已选皮肤同样受影响。

## 4. 决策

选择方案 B：**保留现有 7 套皮肤（默认 + 6），但皮肤只允许覆盖中性色与 `--accent`；`--success / --error / --warning` 的色相在全部主题/皮肤下锁定为绿/红/琥珀。**

约束：

- `scripts/设计令牌一致性测试.mjs` 对每个 `:root[data-skin]` 块做色相断言：success ∈ 70–170°，error ≤15° 或 ≥345°，warning ∈ 20–55°。
- 不允许用状态色充当 Chat/Work/Review 的模式品牌色；模式选中态统一使用 accent 或文本反色。
- 玻璃皮肤（`data-skin="glass"`）的正文/内容面板使用不透明底 `--glass-content-bg`，`backdrop-filter` 只保留在顶栏、输入框、弹层等关键浮层。
- 不新增皮肤；新增皮肤必须另写 ADR。

## 5. 理由

- 状态色是跨界面的“交通信号”，必须与皮肤无关；锁色相即可在不牺牲皮肤的前提下恢复稳定认知。
- 删除皮肤属于删除既有能力与用户数据迁移，收益（测试基线更小）不足以抵消影响面。
- 玻璃皮肤的性能问题可以在皮肤内部解决（正文不透明 + 浮层保留模糊），不必牺牲整套皮肤。

## 6. 影响

### 正面

- 用户既有皮肤选择保留；状态语义在暗/亮与全部皮肤下一致。
- 令牌棘轮有稳定基线（2026-10-28 实测 141 处 / 100 种）。

### 负面 / 代价

- DESIGN 需要维护“皮肤是受控子集”的说明，新增皮肤的门槛提高。
- 玻璃皮肤观感略有变化：正文面板从半透明变为不透明，模糊集中在浮层。

### 迁移与回滚

- 迁移：无需迁移，`localStorage.oaw_skin` 保持有效。
- 回滚：整段皮肤 CSS 与状态色锁定测试在同一提交内，可整提交回滚。

## 7. 验证

- `npm run test:design-tokens`：皮肤状态色色相锁定 + 硬编码色值棘轮。
- `npm run test:a11y`：正文对比度阈值 4.5:1。
- `npm run test:motion`：减少动效/关闭动效下无持续动画。
- 玻璃皮肤手测：1024 / 781 宽度滚动无掉帧；正文对比度达标。

## 8. 复审触发条件

- 需要新增皮肤或允许皮肤覆盖状态色。
- 玻璃皮肤在主流设备上仍出现明显掉帧，且 `data-visual-effects="off"` 降级不足。
- 产品决定彻底收敛为单主题。
