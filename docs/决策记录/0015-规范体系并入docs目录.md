# 0015 规范体系并入 docs 目录

- 状态：已采纳
- 记录日期：2026-10-30
- 决策者：用户
- 基线：v0.13.12
- 关联：[AGENTS.md](../../AGENTS.md)、[文档管理规范](../规范/文档管理规范.md) §2、[GIT工作流规范](../规范/GIT工作流规范.md)

## 1. 背景

本地在 `doc/项目规范化管理/` 下产出了 8 份治理文档（00 需求、01 架构、02 开发规范、03 前端设计规范、04 验收清单、05 当前开发进度、06 决策进度、07 GIT 工作流）。远程 v0.13.11 已建立成熟规范体系：`AGENTS.md` v2.0 + `docs/规范/` 5 份 + `docs/决策记录/0001–0011` + `docs/plans/` + `tests/`。

合并后两套体系并存，违反“单一事实来源”，且 `doc/` 与 `docs/` 一字之差极易误引。

## 2. 问题

本地 8 份文档如何与远程规范体系归口？不解决将导致：

- 同一规则两处维护、逐步分叉；
- 新会话无法判断哪份是生效规范；
- 目录名 `doc`/`docs` 混淆。

## 3. 备选方案

### 方案 A：并入 docs，分层归口（已选）

- 做法：
  - 07 GIT 工作流 → `docs/规范/GIT工作流规范.md`（远程无同类，升为生效规范）；
  - 05 当前开发进度 → `docs/进度/当前开发进度.md`（新目录，作为会话入口）；
  - 06 决策进度 → `docs/决策记录/决策进度.md`（与 ADR 索引并列，保留 D 台账）；
  - 00–04 → `docs/规范/归档/本地v0.11.55/`（标注“历史基线归档”，生效规范以 `docs/规范/` 远程版为准）；
  - 删除空 `doc/` 目录；`AGENTS.md` 升 v3.0 作为唯一宪法。
- 优点：唯一归口、路径统一、远程规范与本地增量并存且边界清晰。
- 代价/风险：00–04 中可能有少量独有细节被归档而非合入生效规范。

### 方案 B：保留 doc/ 平行体系

- 做法：`doc/` 与 `docs/` 长期并存，靠文档头标注关系。
- 优点：无需搬迁，零风险。
- 代价/风险：双事实来源、维护成本翻倍，最终必然分叉。

### 方案 C：全量删除本地 8 份

- 做法：只保留远程规范，本地文档直接删除。
- 优点：最干净。
- 代价/风险：丢失用户明确要求产出的文档与本地增量（GIT 工作流、决策台账、进度视图）。

## 4. 决策

选择**方案 A**。生效规范归口：

| 主题 | 唯一事实来源 |
|---|---|
| 宪法 | `AGENTS.md` v3.0 |
| PRD | `REQUIREMENTS.md` |
| 设计与体验 | `DESIGN.md` |
| 长期规范 | `docs/规范/*`（含新增 `GIT工作流规范.md`） |
| 决策 | `docs/决策记录/*` + `决策进度.md`（D 台账） |
| 计划 | `docs/plans/*` |
| 进度 | `docs/进度/当前开发进度.md` |
| 变更 | `变更日志.md` |

归档文档（`docs/规范/归档/本地v0.11.55/`）只作历史参考，**不得**作为实施依据；与生效规范冲突时以生效规范为准。

## 5. 理由

- 符合用户“规范归口并入 docs”的明确选择。
- 保留全部既有内容（只归档、不删除），同时消除双事实来源。
- 与远程索引机制（AGENTS.md §10、决策记录索引）一致，可被机检与人工检索。

## 6. 影响

### 正面

- 索引、ADR、计划、进度、变更形成单一链路；`AGENTS.md` 可直接作为交叉验证锚点。

### 负面 / 代价

- 归档文档内的相对链接按归档目录重算，个别跨目录链接可能失效（已在归档索引标注）。

### 迁移与回滚

- 迁移：本轮已移动文件并更新 `AGENTS.md` §10 索引、[决策记录索引](决策记录索引.md)。
- 回滚：从 `backup/local-v0.11.55-20261030` 恢复 `doc/项目规范化管理/` 即可。
- 兼容性：纯文档移动，不影响代码与测试。

## 7. 验证

- 需要新增/更新的测试：无代码测试；`npm run verify` 确认无副作用。
- 验收口径：`doc/` 不存在；`docs/规范/`、`docs/进度/`、`docs/决策记录/` 各文档可从 `AGENTS.md` §10 到达；归档索引存在。
- 观察指标：新会话首读 `docs/进度/当前开发进度.md` 可获取最新状态。

## 8. 复审触发条件

- 远程主线新增同类规范并出现主题重叠；
- 归档内容被多次引用为实施依据（应升为生效规范或合入）；
- 文档数量增长导致手工索引失效（改为脚本生成）。
