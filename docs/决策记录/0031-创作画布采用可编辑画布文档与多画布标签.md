# 0031 创作画布采用可编辑画布文档、多画布标签与“对象板 + 兼容板”混合模型

- 状态：已采纳（随 2026-11-09 用户确认“全量修改”落地）
- 记录日期：2026-11-09
- 决策者：用户
- 基线：v0.13.24
- 关联：[创作画布模块修改计划](../plans/2026-11-09-003-创作画布模块修改计划.md)、`REQUIREMENTS.md` R17、`DESIGN.md` §8.4、`AGENTS.md` §1/§5、[开发收敛规范](../规范/开发收敛规范.md) §1/§7、[架构规范](../规范/架构规范.md) §8/§11

## 1. 背景

仓库 `designs/` 下已有 claude-design / baoyu-design 格式画布（`project/canvas.json` v3 + `.dc.html`），但产品内没有渲染、编辑与导出入口；地图“AI 画布”是地图工程入口，不能复用为通用设计画布。用户要求：可编辑画布、PPTX 文本可编辑、V1 兼容 `.dc.html`、多画布多标签、命名“创作画布”。

## 2. 问题

如何在不引入画布引擎、不破坏外部 skill 工作流的前提下，提供产品内可编辑的设计画布，并让 Agent 与用户共用同一数据模型？

不解决的后果：Agent 生成的 SVG/版面只能留在工作区文件里，用户要在外部编辑器与产品之间来回搬运；无法形成“生成 → 编辑 → 预览/导出”的闭环。

## 3. 备选方案

### 方案 A：纯 SVG 文件为真源（只读渲染）

- 做法：Agent 写 `.svg`，前端 `<img>`/沙箱 iframe 预览。
- 优点：零编辑复杂度；导出 SVG 直接。
- 代价：无法满足“可编辑画布/可编辑文本框/PPTX 文本”；放弃。

### 方案 B：canvas.json 对象模型 + 对象板 + 兼容板（本决策）

- 做法：`canvas.json` 索引 + `.board.json` 对象板（text/rect/line/image/svg）+ `.dc.html` 只读兼容板；React DOM/SVG 渲染与编辑；导出走 CDP（PNG/PDF）与 pptxgenjs（PPTX）。
- 优点：满足编辑与 PPTX 文本；兼容外部画布；零新依赖；可逐板 CAS 保存。
- 代价：自研编辑器工作量最大；PPTX 为近似还原；HTML 兼容板不可编辑。

### 方案 C：引入 konva/fabric/tldraw 画布引擎

- 做法：用成熟引擎承载对象编辑。
- 优点：编辑体验好。
- 代价：新增依赖/包体/许可/学习成本，需另行 ADR 与体积评估；与“零新依赖”和当前收敛方向冲突。

## 4. 决策

选择**方案 B**：画布真源为 `canvas.json` + `.board.json` 对象板；`.dc.html` 作为只读兼容板；多画布多标签；工具仅 Work、默认关（`OAW_CREATIVE_CANVAS`）；导出采用“对象映射 + 图片兜底”。

不适用的边界：不做 HTML 内部对象编辑；不做多人协同；不做设计系统；不写回外部 `.dc.html`。

## 5. 理由

- 用户明确要求可编辑、可编辑文本、V1 兼容，方案 B 是唯一同时满足三项且不引依赖的形态。
- 对象板与 PPTX 文本框一一对应，导出可验证；兼容板整页图片兜底，风险可控。
- 与现有画布标签体系、产物台账、审批与事件契约同构，改动可收敛；开关关闭即基线。

## 6. 影响

### 正面

- 产品内获得设计画布与导出闭环；外部画布可直接打开；Agent 获得可视化产出能力。

### 负面 / 代价

- 编辑器维护成本；PPTX 近似还原；兼容板只读可能低于部分用户预期。

### 迁移与回滚

- 迁移：新增 `designs/<slug>/` 目录与 `canvas_*` 工具；无存量数据迁移。
- 回滚：`OAW_CREATIVE_CANVAS=0` 即基线（入口/工具/API 全部关闭）；已产生文件保留。
- 契约兼容性：新增工具与事件，不改既有工具语义；会话 header 新增 `creativeCanvas` 字段，旧会话缺省为空。

## 7. 验证

- 新增/更新测试：`test:canvas-model`、`test:canvas-export`、`test:canvas-ui`、`test:capability-contract`、`test:tool-metadata`、`test:event-payload`、`test:event-emission`。
- 验收口径：见 `REQUIREMENTS.md` R17 验收与计划 §6。
- 观察指标：画布加载/保存失败率、导出成功率、PPTX 可编辑性、关闭开关后的基线一致性。

## 8. 复审触发条件

- 对象板/画布规模或编辑操作复杂度显著上升（需要引擎）；
- PPTX 保真成为主要投诉（需要原生形状/文本增强或换导出器）；
- 外部画布格式升级导致兼容层维护成本上升。
